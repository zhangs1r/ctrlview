当指令开始检索轨迹

Hung-Jen Chen, Yu-Hsun Hou, Yan-Hong Chen, Yan-Fu Chen, Binghua Cai, Min Sun, Chun-Yi Lee
arXiv:2609.39971 · 2026-10-01 · 精读约 32 分钟
VLA模仿学习分布偏移反事实增强具身操作

它想干什么

一台机械臂接到口令，把盘子放到柜子顶上。它伸出爪子，稳稳抓起旁边那只碗，走出一条和演示里几乎重合的弧线，把碗放到了柜子顶上。抓取干净，轨迹平滑，口令没被执行。

微调过的 π₀.₅ 就会这样。π₀.₅ 是 Physical Intelligence 的视觉语言动作模型。它让一个预训练视觉语言模型读图像和口令，再让一个三亿参数的动作专家用流匹配生成一段连续动作。训练时可以选择只训视觉编码器和动作专家。和本文后面要评的推理端干预路线相比，差别在这里。它的动作选择发生在训练好的条件分布里，调用的训练信号只有模仿损失一个。

麻烦的是同一套策略在很多扰动下依然好看。口令换个说法它照做，物体换个外观它照做，成功率还是九十几。可只要把两个物体的位置对调，或者把口令里的目标换掉，成功率就掉到两三成。论文把这两类扰动分开命名。改变措辞或外观、成功所需动作没变，叫 nuisance 扰动。把目标、位置、关系换掉、成功所需动作跟着变，叫 counterfactual 扰动。这一刀切下去才看得清问题，因为把两类扰动混成一个平均鲁棒性分数，会把真正的失败盖住。

盖住的是什么，论文给出了很具体的回答。它在 LIBERO-PRO 上跑了 381 条定点扰动轨迹，逐条人工标注。其中 69.3% 是熟悉的演示行为重演，27% 左右近似完成了改动后的要求，只有 4.2% 彻底崩掉，连一条像样的轨迹都拿不出来。所以失败不是模型看不见、也不是听不懂，它选中了另一条它熟悉的轨迹，然后老老实实把那条轨迹执行完。论文把这个失败模式命名为 instruction-action binding，指令与动作的绑定失效。

论文的处理分三步。先用行为统计和内部状态读出把失败描述清楚；再从模仿学习的目标函数上解释为什么这种解能通过训练；最后给出一个训练侧的修法，Equivariant Counterfactual Training，简称 ECT。ECT 分两层，一层是造数据，在同一口令下补进场景不同、所需动作也不同的合法演示；另一层是改批次的组法，把一对互为反事实的演示放进同一次参数更新。效果是 LIBERO-PRO 上 π₀.₅ 的 Swap 格平均从 36% 提到 59%。CALVIN 上五连任务完成率从 58% 提到 76%，真机 UR5e 在固定演示预算下把未见位置的成功率从 3/40 提到 35/40。

这节要你记住的是，指令和场景要一起决定动作，只挑轨迹族会挑错。

一、问题背景

1.1 扰动要按"改不改动作"分两类

先把判据立起来。设 s 是观测，ℓ 是口令，a 是专家动作轨迹，记 a*(s,ℓ) 为这个场景加这个口令下、与任务成败有关的动作要求，它包含目标物、终点以及它们的空间实现，不纠缠执行时的细微差别。论文用两个示性量给扰动分类。

(4)Δk=1[k(ℓ′)≠k(ℓ)],Δa=1[a*(s′,ℓ′)≠a*(s,ℓ)]

Δk 说的是这个扰动的口令是否对上了另一个熟悉任务，Δa 说的是成功所需的动作是否换了。前者管策略选了哪条轨迹族，后者管任务要求什么。两个界面都没坏，坏的是把它们合起来选动作的那一步。

这个分类不是文字游戏，它直接决定了分数该怎么读。LIBERO-PRO 把扰动分五格，论文用了其中四格，Semantic、Object、Swap、Task。前两格的分数高只说明陈旧的熟悉行为还没被破坏，后两格才在问策略有没有按当下的口令和场景重新选动作。

1.2 为什么模仿学习允许这种解

论文的解释落在条件动作支撑上。记 suppD(A∣ℓ) 为口令 ℓ 下演示轨迹覆盖到的那一块动作分布。在 LIBERO 的任务级微调设定里，同一口令下的演示通常挤成一条窄窄的轨迹族，于是指令几乎就确定了任务。

(1)H(T∣ℓ)≈0,H(T∣s)≈0

H(T∣x) 是看过线索 x 之后，任务身份还剩多少不确定度。式 (1) 说的是口令和场景各自都能把任务认出来，两个线索都够用。这带来一个后果，策略不需要把两者结合起来就已经能把演示拟合好。

论文把这条路径写成理想化的查表策略。一个真正把口令落到场景里解指称的策略，动作只通过"口令指的东西在当前场景里是哪一个"来依赖观测。

(2)πground(a∣s,ℓ)=π(a∣g(s,r(ℓ)))

而查表式的策略绕开场景，直接按口令的最近邻演示去挑一条轨迹族，fℓ 把口令映成表示，dℓ 量距离，k(ℓ) 给出最近的演示口令。

(3)πlookup(a∣s,ℓ)=π(a∣k(ℓ)),k(ℓ)=\argminjdℓ(fℓ(ℓ),fℓ(ℓj))

这两种解在演示数据上可以同时把损失压到很低。原因在流匹配的目标函数里看得很清楚。设 a0 是噪声，at=(1−t)a0+ta 是插值动作，平方损失下的群体最优速度场是条件期望。

(10)v*(at,t∣s,ℓ)=𝔼[a−a0∣at,t,s,ℓ]

如果 k(ℓ) 在训练分布上几乎就决定了演示轨迹，那么把条件里的 (s,ℓ) 换成 k(ℓ)，这个条件期望几乎不变。同一套百分之百的演示，既容得下会组合的解，也容得下查表的解。更多的同类演示只是把样本数堆高，换不来新的动作分支。要打破它，监督里得有同一个口令下动作不同的演示，而且两个场景要足以分辨该走哪一支。这就是论文说的问题根源，窄的条件动作支撑让两种解在监督上不可分。

1.3 前人两条路各自缺什么

第一条路是从模型内部找原因，把 VLA 的失败归到语言用得不够、模态失衡或者视觉表示在微调中变形。Fang 等人在这条路上走得最远，他们报告了反事实口令下模型仍执行熟悉任务的现象，把它归给视觉捷径，并给出 Counterfactual Action Guidance，CAG。CAG 在推理时加强语言条件。好处是不用重训、上线就能用，代价是它只在解码阶段的注意力上动刀，改不了训练数据里缺掉的那部分动作支撑。

第二条路是造数据。CAST 固定观测，同时改口令和动作，出的是同一画面下的另一套说法与做法。RoCoDA 与 MimicGen 把演示搬到新的场景配置里。RoCoDA 用因果重采样配 SE(3) 变换，在单任务的 ACT 设定上保存成功的变换子轨迹。MimicGen 从人类演示批量生成新场景中的轨迹。这两个工作都证明了变换和重放能造出可执行的演示，但它们的目标是数据效率或者覆盖度，没有盯住"同一口令下两种动作都出现"这一条。等变策略是第三条路，EquiBot 这一类的做法是把对称性直接写进网络结构，让动作天生随场景变换，代价是架构要改、对称性要预先指定。

ECT 的位置落在第二条路和第三条路之间。它沿用动作有效的几何变换来造演示，换掉的是变什么，固定口令、变场景和所需动作，同时把"这两个演示是同一口令下的两个分支"这件事写进同一次更新。架构一行不改。

📌 控制视角　把式 (1) 到式 (3) 翻成控制的语言，这是在说系统的输入输出映射有多解。口令是参考输入，场景是工作点，动作是控制量。演示数据只在一个工作点附近给过参考输入到控制量的样本，那么任何在这点附近插值的映射都能拟合示教。要把它变成真正的条件映射，得让同一参考输入在不同工作点上配不同的控制量，而且工作点本身要能从量测里分辨出来。系统辨识里这叫持续激励，这里叫条件动作支撑。

这节要你记住的是，监督里没有同口令不同动作的对照，查表解就够用了。

三、方法拆解

3.1 第一步，把成功率按格拆开

论文在两个 VLA 家族上跑官方 checkpoint。π₀.₅ 用的是四 suite 联合微调的 checkpoint。另外一个是 GR00T-N1.7，NVIDIA 的人形基础模型，它冻结视觉编码器和语言模型，只训投影层与动作头，动作同样走流匹配。区别在动作头读的是主干特征序列，不是键值缓存。两个架构的动作通路没有共享组件，这一点让下面的对照有意义。

评测都在仿真里。LIBERO-PRO 的四个 suite 是 Spatial、Object、Goal、Long，每格 500 个 episode。成功判据是 episode 终止时模拟器谓词是否成立，中途碰到过目标不算数。结果非常干净，两个架构在每一 suite 内部都是 nuisance 格高于 counterfactual 格，Swap 和 Task 最多比 ID 低 42 个百分点。

nuisance 格的分数同一水平，counterfactual 格整片塌下去，这个对比本身就是一条可检验推论。如果失败的原因是模型没看见或者指令被忽略，nuisance 格也该掉，因为换措辞换外观同样改变了像素。它没掉。

3.2 第二步，给失败行为贴标签

成功率只说哪里失败，不说失败时在干什么。论文为这一步单独设计了扰动规则，再逐条比对 rollout 与源行为、请求行为、以及其它演示任务，标注体系见原文表 8，分成七种细标签。论文明确定过一个限度，检索型这个说法指的是观测到的行为与某条演示重合，不是对内部机制的断言。Spatial 里 R1 换目标物，Object 里 R1 把目标物与场景内另一物体对调，Goal 里 R1 换动作动词，Long 里 R2 换放置终点。

结果按 suite 分得很开。Goal 上 120 条里 82.5% 是检索型，其中 44 条是执行了另一个熟悉任务，也就是说改口令改变的是它掉进哪个熟悉任务的吸引域，语言盲这种解释对不上。Long 上 87.5% 是检索型，多数是保住源任务，偶尔出现子轨迹混搭。Spatial 上 51.7%，Object 上 58.0%。标注可靠性论文给了数，117 条双重标注上，检索型这一二分类的一致率 90.6%，Cohen's κ 为 0.778。

Object 那一组探针还多做了一件事，把"选错目标"和"跟丢目标"分开。口令保持不动，把被点名的物体和占据源位置的那个物体对调，再把对调后的一方整体平移 10 厘米。九条全部去抓源位置上的那个物体，然后稳稳跟住它平移后的新位置。它跟的是被搬到源位的那个物体，而不是口令点名的那个。这个结果排除了两件事，它不是坐标写死地重放，视觉反馈也没有失效，它在选错任务的前提下把执行调得很顺。

论文还给了一条容易被忽略的对照，换目的是会掉分的。把目标物平移 10 厘米但不动命令行不行，行，27 条里 25 条正确跟随。Object Swap 那条 30 条里 25 条是重演源行为。同一类场景扰动，一个能跟，一个不能跟，分界线就是成功所需的动作有没有变。

📌 控制视角　这一步的实验设计值得单独抄下来。它用"改一件还是改两件"做出对照，测量的是任务级选择与执行级跟踪的解耦。控制里判断一个控制器是否真的在做状态反馈，也会用类似手法，保持参考不变而移动初值，看它跟不跟；保持初值不变而改参考，看它选不选对目标。两个方向各自单独测，才分得清"选错了"和"控不准"。

3.3 第三步，读出内部状态并动手改

行为标签是外部观察，论文还想知道这个错选的任务是否已经写进了动作接口。它在 π₀.₅ 上取一份状态，视觉语言专家在视觉语言前缀位置上产生的最后一层键和值张量，论文叫它 prefix-KV 表示。它不等于动作专家自己的状态，而是动作 token 生成时要去看的那份前缀缓存。把键值展平归一化之后按余弦距离排序。

(13)ϕKV(s,ℓ)=vec[K(L)(s,ℓ),V(L)(s,ℓ)]‖vec[K(L)(s,ℓ),V(L)(s,ℓ)]‖2

固定 45 条被标成 same\_to\_other 的 Goal rollout，每条都用同一个源场景配十个候选任务的口令，看被执行的那个任务在十个候选里排第几。34/45 排第一，43/45 进前三。作为对照，只用口令文本做 TF-IDF 相似度，排第一的只有 22/45。观测被固定住了，所以读出来的差异来自口令对任务选择的调制，不只是表面词的相似。

读出是相关性的，论文接着做干预。在每个策略调用点，把前缀键值缓存整份换掉，换成用目标任务初始观测和口令算出来的那一份。源场景、源口令、策略权重全部固定，控制组保留源缓存。50 对有序的 Object 任务对在评测前就枚举好了，每对四种条件。注入组 109/200 条 rollout 结束时末端更靠近目标任务的物体，控制组是 0/200。源任务完成率从 200/200 掉到零，注入组也没有任何一条真的完成了目标任务。GR00T-N1.7 上换上它动作头交叉注意的那份主干特征序列，结果是 121/200 对 0/200。

还有一步更有说服力的单次干预。观测不动，把每个候选口令的那份缓存换进去，量换完之后动作位移与哪个任务的专家轨迹更贴合。与被打补丁的那个任务自己的轨迹贴合度是余弦 0.443，与其它任务平均是 0.182，见表 17。挡住动作的是一份被冻住的初始观测缓存，不是策略本身选不动。这份缓存不随当前画面更新，所以注入能得到朝目标移动的行为，却得不到一次完整的目标任务执行。

3.4 机制，窄的条件动作支撑

把诊断接回 1.2 节那个解释，论文用一张图把动作支撑的变化画出来。在 Spatial 上，每条演示取它前十步的平均横向动作，原来的演示全部落在同一个方向的一侧，因为那个碗永远从一个方向去够。黄色的镜像反事实把同一句口令放到另一侧，散布也变宽了。

这张图解释了为什么"多来点同类演示"不管用。图里同一行的蓝点再加一百个，还是挤在同一侧，查表解照样够用。要让它不够用，得让同一行的点在两侧都有，而且场景要能告诉它该走哪一侧。

论文还有一个反例，价值不低于正例。Object 上的第一个构造是前后镜像。镜像确实改变了所需动作，但主要地标在图像里仍落在相近的位置，两个分支在外观上分不开。这一版在分 suite 诊断里 ID 从 94.2% 掉到 23.8%，Object 格从 84.4% 掉到 25.4%。

改场景还不够，场景得让人分得出该走哪一支。这条判据后来变成了构造算子的取舍标准，见原文表 19 的对照。前后镜像 ID 23.8%、全镜像 29.0%，两者都保不住原有能力；y 向镜像 93.2%、x 镜像加 x 平移 97.4%、xy 镜像加 xy 平移 95.6%，ID 和 Object 都守住。最终 Object 的 ECT 数据正好用后三种，把全镜像那一版舍掉了，尽管它在表里的 Swap 是最高的一版。这个取舍说明论文选的是不破坏既有能力的构造。

3.5 造替代，五元组

ECT 的核心对象是一个五元组。

(5)e=(ℓ,s,s′,a,a′),(s,ℓ,a) 与 (s′,ℓ,a′) 都是合法演示

要求有两条，一是场景变了之后同一口令下的正确动作也变了，二是两个观测足以分辨该走哪一个分支。在 LIBERO 上，第二个演示由第一个变换加重放得到。

(6)(s′,ℓ,a′)=𝒯ECT(s,ℓ,a),s′=Ms(s),a′=Replays′(Ma(a))

Ms 改场景几何，Ma 变换对应的末端路径，重放控制器在变换后的场景里执行这条路径并把实际达到的位移记成动作。之所以要重放而不能直接搬动作指令，是因为机械臂底座没有被镜像，同样的末端点在镜像场景里要靠另一套关节构型到达。论文量过这件事，在 Spatial 的 y 镜像对上，旋转和夹爪通道与反射后的指令逐帧相等，平移通道的中位差约 0.1（动作刻度在 [−1,1]）。所以动作有效指的是这份动作在变换后的场景里确实能完成任务，由任务成功来检验。它不等于动作的对称像，ECT 也不构成对动作的等变约束。

这句话把 ECT 和等变策略彻底分开了，也说明了为什么用"重放成功"当过滤器是必要的。变换族的选择在训练前定死，不按评测 rollout 微调。

论文还核对了一件容易出问题的事，ECT 的构造和 LIBERO-PRO 的评测格是不是撞了。构造的输入是训练演示，评测的输入是评测时改写的 BDDL 描述，两者不同源。布局距离上，Swap 状态到变换后布局的最小距离是 6.4 厘米，而 ID 参考尺度最大只有 1.7 厘米，没有任何一个 Swap 状态落进这个尺度内，见表 21。

3.6 配对训练，同一次更新里放对照

数据补齐之后，训练还有第二种做法。把配对池记作 ℰ，配对损失就是把一对反事实的两条模仿损失加在同一次更新里。

(7)ℒECT(θ)=𝔼e~ℰ[Lθ(s,ℓ,a)+Lθ(s′,ℓ,a′)]

Lθ 还是原来的逐样本模仿损失，所以 ECT 没有引入新的辅助目标。论文特意把"补了数据"和"改了组法"分开评测，对照是同样的样本池，一路独立采样，一路按对采样，更新里的示例数都是 64，配对那一版由 32 对填满。在 π₀.₅ 的实现里，一对样本还共享流匹配的噪声采样与流时间。

被优化的量仍然是参数 θ，初值是 π₀.₅ 的基座权重，驱动它的是流匹配那条速度残差 ‖vθ(at,t∣s,ℓ)−(a−a0)‖22，兜底的约束是每个样本自己的标准模仿损失，配对只改变同一次更新里谁和谁一起出现。

这节要你记住的是，先补同口令异动作的演示，再让配对进同一次更新。

数据那一路解释了绝大部分 Swap 增量，配对损失再补 2 到 5 个点。表 3 把两层分开，同样是 Frozen-LM、匹配步数与批大小、64 个示例每次更新、三个种子的均值。ECT 数据对标准训练的增量为 Spatial +19.4、Object +32.8、Goal +10.5、Long +16.8。配对损失在数据基础上再补 Spatial +2.3、Goal +3.7、Long +5.2，Object 上是 −0.3。Object 的 Swap 全靠数据那一路。

有两个方向的证据说明这不是"演示越多越好"。一是数据量扫描，固定 30k 步，把原始演示从 25% 加到 100%，Swap 和 Task 每一格都还至少比 ID 低 34.6 个百分点，Long 的 Swap 在 15% 上下几乎不动，见表 25。二是 RL 后训练，在模仿之后接一段 π_RL 的 PPO。这段 RL 的奖励只覆盖训练指令和场景，但它可以采新轨迹。40 个 PPO epoch 之后，Standard 在每个 Swap 和 Task 格上仍在自己初值 4 个点以内，两个 ECT 模型依旧领先，见表 26。ECT 的优势在 RL 之后还在。

再往外走两层。CALVIN ABC→D 上，原始演示里本来就存在同口令不同场景的对照，所以只用配对损失、不造数据也能拿到提升，五连完成率 LH-5 从 57.6% 到 75.6%，平均链长从 3.63 到 4.28。造数据那一版反而是 65.7%，配对那一版最好。这是全文最干净的一个结论，因为它的监督不需要任何构造。

真机 UR5e 那一组要在固定预算下读。三个模型都从同一个 π₀.₅ 基座出发，都用 400 条演示。Standard 是每个物体 100 条、单一布局；两个 ECT 模型是每个物体每个布局 25 条、四个布局。观测是固定场景相机加腕部相机两路 RGB，动作连续，成功判据是物体最终进箱子，示教靠手把手引导。结果里 nuisance 格基本不动，ID 40/40、换措辞 19/20、换外观 9/10；counterfactual 格变化很大，未见位置从 3/40 到 30/40 再到 35/40，未见物体加未见过位置从 0/10 到 8/10，Swap 从 4/20 到 20/20。同一组里还有一个对照，把标准模型的单布局数据翻四倍，未见位置仍然是 1/50 对 3/50 那个量级，加数据没动这一格。

还有一面得说清楚，ECT 不是处处占优。在 Frozen-LM 配方下，Spatial 的 Task 格 ECT 只有 22.1，官方全量微调的 π₀.₅ 是 53.0，差了 30 个百分点，差就差在语言模型有没有一起训。任务级指令跟随这条路上，把语言模型一起训的配方更强，ECT 改不了这件事，表 23 里 Full FT 的 ECT 也只把 Spatial Task 从 53.0 动到 53.2。跨架构那一段更明显，GR00T-N1.7 的 per-suite ECT 在 Object Swap 上是 0.0 对官方的 0.0，完全没有改善，Spatial 的 ID 还掉了 6.6 个点；论文自己说明 per-suite 模型只训了官方配方约十三分之一的样本，这个对照对官方有利。四 suite 联合训练的 GR00T ECT 才把 Spatial Swap 拉起来，从 1.2 到 38.2。

还有一条选择性，读起来比总分更有信息量。Spatial 的三个子规则里，换目的地那一组 R3，官方策略在 30 条里有 29 条完成了原来的放置，ECT 模型只有 3 条，见表 14。换成换物体名那一组 R1，两个策略都还是去拿同一个黑碗。原因是训练数据里目的地在各处出现过，但每一句 Spatial 口令点的都是同一个碗，数据里没有任何东西要求它去读那个物体名词。ECT 改善的是数据里出现过的区分，造不出数据里没有的区分。

这节要你记住的是，把对照放进监督里才有效，堆同类数据无效。

五、局限

论文在附录 K 里自己列了这些。

换场景仍然补不满。 Swap 和 Task 在 ECT 之后每一个 suite 上仍然低于 ID，差距见原文表 23。也就是说 ECT 缩小了缺口，没有填平它。

绑定是对任务选择的描述，不是某个唯一的检索算法。 论文明确写了 binding 刻画的是任务选择这一层，读出的 KV 表示只是这一次实现用到的一份状态，不能当成模型内部真在查表。

配对的收益不一致，机制也还没说清。 在 π₀.₅ 上配对采样器同时改变了三件事，一对样本有没有同现、原始与反事实样本的比例、以及两半共享流匹配噪声与时间。所以 Δloss 度量的是这几样东西合起来的效果，它到底是靠什么起作用的，论文说仍然是开放的。Object 上 −0.3 就是这个不一致的体现。

统计口径的参差。 π₀.₅ 主方法和 Frozen-LM 对照用了三个训练种子，CALVIN 和另外几组对比只有一个种子。rollout 的置信区间不含训练带来的波动。官方 checkpoint 不是匹配重训的对照，GR00T 的四 suite 模型改变了训练范围。数据量扫描只覆盖四倍范围，而且固定在同一个步数上。

ECT 的适用前提。 它要求存在动作有效且场景相关的替代演示。论文测的是构造出来的、天然存在的、以及真机采到的三种配对，都在任务级微调之后。没有微调的通用模型、接触丰富的操作、移动操作和导航都没测。

编者补充的几条

下面这三条论文没有把它们写进附录 K 的清单，是本文读下来自己看到的，标注清楚以免和上面的清单混淆。

诊断只覆盖了两个架构，而且都走流匹配。 论文的机制解释依赖式 (10) 那个条件期望，两边的解释力都建立在流匹配上。Diffusion Policy 这条线同样用生成式动作头，只是把动作生成写成条件去噪，路径和流匹配的直线插值不同；在这类动作头上窄支撑会不会同样放行查表解，论文未将其列为局限，也没有测。

干预实验的注入项不来自实时画面。 持续干预把前缀缓存换成目标任务初始观测算出来的那一份，这个缓存不随执行中的画面更新。论文自己指出了这一点，也据此说明为什么注入组能朝目标移动却完不成目标。把这条当因果证据时要记住，它证明的是这份状态能影响动作选择，不是策略在正常运行时也这样用状态。论文未将其列为局限。

真机每格的样本量偏小。 UR5e 上每格十次试验，Swap 那格还有一行分母只有 14。这些数字方向一致、幅度很大，作为存在性证据够用，作为精细比较不够。论文未将其列为局限。

这节要你记住的是，缺口被缩小没被填平，配对的机制仍开放。

六、我的评价

做得最好的地方是 3.1 和 3.2 那两步诊断，把判据留给别人复用，比再多刷几个 benchmark 有用。式 (4) 那两个示性量很朴素，但一旦立起来，很多工作里"鲁棒性 92%"这种数字立刻要重新读。Object 那组"对调加平移"的探针同理，它用一个不变的口令把选目标和跟目标分开，这是设计出来的对照，不是碰巧发现的。

第二个做对的地方是那个失败的反例。前后镜像在分 suite 诊断里把 ID 从 94.2% 打到 23.8%，论文没有把它藏起来，反而拿它当判据，推出"场景必须能分辨该走哪一支"，再用它筛掉全镜像那几个谱系。把负结果写成判据，比写成脚注有用。表 19 那六个构造并排放在一起，读者能自己看出取舍逻辑。

第三个做对的地方是 CALVIN 那一组。原始演示里已经有同口令不同场景的对照，所以配对损失单独就能拿到提升，这一组的监督不依赖任何构造，是全文最不容易被质疑的证据。

存疑的地方有四处。

一是 Δloss 的分寸。配对采样器同时改了三样东西，论文也承认这一点，可是正文和摘要里"配对损失再加 2 到 5 个点"这个说法读起来像是有一个干净的机制。2 到 5 个点相对于三个种子的标准差（Long 上 4.9 个点）并不宽裕，Object 上还是负的。要坐实配对本身的价值，需要一个只改配对、不改比例也不共享噪声的消融，论文没有做。

二是 Frozen-LM 与官方 checkpoint 混着比。表 2 里官方 π₀.₅ 是 Full FT，ECT 里最强的一行是 Frozen-LM，两侧的行为习惯不同。论文在说明里写清楚了，也补了表 28 的配对增量，但读者容易把 74.4 对 46.6 直接当成一个方法对一个方法的胜负。真要比，应该都拿 Full FT 那一行比，那时 Spatial Swap 是 72.8 对 46.6，涨幅小一点，结论不变。

三是 Task 格的迁移解释。Goal Task 从 20.6 涨到 35.7，涨得不少，而 ECT 的数据里没有改口令的构造。论文给出的说法是补了场景相关分支之后顺手学会了一点按口令分。这个解释合理也可能对，但和 CAG 那种"推理端加强语言条件"的解释在观测上不容易分开，论文没有做拆解实验。

四是数据量扫描的步数固定。从 25% 到 100% 演示、步数固定在 30k，样本少的时候模型可能还没训到收敛，这样"加数据没用"的结论会被欠训练污染。论文另外补了四倍数据的真机对照，那个更有说服力。

论文想走去的地方我读出来是这样。它没有想赢某个成功率榜，而是想把"反事实评估"变成 VLA 评测的常规一格，再把"补同口令异动作的对照"变成一条常规训练配方。如果这两件事被社区接住，它比一个更高的 Swap 数字有价值。

这节要你记住的是，值得学的是判据设计，存疑的是配对机制。

七、可以接着做什么

读完这篇，我顺手想了几个方向。都只是读完之后的即时联想，没有实验也没有查证，给正在找题的人当线索。

1. 把式 (4) 那两个判据做成通用的体检脚本

Δk 和 Δa 是可以从评测集定义里算出来的，不需要跑模型。任何一句扰动样本，都能先判断它属于哪个格，再去看模型在格内的表现。把式 (4) 那两个判据接到现有评测上，得到的是四格的分项分，不再是一个平均分。要做的事情里面，判据的自动化标注是主要工作量，模型那边不用改。

2. 做一个只改配对、不改别的的消融

现在配对采样器同时动了同现、比例和噪声共享。可以把三样拆开，分别控制。如果收益主要来自噪声共享，那 ECT 的机制解释就得重写，它会变成一个正则化技巧而不是监督结构问题。这个实验很便宜，三个种子、四个 suite 就够下判断。

3. 把配对从"同一次更新"推广到显式对比项

式 (7) 只把两条模仿损失相加，没有用到"这两条的动作应当不同"这个信息。Teney 那类工作用过反事实输入之间的差来监督梯度方向。可以试一个显式的分离项，要求同口令下两个观测预测出的动作分布互相远离，至少在任务相关的通道上远离。风险是可训性，分离项太强会把正常的变化也一起推开。

4. 给配对采样器加一个比例控制器

原始样本和反事实样本的配比现在是个超参。可以让它随训练动态调，比如当反事实那一支的损失长期低于原始支时加大原始支的权重。这相当于把数据配比当成一个调度问题来做，控制里的人会很自然想到这个动作。

5. 把构造算子推到接触密集的任务上

现在的构造是镜像加平移加重放，成立的前提是变换后的路径还能被同一个重放控制器执行成功。插孔、拧螺丝这类任务里，几毫米的位姿偏差就会让重放失败，过滤器会把大部分样本筛掉。可以试试在仿真里用带力反馈的重放，或者只在任务相关的自由度上做变换。

6. 用条件动作支撑的覆盖率当数据采集的在线指标

ECT 的逻辑是"同一口令下需要不同动作的场景都要有样本"。这句话可以直接变成一个采集指标。跑任务的时候在线估计当前场景属于哪个口令下的哪个分支，如果某个分支长期没有新样本，就主动去采。这就把数据引擎从"多采"改成"按缺口采"，和控制里按可辨识性设计激励是同一个思路。

这节要你记住的是，缺的是同口令下的动作对照，不是更多演示。

上面六条都是读完文章之后的即时联想，我没有做实验，也没有查证过是否已经有人在做，更没有验证过可行性。只当选题线索看，不要当结论用。

OpenVLA把预训练视觉语言模型直接微调成自回归策略的开源工作，动作被写成离散 token；本文两个模型都是连续动作生成，配对训练作用在连续动作上
RT-2把网络规模的视觉语言知识迁移到机器人控制的工作，动作同样落在文本 token 空间
Diffusion Policy用扩散去噪生成动作序列的视觉运动策略，同样属于生成式动作头，但插值路径与流匹配不同
RoCoDA用因果重采样加 SE(3) 变换造演示的数据增广工作，单任务设定，保存变换后成功的子轨迹；ECT 借它的变换与重放，但目标是补同一口令下的动作分支
MimicGen从人类演示批量生成新场景轨迹的数据生成系统，目标是覆盖度而不是条件动作支撑
CAST固定观测、同时改口令和动作的对照构造；ECT 方向相反，固定口令、改场景和所需动作
CAGCounterfactual Action Guidance，在推理时加强语言条件的干预方法，不动训练数据也改不了训练监督
等变策略把对称性写进网络结构的做法，动作天生随场景变换，代价是架构要改
π_RL在模仿之后加一段在线 PPO 的微调流程，奖励只覆盖训练指令和场景，但可以采新轨迹
动作有效变换后的演示在变换后的场景里确实能完成任务，由任务成功来检验，不是动作的对称像
IDin-distribution，原始分布上的成功率，用来确认模型没忘掉训练任务
Cohen's κ两名标注者一致程度的指标，扣掉了随机一致的部分
underspecification欠定，多个解法在训练数据上表现一样好，训练指标挑不出该用哪个
