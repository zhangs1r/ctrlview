# L1 · SLAM 与状态估计

> 搭配 `L0-精读契约.md` 使用。栏目 id：`slam`

## 定位

控制背景读者的强项区，术语迁移成本最低。他们熟悉卡尔曼滤波、可观性、一致性，**不需要科普什么叫状态估计**，但需要知道这批新论文把哪些东西重新想了一遍。

## 必读项（缺一项就算没讲完）

1. **状态量怎么选**。状态向量里有什么、为什么是这些、有没有被刻意排除的量。
2. **可观性的账**。哪个量在什么运动条件下解不出来，论文是靠分析还是靠拒绝来处理。
3. **初始化**。谁给尺度、谁给重力、初值从哪来。SLAM 论文的成败经常就卡在这。
4. **漂移与回环**。漂移怎么建模、回环/回访约束什么时候被允许进入优化。
5. **评价口径**。ATE 是有尺度还是无尺度对齐、成功率怎么定义、和哪些基线在同等条件下比较。

## 可压缩项

- 主干网络的层次结构（除非它就是贡献本身）
- 数据集的常规介绍（EuRoC / KITTI / TUM 的细节不用铺开）
- 与前作在工程实现上的微小差异

## 类比库（按贴合度排序）

- **级联滤波 vs 联合状态估计** —— 讲"级联还是端到端"
- **可观性分析** —— 讲"秩不够，加传感器也没用"
- **新息协方差门限 / 卡方检验** —— 讲各种"约束要不要采纳"的门控
- **一致性** —— 讲估计器是不是过于自信
- **信息互补 / 零空间错开** —— 讲多传感器融合值不值得做
- **持续激励** —— 讲退化运动下能不能主动设计激励

## 这个栏目的论文通常长这样

系统架构图 → 前端（特征/深度）→ 后端（滤波或优化）→ 数据集表格（ATE / RPE / 地图精度）。

读的时候优先抓**"为什么这样切分模块"**和**"误差从哪来"**，架构细节可以略。

## 选文偏好（每周挑 3 篇时用）

优先给这样的：

- 讲清了某个**设计判断的来龙去脉**的，而不是只报指标的
- 涉及**退化/失败场景分析**的
- 对**经典方法有明确继承或对立关系**的（好做机制对比）

压后处理：纯刷分、只换主干、增量式工程改进、纯数据集论文。
