# L1 · 控制与优化

> 搭配 `L0-精读契约.md` 使用。栏目 id：`control`

## 定位

把熟悉的方法接到机器人前沿。读者**就是干这个的**，所以这一栏最忌讳写教科书内容——他们不需要被解释什么叫 MPC、什么叫凸优化。

## 必读项

1. **优化问题的完整形式**。决策变量、目标函数、约束，一个都不能省。这是这一栏的骨架。
2. **为什么不能直接解**。非凸？规模太大？信息不全？实时性不够？
3. **松弛或近似在哪一步**。近似掉了什么、代价是什么、有没有理论保证。
4. **可行性、稳定性、收敛性**。给了哪一条，用什么条件换来的。
5. **和经典方法的对应**。它退化到某个经典形式时会变成什么，这一步最能帮读者定位。

## 可压缩项

- 标准算法的推导（ADMM、SQP、内点法这些不用重讲）
- 一般性的背景综述
- 仿真环境的常规描述

## 类比库

- 这一栏**尽量少用类比**，读者不需要。真要用，用**退化到经典形式**的方式定位，比比喻有效得多。
- 需要解释新概念时，优先用"和某个熟悉的量对应"而不是"就像生活中的某件事"。

## 这个栏目的论文通常长这样

问题形式化 → 算法 → 理论结果（定理/引理）→ 仿真对比 → 有时有真机。

优先抓**问题形式化和松弛步骤**，定理的证明细节可以只讲条件和结论。

## 选文偏好

优先：给了完整问题形式的、有可行性或收敛性讨论的、能把新方法定位到经典方法谱系里的。

压后：纯应用调参、只在仿真里比基线、理论结果和实现严重脱节的。
