# L1 · 自动化

> 搭配 `L0-精读契约.md` 使用。栏目 id：`automation`

## 定位

工业与产线落地，量偏小。这一栏的论文经常**方法不新但集成很难**，所以精读的重点要从"方法怎么想出来的"挪到"为什么在产线上可行"。

## 必读项

1. **产线环节**。任务在制造流程的哪一步、上下游是什么。
2. **节拍与良率**。这两项是工业场景的硬约束，比论文里的精度指标更能决定成败。
3. **与现有系统的接口**。怎么接 PLC、怎么和老设备共存、改造量多大。
4. **停机成本与安全**。出错了会怎样、有没有人工兜底。
5. **训练数据的获取成本**。产线数据往往稀缺且标注昂贵，这一点要说清。

## 可压缩项

- 通用的工业 4.0 背景叙述
- 与本文无关的机械设计细节

## 类比库

- **节拍 = 采样周期** —— 讲实时性约束怎么决定方法选型
- **良率 = 稳态误差 + 方差** —— 讲工业指标的统计性质
- **标定与在线自适应** —— 讲产线换型时哪些量要重标
- **故障安全** —— 讲为什么工业系统要求失效时进入安全状态

## 这个栏目的论文通常长这样

产线照片或示意图 → 集成方案 → 方法 → 现场数据（节拍、良率、停机时间）。

优先抓**集成方案和现场数据**，方法部分如果是现成的可以压缩。

## 选文偏好

优先：有真实产线数据的、把集成成本和改造量讲清楚的、讨论了换型或异常的。

压后：实验室里的理想工况、没有节拍数据、把现成方法在一条产线上跑一遍就发文的。
