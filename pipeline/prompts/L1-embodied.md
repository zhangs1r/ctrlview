# L1 · 具身智能与 VLA

> 搭配 `L0-精读契约.md` 使用。栏目 id：`embodied`

## 定位

AI 与控制的交汇点。读者懂控制但**不熟悉深度学习和数据驱动的范式**，最容易在"这东西怎么算是学会了"上卡住。精读的主要任务是把学习型系统的假设讲透。

## 必读项

1. **任务怎么定义的**。观测空间是什么、动作空间是什么、一个 episode 什么时候算成功。
2. **数据从哪来**。真机遥操作 / 人类视频 / 仿真 / 合成，各占多少。数据规模是这类论文的核心变量，不是背景。
3. **策略表示**。输出的是动作、动作块还是轨迹。有没有高层规划器。
4. **闭环在哪**。是开环执行还是边看边调，出错之后怎么恢复。
5. **真机还是仿真**。仿真成功率要单独标注，别和真机混着说。

## 可压缩项

- Transformer 的注意力实现细节
- 预训练超参
- 具体机器人型号的外观描述

## 类比库

- **策略 = 控制器** —— 讲清楚"策略"在控制语境里是什么
- **模仿学习 = 示教编程** —— 但要说清泛化和分布偏移的区别
- **端到端 = 直接反馈控制** —— 讲 VLA 为什么把感知决策执行合成一个函数
- **数据引擎 = 系统辨识的数据需求** —— 讲为什么这类工作要求海量数据
- **分布偏移 / 协变量漂移** —— 讲"训练时没见过的情况怎么办"

## 这个栏目的论文通常长这样

任务示意图 → 数据构成 → 模型结构 → 仿真成功率表 → 真机实验视频截图 → 失败案例分析。

优先抓**数据构成**和**失败案例**，模型结构可以略。

## 选文偏好

优先：有真机验证的、把失败模式讲清楚的、数据管线本身有方法贡献的。

压后：只在仿真里刷成功率、模型规模军备竞赛、没有动作空间定义的纯表征学习。
