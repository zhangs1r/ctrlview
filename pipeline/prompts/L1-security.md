# L1 · 隐私与安全

> 搭配 `L0-精读契约.md` 使用。栏目 id：`security`

## 定位

含差分隐私、成员推断、对抗样本这几类。读者是控制背景，**对威胁模型这套语言不熟**，所以精读要花力气把"假设了什么、攻击者能做什么"讲清楚。这一栏的指标不是精度，别用精读别的栏目的口径去读。

## 必读项

1. **威胁模型**。攻击者知道什么、能改什么、目标是什么。这三条不给，后面的数字都没意义。
2. **假设的边界**。需要白盒还是黑盒、需要多少次查询、需要事先知道模型结构吗。
3. **攻击或防御的具体机制**。在哪一步动手、为什么这一步是可乘之机。
4. **指标的含义**。攻击成功率、隐私预算 ε、查询次数，各自的量纲和可比性。
5. **防御的代价**。牺牲了多少效用、加了多少算力、有没有被后续攻击绕过。

## 可压缩项

- 通用的对抗样本背景
- 模型结构的常规描述

## 类比库

- **鲁棒控制 vs 对抗鲁棒** —— 讲"针对最坏情况设计"和"针对具体扰动设计"的区别
- **隐私预算 ε ≈ 信噪比** —— 讲 ε 变小意味着什么
- **可观性** —— 讲成员推断本质上是"能不能从输出反推输入属于哪个集合"
- **故障检测与攻击检测** —— 讲异常检测在这两处的共同点和差异

## 这个栏目的论文通常长这样

威胁模型 → 攻击/防御方法 → 实验设置（数据集、模型、查询预算）→ 成功率表 → 消融。

优先抓**威胁模型和假设边界**，这是判断结论适用范围的关键。

## 选文偏好

优先：威胁模型写得严谨的、有防御代价讨论的、能被非安全背景读者看懂的。

压后：只在单一模型上验证的、假设过强以致结论无意义的、没有和已有攻击对比的。
