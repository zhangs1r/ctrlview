## 它想干什么

一块刚过回流炉的板子摆在检测工位上。模型要判断上面有没有缺陷，如果有，是开路还是桥连。绝大多数样本它闭着眼都能答对，剩下那一小撮里，几类的证据咬得很紧，答错就是一次误报或者一次漏检。

这两种错的代价不一样。误报要把一批板子拦下来复查，漏检可能让缺陷件流到病人身上。多报几次，产线的节拍和返修工位先受不了；漏掉一次，代价落在使用者那边。

这篇论文做的是给模型加一个出口。它在分类器的输出层多挂一个单元，让模型有资格说"这一件我拿不准"，把决定推给下游的人或者另一道自动检查。论文在医疗器械制造这个场景里把这件事做齐，从理论到合成基准到真实的 FDA 报告数据都给了一遍。

机制本身不复杂。训练时给正确预测的收益乘一个价，记作 k。选对类别，收益按 k 倍算；改选弃权档，收益按一倍算。k 高的时候模型倾向于硬猜，k 低的时候倾向于闭嘴。

==值得看的是定理 3.2，它把 k 的三段区间划死了。== k 小于 1，最优解是把全部概率压在弃权档上，这时候整套东西退化成一个人工全检流程。k 大于类别数 C，弃权档在最优解里恒为零，模型退回普通的后验输出。只有夹在中间那一段，弃权与预测才会同时出现。论文在合成基准上的消融把 k 一路扫到 4 以上，精度曲线在那里出现平台和陡降，拐点离 C = 3 不远。

__代价乘子 k 是一个价，它决定模型押类别还是押闭嘴。__

真实数据一侧用的是 FDA 的 MAUDE 器械不良事件报告，26.6 万条。论文测到的口径是，把覆盖率压到 **90%**，也就是弃权掉一成样本，分类错误相对下降 **47.93%**。更激进的弃权到大约 70% 覆盖率，论文称保留样本上的精度接近满分。

落到制造场景，塞进产线的那部分证据是合成数据。论文复现了 Shenoy 与 Ameri 的表面贴装缺陷基准，三类任务（无缺陷、开路、桥连），特征取六个工艺量，包括环境相对湿度、环境温度、锡膏黏度、钢网厚度、液相线以上时间和峰值回流温度。在这个任务上以同样的目标覆盖率弃权，错误相对下降 **62.65%**。

这节要你记住的是，模型多了一个可以闭嘴的出口，出口大小由一个价控制。

## 一、问题背景

### 1.1 误差顺着根因链往下传

论文盯住的是多级级联里的第一级。上游那篇工作搭了一个三头串行的多层感知机，第一个头判缺陷有没有、是哪种，第二个头认机理，第三个头估参数级风险。第一级判错，后面两级的输入就建立在错误事实上，报出来的根因排序再漂亮也没有意义。

第一级恰恰是最难判的那一级。缺陷本身在样本里就稀少，几类缺陷的边缘分布又互相重叠，边界附近的样本谁看都悬。

麻烦来自模型对自己没数。论文引的分类里，一类是数据本身的随机性，同一批工艺参数下缺陷时有时无；另一类是模型没见过足够多同类样本带来的认识不确定性。合起来的结果是，模型输出的那串概率在边界样本上并不能反映它真有多虚。论文引用的工作里有人提过，级联架构对第二种不确定性很敏感。

传统的缺陷检测方法对付不了这个场景还有更直接的原因。基于规则的判定写到规程里就不再变化，遇上纹理背景、小目标缺陷和域漂移就漏，[2] 那篇做手术器械无监督检测的工作在综述里把这几条列成了医疗器械领域的特有困难。

### 1.2 前人两条路各缺一块

围绕着"知道自己什么时候会错"，前人走过两条路。

一条路是把不确定性装进网络结构里。SelectiveNet 在骨干网络后面挂一个置信头，用一个专门的损失逼它预测自己会不会错，弃权是训练出来的。Fisch 那篇校准选择性分类走的是同类思路，用扰动过的训练数据让弃权判据更稳。这两种做法都要改训练流程，代价是调参面变大，收益是判据和任务贴合得紧。

另一条路完全不碰模型。DOCTOR 那篇用信息论的量去算一个样本该不该被信，输入只是模型的输出分布，模型本身一行代码都不用改。这条路省事，对过度自信的模型效果会打折，[31] 那篇校准问题的经典工作已经把神经网络的过度自信讲清楚了。

第三种走法是论文采用的。它来自 Deep Gamblers 那篇用组合理论学弃权的工作，把弃权做成网络的第 C+1 个输出，训练目标和分类任务写在同一个损失函数里。论文接着往下做的是理论。==定理 3.1 给出了弃权阈值在最优解上的表达式，定理 3.2 划出了代价乘子 k 的有效区间 1 < k < C==，包括两个端点上的退化情形。论文原话说，这样做能给出选择 k 的指导，而不是把 k 当玄学超参调。

### 1.3 产线上的两条岔路

论文里能落地的部分有且只有一段合成基准。这套装置在制造流程里对应的位置很清楚，回流焊接后的在线检测工位，输入是焊膏印刷与回流段的工艺量，输出是这块板子算不算缺陷件。上游是印刷机和回流炉，下游是返修、报废或者 AOI 复判。

论文真实数据那一半不在这条线上。MAUDE 是上市后的被动上报系统，报的是已经卖出去的器械出的事，报表上带的是器械标识、事件类型和叙述文本。这一段对应的工序是上市后监督与召回评估，处置方式是排队等人工审。

两级对时延和出错的容忍度完全不同。在线检测工位跟着产线节拍走，单板判定必须在节拍内出结果；上市后监督是批处理队列，一条报告压几天没人管也不影响病人。论文把弃权机制放在同一套框架里讲了两级，这一点后面谈落地的时候要分开算。

这节要你记住的是，能落地的那半是回流后的在线检测，另一半是上市后的报告分诊。

## 三、方法拆解

### 3.1 先把问题写成一次多类分类

论文把第一级的任务写成多类分类。特征空间记作 $\mathcal{X}$，标签空间 $\mathcal{Y} = \{1, \dots, C\}$，训练集记作 $\mathcal{D}_n$，里面是 n 个独立同分布的样本对。分类器要逼近的是贝叶斯判据

$$f^{\star}(\mathbf{x}) \triangleq \operatorname*{argmax}_{y \in \mathcal{Y}} P_{Y|X}(y \mid \mathbf{x}) \tag{a}$$

符号逐个说。$\mathbf{x}$ 是一个样本的特征向量，在合成基准里就是那六个工艺量。$C$ 是类别数，合成基准取 3，MAUDE 报告任务取 4。$P_{Y|X}(y \mid \mathbf{x})$ 是真实但未知的类别后验，也就是知道全部工艺条件的情况下这个样本属于第 y 类的概率。$P_{\widehat{Y}|X}$ 是模型估出来的那一份，通常就是 softmax 的输出。上标带星号的 $f^{\star}$ 是理论上的最优判据，模型能逼近它但不能达到。

平时的训练把经验交叉熵压到最小

$$\mathcal{L}_{\mathrm{CE}}(\mathcal{D}_n) = - \frac{1}{n} \sum_{i=1}^{n} \sum_{j=1}^{C} P_{Y|X}(y_j \mid \mathbf{x}_i) \log P_{\widehat{Y}|X}(y_j \mid \mathbf{x}_i; \mathcal{D}_n) \tag{b}$$

这一项的作用是逼模型给正确类别压上高概率。写成这样是为了后面替换方便，训练时真实后验用独热向量代替，求和退化成一个对数项。

### 3.2 加一个弃权档，把收益乘上一个价

论文改的就是上面这个目标里的那一项。原来每个样本的似然项是 $\sum_j p_j \log \widehat{p}_j$，改完之后变成

$$W_r(p, \widehat{p}) = \sum_{j=1}^{C} p_j \log\left(k \cdot \widehat{p}_j + \widehat{p}_{C+1}\right) \tag{c}$$

$\widehat{p}_j$ 是模型给第 j 类压上的概率，$\widehat{p}_{C+1}$ 是新加的第 C+1 个输出，论文叫它预留变量，读出来就是模型这一刻的自认不确定度。$p_j$ 是真实后验的第 j 个分量。$k$ 是一个正实数，论文叫它代价乘子。约束和普通概率一样

$$\sum_{j=1}^{C} \widehat{p}_j + \widehat{p}_{C+1} = 1, \qquad \widehat{p}_j \geq 0 \ \ \forall j \in \{1, \dots, C+1\} \tag{d}$$

k 的作用在这条式子里看得清楚。选对类别时，模型拿到的收益是 $\log(k \widehat{p}_j + \widehat{p}_{C+1})$，k 越大，把概率挪给类别档越划算。全押弃权档时 $k \cdot 0 + 1$ 取对数得零。k 大到某个程度，押类别的期望收益再也追不上弃权档的零，模型就彻底不弃权了。

### 3.3 最优解长什么样

定理 3.1 说，在弃权档的最优取值严格大于零的前提下，每个类别档的最优解可以写成

$$\widehat{p}_i^{\star} = \max\left\{\frac{p_i}{\lambda} - \frac{\widehat{p}_{C+1}^{\star}}{k}, 0\right\}, \qquad i \in \{1, \dots, C\} \tag{e}$$

$p_i$ 是第 i 类的真实后验，$\lambda$ 是等式约束对应的拉格朗日乘子，在最优解上严格大于零。$\widehat{p}_{C+1}^{\star}$ 是弃权档在最优解上的取值，$k$ 就是上面那个价。

两个符号先解释清楚。拉格朗日乘子在这里的角色是配额，$\lambda$ 越大，整个右端项被压得越小，可用的概率总量越紧。$\widehat{p}_{C+1}^{\star}/k$ 这一项是门槛，真实后验低于 $\lambda$ 倍这个门槛的类别，算出来的坐标是负数，被 max 截到零，论文说这些类别在最优解上失活。

这条式子的读法值得停一下。==门槛项随弃权档的取值上升而抬高，随价 k 上升而降低==。__模型自认越不确定，它能接受的类别就越少；价给得越高，它愿意接受的类别就越多。__论文把这解释成弃权输出本身就是一种自适应的不确定度度量。

### 3.4 自由度账本

这套问题的未知量和约束可以数清楚。模型的输出向量一共 C+1 个坐标，就是 C 个类别概率加一个弃权档。约束有两条，一条来自式 (4) 的归一化等式，一条来自实数域上的非负性，后者在最优解上以互补松弛的形式生效。未知数减去独立的等式约束，剩下的自由维度是

$$(C+1) - 1 = C$$

求解所需的观测来自真实后验 p，它一次提供 C 个分量，且因概率归一而只剩 C 个独立取值。所以从自由维度看，这条问题的观测与未知数刚好齐平，不需要额外的观测源，也不存在最小样本数一类的要求。它是一次逐样本的凸优化，不是需要堆观测才能定解的状态估计问题。

要小心的是秩的问题出在别处。约束集合是概率单纯形，论文的引理 1.1 说它凸、闭、有界，引理 1.2 说目标函数在这个集合上凹，于是问题有全局最优解，这就是凸优化教科书里那套存在性论证。极端取值上自由度会塌掉，那是 3.5 小节讲的退化情形。

### 3.5 价 k 的三个区间

定理 3.2 把 k 分了三段，每一段的最优解形状都不同。

<figcaption><b>示意图 C</b>　横轴为价 k 的取值，纵轴无物理量。黑色实心点为合成基准消融扫到的位置，空心点为扫描上限。（编者绘制）</figcaption>
</figure>

第一段是 $k < 1$。论文的证明思路是先证任意可行解上目标函数不超过零，再指出全弃权的那个解恰好取到零。完整句式在式 (12) 的记号下写作，对任意可行解和任意类别 j 都有

$$k \widehat{p}_j + \widehat{p}_{C+1} \leq \widehat{p}_j + \widehat{p}_{C+1} \leq 1$$

右边的不等号来自归一化，左边来自 k 小于 1。取对数之后整个目标函数非正，而把概率全压在弃权档上恰好让它等于零。这一段的最优解就是把每个样本都推给人工。

第二段是 $k > C$。论文用反证法，假设最优解里弃权档严格大于零，经过一串推导会得到 k 不超过 C，与假设矛盾；剩下的一种情形会逼出活跃类别数等于 k，而 k 已经超过类别总数。结论是弃权档在最优解上恒为零，目标函数退回

$$W_r(p, \widehat{p}) = \log(k) + \sum_{j=1}^{C} p_j \log \widehat{p}_j$$

把它最大化等于最大化右边的求和项，按吉布斯不等式，解就是 $\widehat{p}_j^{\star} = p_j$。模型老老实实输出后验，弃权机制等于没有。

第三段是 $1 < k < C$，论文说这是最有意思的一段，弃权与预测同时出现。两端的取值 $k = 1$ 和 $k = C$ 是退化点。论文各给了一个例子，k 等于 1 时后验集中在一个类别上，任何让类别档与弃权档之和等于 1 的分配都是最优；k 等于 C 时后验均匀分布，对任意 $\alpha \in [0,1]$，把 $\alpha$ 放在弃权档、剩下的均匀摊给 C 个类别，目标值都是零。

### 3.6 训练与推理的具体装置

训练就是把式 (1) 换成式 (3)。合成实验用的是上游架构的第一个头，两个隐藏层各 256 个神经元，ReLU 激活，dropout 取 0.1，Adam 优化器，学习率 $10^{-3}$，批大小 128，最多 40 轮，早停耐心 6 轮。

真实数据实验的网络小一号，两个隐藏层分别是 256 与 128 个神经元，Adam 的学习率同样是 $10^{-3}$，权重衰减 $10^{-4}$，批大小 32，最多 80 轮，早停耐心 10 轮。文本特征用 TF-IDF 表示，最多 5 万个一元与二元特征。论文给的理由是可扩展、可解释，并且不依赖预训练语言模型。

推理规则短。一次前向得到 C+1 个输出，最大的类别概率超过弃权档概率就接受这个判定，否则拒收。论文在玩具例子上写的是"最大类别概率超过弃权档概率"这条判据，真实数据实验里的弃权量由目标覆盖率控制。

被优化的量的三件套可以交代一下。初值来自随机初始化的网络权重与 Adam 的默认状态。驱动它的残差是式 (3) 里对数似然项对参数的梯度，训练时真实后验换成独热标签。兜底的是式 (4) 那条归一化等式加上非负约束，它们把解限制在概率单纯形里。

这节要你记住的是，价的三个区间决定弃权机制开还是关。

## 四、结果

第一个基准来自上游工作，三类任务，六个工艺量特征。论文说原始基准数据没有公开，它是照原文的描述复现的，复现之后用同样规模的感知机核对了性能量级。

## 五、局限

论文自己承认的局限有四条，逐条列在下面。

1. 真实基准稀缺。论文的原话是当前缺少同时刻画制造缺陷与检测不确定性的真实基准，跨器械、跨缺陷类型、跨制造环境的更广评估仍然必要。
2. 数据源是自发上报系统。MAUDE 的报告量反映的是上报行为、器械使用量和法规要求，不是确认的失效发生率。叙述文本完整程度差别很大，还可能包含重复。论文明确要求不要把结果读成器械失效率的估计。
3. 任务性质被限定。论文把这套基准的定位写成"带真实标签噪声的报告级严重度分类"，并说明在这个条件下认识不确定性本来就会偏大，弃权也就相应地更有价值。
4. 近似重复与切分方式。论文说已经按叙述文本完全相同去掉了重复，但 MAUDE 里还有同一事件的近似重复报告，来源可能是厂商与使用机构各报一次。随机切分有可能把这类报告同时放进训练侧与测试侧。论文把近似重复检测与按时间切分列为更接近部署条件的自然延伸。

以下三条是编者补充的，论文未将其列为局限。

合成数据与真实数据之间的桥没有搭完。论文在真实数据上做的是报告文本分诊，在合成数据上做的是工艺量缺陷判定，两件事的输入端完全不同。==论文没有给出任何一组"同一套工艺量、既有合成也有真实标签"的对照==，所以弃权机制在产线检测工位上的实际收益仍然靠推断，没有实测。

节拍一项在论文里没有出现。论文没有报告推理耗时、没有报告产线节拍，也没有报告人工复核一个弃权件要花多久。真实数据那一侧的弃权比例是按覆盖率目标设定的，不是按人力预算设定的。

价 k 的选取仍然靠试。定理 3.2 给的是允许区间 $1 < k < C$，这个区间在四分类任务上是宽度 3 的一段，论文的消融显示区间内部精度差异不大，但论文没有给出从错误代价与人工成本反解 k 的公式。

这节要你记住的是，论文承认的是基准稀缺，编者担心的是产线收益没被直接测过。

## 六、我的评价

先说做得对的地方。这篇论文最扎实的一步是把弃权这件事从"调个阈值"变成"解一个带约束的优化问题"，然后把最优解的形状完整写出来。定理 3.1 给出的表达式里，门槛项同时含弃权档与价 k，模型自认越虚、价给得越低，被截到零的类别就越多。这个耦合关系是能拿去做工程判断的，比给一个固定阈值可靠。

定理 3.2 是这篇里唯一一处可以直接指导选参的结果。它把 k 的有效区间钉在 1 与 C 之间，两端分别是全弃权与不弃权。论文的两次消融都在类别数附近出现转折，方向一致。合成基准的类别数是 3，转折出现在 k 约 2.2；真实任务的类别数是 4，转折出现在 k 约 3.75。第一次的差值是 0.8 左右，第二次是 0.25 左右，两次都落在有效区间内侧，这个系统性偏差论文没有解释。

存疑的地方有三块。

第一块是理论结果与实验口径对不上。定理 3.1 的推导前提是弃权档在最优解上严格大于零，这是一个关于最优解的表述，而论文的实验是拿梯度下降训练一个有限宽度的网络，训到早停就停。论文没有讨论训练解与定理最优解的差距，也没有给出任何一个样本上实际算出来的阈值与式 (6) 预测值的对照。

第二块是同一个量挂着三个名字。玩具例子的那一节把超参写成"预留奖励 r = 2"，定理与正文叫它代价乘子 k，而图 5 与图 7 的横轴标注又是"payoff k"。这三个名字是不是同一个量，论文没有交代。如果 r 与 k 是同一个量，那么取 2 恰好落在三分类任务的退化点附近，最优解不唯一，玩具图上那条弃权带因此不能读成有唯一性的东西。

第三块是数据侧的对照组缺位。真实数据实验里，无弃权基线是同一个网络的普通版本，公平性是够的。缺的是另一类对照，把弃权交给一个不依赖模型结构的后处理判据会怎样。论文的文献综述里提到过这类做法对过度自信模型的局限，实验里没有做这件事的对照。

它想走去哪，论文最后一段说得很清楚。作者希望这项工作能推动更大、更多样的基准出现，并让弃权决策接上下游的根因分析、风险评估与人工复核。这个方向对产线是有意义的，因为人工复核这条支路的容量是有限的，而论文目前只给出了弃权量的比例，没有给出复核工作量的分布。

**这节要你记住的是**，定理给的是最优解，实验训的是早停网络，两者之间论文没搭桥。

## 七、可以接着做什么

论文缺一个节拍数字，这是一块可以直接补的空白。把弃权模型的推理耗时与产线节拍放在一起量，再测人工复核一个弃权件需要多久，就能把弃权比例的收益换算成每小时的复核件数。这条线索的入手点是给覆盖率目标加一条人力预算约束，让 k 由这个预算反解出来。

再往下可以做近似重复报告的时间切分。论文自己把这条列为延伸，做法是把同源厂商与使用机构的报告按时间归到同一侧，再看弃权机制的性能是否还成立。这条能检验的是一件具体的事，看模型学的是缺陷模式还是报告者的措辞习惯。

第三块可以把弃权接到第二级和第三级上。论文只改了第一级，第二级认机理、第三级估风险都还在原设定上跑。如果第一级的弃权信号能往下游传，那么"第一级拿不准"可以变成"机理排序里少给几条候选"，复核的人拿到的东西会更有指向性。这件事要做的话，接口处至少要定义清楚弃权信息以什么形式进入第二级的条件输入。

※ 以上三条是即时联想，没有实验，没有查证，只当线索。

| 退化 | 最优解不唯一的情形，出现在 k 等于 1 与 k 等于 C 两处 |
| 贝叶斯判据 | 在已知真实后验的条件下错误率最低的判定规则 |
| 交叉熵 | 衡量两个概率分布差距的常用损失，训练分类器的默认目标 |
| 独热标签 | 只有一个位置为 1 的向量，用来表示样本的真实类别 |
| KKT 条件 | 带约束优化问题里最优解要满足的一组条件，用来推出解的表达式 |
| 拉格朗日乘子 λ | 等式约束对应的乘子，在式 (6) 里起配额的作用 |
| 互补松弛 | 最优解上约束与其乘子不能同时为正，用来区分类别档是否失活 |
| 概率单纯形 | 各分量非负且和为 1 的向量集合，也就是所有合法概率分布 |
| 凹函数 | 曲线朝下的函数，在凸集合上最大化它不会掉进局部陷阱 |
| 吉布斯不等式 | 说两个概率分布之间的交叉熵不小于熵的定理，用来定出最优解 |
| 贝叶斯误差 | 最优判据也避免不了的那部分错误，是任务难度的下界 |
| 知识图谱 | 用实体与关系组成的数据组织方式，这里用来整合器械与报告 |

| MAUDE | FDA 的器械不良事件上报库，被动上报，不是失效率的统计源 |
| 510(k) | 器械上市前通告，与 MAUDE 通过器械标识连接 |
| 表面贴装 | 把元件焊到板面上的工艺，回流焊是其中一环 |
| 桥连与开路 | 两种典型焊接缺陷，前者是相邻焊点被锡连上，后者是该通的没通 |
