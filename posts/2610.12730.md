## 它想干什么

攻击者先摸清电网的量测结构，再解一个约束，让假数据满足坏数据检测的门槛。假数据一旦混进状态估计，发电机的调频回路就照着错的频率偏差动作。这套手法在电力系统里被研究了很多年，防御方一直没有便宜好用的解法。

ROAM 换了个思路，它不去改电网，也不去加固量测值，而是把传感器到逻辑编号的那张对照表做成在线变量。每隔一个决策周期，相量数据集中器把一部分相量测量单元的编号重新洗一遍，控制中心按同一张表还原。攻击者按旧编号算出来的注入向量，落到还原后的流里就站错了位置。

洗牌本身不难。难的是洗多少、洗哪些、还原走哪条路。论文把这三件事写成一个动作 $a_t = (d_t, \mathbf{c}_t, \rho_t)$，其中 $d_t$ 是参与洗牌的测量单元百分比，$\mathbf{c}_t$ 是逐传感器的二值标志向量，$\rho_t$ 是这些被洗过的传感器里走种子还原的百分比。剩下那部分走另一条路，用一个离线训好的机器学习模型预测期望量测，再用混合整数规划把收到的乱序数据配回原位。

这个混合是全文最实在的地方。纯种子的路子恢复快，一次不到 2 ms，但它把安全性押在一把预共享密钥上。密钥一旦泄露，还原出来的编号是错的，注入数据反而被对齐到攻击者原本想要的位置。论文在 IEEE 14 母线上量到，20% 欺骗水平加种子泄露，隐身穿透率上升到 **46.19%**，比完全不设防的 **30.63%** 还差。纯机器学习的路子没有共享秘密，代价是恢复耗时涨到大约 **90 ms**。按 IEEE C37.118 的帧率，注入必须在一个帧内完成，这个时延已经出界。两条路各自都有一个会致命的失效模式。

ROAM 让每个被选中的传感器单独决定走哪条路。种子泄露只影响走种子的那一部分，走预测的那部分不含密钥。作者把 60% 种子加 40% 机器学习的固定配比拎出来做过对照实验。它在五个欺骗档位里的四档上隐身穿透率低于纯机器学习，全欺骗档位上两份分别是 **1.27%** 和 **1.96%**，同时恢复耗时从 **90.86 ms** 压到 **17.99 ms**。这个配比是对照实验里定死的，实际部署时由深度 Q 网络按当时的检测结果在线选。

控制这份灵活性的是一张奖赏表。检测率上升给正分，欺骗开销、处理时延、攻击准确度各按权重扣分，攻击准确度指注入仍然落在原本瞄准的那台传感器上的比例。这套反馈让策略能对活威胁做反应，而不是按固定日程换编号。

==真正决定成败的一环是恢复通道的时延预算，洗牌覆盖率排在它后面==。论文在 57 母线系统上量到一个反直觉的结果，深度 Q 网络把更多攻击推离了目标，状态估计偏差却比另一套策略高出接近一倍。

**这节要你记住的是，防御靠不停改动攻击者看到的空间布局，不靠更好的检测器。**

## 一、问题背景

### 1.1 物理对象和信息层的介入点

被保护的是一套三层结构的广域测量与控制链路。最底下是同步相量测量单元，装在变电站里，按 IEEE C37.118 的帧率输出母线电压相量与线路电流相量，每秒 30 到 60 帧，折合 16.7 到 33.3 ms 一帧。中间是相量数据集中器，把多台测量单元的帧按时间戳对齐，再往上传。最上面是能量管理系统的服务器，它跑状态估计和坏数据检测，然后把发电机设定点通过自动发电控制回路发下去。

信息层的介入点在这个链条的第二层。编号重映射发生在相量数据集中器上，代价为零的硬件改动，测量单元的固件、接口和报文格式都不动。这也是论文反复强调 IEEE C37.118 兼容的原因，防御不需要换设备。

物理后果落在最后一层。虚假数据注入的目标是让自动发电控制回路读到错误的频率偏差。论文把注入的速率限制写成两条约束式，

$$- \tau_{\omega}^{b} \le \left(\omega^{b}[t+1] + \tilde{\omega}^{b}[t+1]\right) - \left(\omega^{b}[t] + \tilde{\omega}^{b}[t]\right) \le \tau_{\omega}^{b}, \quad \forall b \in \mathcal{B}^{GV}\tag{4}$$

$$- \tau_{P}^{b} \le \left(P^{b}[t+1] + \tilde{P}^{b}[t+1]\right) - \left(P^{b}[t] + \tilde{P}^{b}[t]\right) \le \tau_{P}^{b}, \quad \forall b \in \mathcal{B}^{GV}\tag{5}$$

$\omega^{b}[t]$ 和 $P^{b}[t]$ 是母线 $b$ 在时刻 $t$ 的真实频率与有功功率，带波浪号的量是攻击造成的偏移，$\tau_{\omega}^{b}$ 和 $\tau_{P}^{b}$ 是系统给出的速率上限，集合 $\mathcal{B}^{GV}$ 是装有机组调速器的母线。这两条式子的意思是攻击者不能一步把系统推垮，只能分几步慢慢拱。这个缓慢给了防御方一个响应窗口。

时间尺度上有两个数值得同时记住。帧间隔是 16.7 到 33.3 ms，这是恢复必须完成的硬上限；决策周期在仿真里按步走，在硬件在环实验里配成 3000 ms。==恢复在帧内，决策在秒级，两件事不在一个时间尺度上==，这一点决定了后面为什么要把恢复通道劈成两条。

### 1.2 为什么难

难点在恢复。攻击者要想让注入躲过坏数据检测，他的注入向量得满足检测器用的那套约束，而约束是相对当前帧的量测写的。注入于是有了三个必须同时满足的前置条件，同一帧内、真实量测还原之后、坏数据检测之前，位置还得对。恢复快慢直接决定防御的可行性，它是一道硬门槛而不是工程细节。

纯种子方法恢复只要 1.5 ms 上下，帧预算绰绰有余。代价是它的安全性来自共享秘密。相量数据集中器与控制中心之间有一套硬件随机数发生器产生的时变种子，走的是 AES-256-GCM over TLS 1.3 的认证加密通道，种子分发不成功超过 $\Delta_{\mathrm{sync}} = 50$ ms 时集中器会在带外信道重传。这个根信任一旦被攻破，还原用的函数 $f^{-1}(\cdot, s_t)$ 就是错的。

论文在 1.1 节给出的部分泄露模型写成一条加权式，

$$AA_{\text{partial}} = \frac{k}{N} \cdot AA_{\text{full}} + \left(1 - \frac{k}{N}\right) \cdot AA_{\text{displaced}}\tag{1}$$

$k$ 是被攻击者拿到的种子数量，$N$ 是种子总数，$AA_{\text{full}}$ 是无防御时的攻击准确度，$AA_{\text{displaced}}$ 是被完全错位之后的残余准确度。这条路子在低欺骗水平下不只是失效，它会变成负资产。错位的还原把攻击者的注入重新对齐到他原本瞄准的母线上，攻击准确度不降反升。用这条式子解释不了为什么低欺骗更危险，那个现象是实验量出来的，论文在第 IV-A 节专门讨论。

纯机器学习方法换掉了共享秘密。它离线在历史状态轨迹上训四个模型，XGBoost、随机森林、LSTM 和 GRU，训练集按 80/20 的时间顺序切分，谁在留出集上的均方误差最小谁上。树模型和序列模型的机制差别在输入形态，前者只吃手工构造的五块特征，后者直接吃原始状态序列并自带时序记忆。运行时它先预测下一时刻的状态，再用状态算出期望量测向量，最后把收到的乱序量测和期望量测做一对一匹配，用的求解器是 OR-Tools 的 CBC。这条路的恢复耗时在满欺骗下是 90.86 ms，比种子方法高大约 60 倍。

### 1.3 前人两条路各自缺什么

种子路线的代表是 DDAF，它在传感器层用密码学安全的伪随机发生器改传感器编号，恢复快、开销低，缺的是它对预共享密钥和同步状态的依赖。论文把它列为单点失效，也承认密钥泄露和失步是这类方法的固有弱点。

预测路线的代表是 iDDAF，它用历史数据和威胁模式学出映射关系，把共享秘密去掉了，能适应变化的攻击。缺的是组合匹配那一步的开销，实际测量是恢复时延涨了约 60 倍，在资源受限的部署里精度也会掉。

论文对这两族还有一条共同的批评。它们都把随机化策略固定在设计阶段或按日程预先排定，于是三个操作层面的问题一直悬着，洗多少传感器、优先洗哪些、什么时候从轻量的洗牌升级到重的预测恢复。这三个问题正是 ROAM 的动作空间的三个分量。==动作空间的设计在这里是实现层面的回应，它直接对着前人留下的三个空缺==。

第三条相关路线是把移动目标防御写成博弈。Lakshminarayana 等人 [20] 用双层规划求最优的拓扑扰动策略，另一类做法 [31], [32] 用量测雅可比矩阵的谱性质刻画防御效果。这些做法要显式求解均衡，且难以把实时威胁证据接进去。ROAM 的做法是直接从系统反馈里学策略，不做均衡计算，也不用手工设计的图特征。

**这节要你记住的是，恢复时延和根信任是两条互相排斥的路，选一条就继承它的失效模式。**

## 三、方法拆解

### 3.1 状态估计这一环做了什么，为什么用恒等过程模型

控制中心要还原编号，先得有一份对当前状态的判断。ROAM 用的是扩展卡尔曼滤波，状态维数等于母线数的两倍，每根母线贡献一个电压幅值和一个电压相角，$n = 2|\mathcal{B}|$。三个测试系统的维数分别是 28、114 和 236。量测方程写成

$$\mathbf{z}_{t} = \left|\mathbf{H}\mathbf{x}_{t}\right| + \boldsymbol{\epsilon}_{t}, \quad \boldsymbol{\epsilon}_{t} \sim \mathcal{N}(\mathbf{0}, \mathbf{R}), \quad \mathbf{R} = 0.01\mathbf{I}_{m}\tag{2}$$

$\mathbf{z}_t \in \mathbb{R}^m$ 是集中器对齐后的量测向量，$m$ 是量测条数，三个系统分别是 55、218 和 491。$\mathbf{x}_t \in \mathbb{R}^n$ 是母线状态向量。$\mathbf{H} \in \mathbb{R}^{m \times n}$ 是网络拓扑决定的量测雅可比矩阵。$\mathbf{I}_m$ 是 $m$ 阶单位阵，噪声协方差取 $0.01$ 倍单位阵，也就是量测噪声方差为 $10^{-2}$。绝对值号让量测方程变成非线性的，扩展卡尔曼滤波在 $\hat{\mathbf{x}}_t^{-}$ 附近做线性化。==三个测试系统的状态维数是 28、114、236，量测条数是 55、218、491，这两组数在后面每个结果里都要用==。

过程模型是恒等的，

$$\hat{\mathbf{x}}_{t}^{-} = \hat{\mathbf{x}}_{t-1}, \qquad \mathbf{P}_{t}^{-} = \mathbf{P}_{t-1} + \mathbf{Q}, \qquad \mathbf{Q} = 10^{-3}\mathbf{I}_{n}\tag{3}$$

先验状态直接等于上一时刻的估计，先验协方差在上一时刻的基础上加一个过程噪声协方差，标量 $10^{-3}$ 是分给每个状态分量的均匀过程噪声方差。滤波器初始化用 $\hat{\mathbf{x}}_0 = \mathbf{0}_n$ 和 $\mathbf{P}_0 = 0.1\mathbf{I}_n$。

恒等过程模型是个有意的选择，理由来自相量流水线的时间分辨率。帧率每秒 30 到 60 帧，相邻帧之间的状态变化相对量测噪声底很小。论文给出的实测数字是，正常工况下相邻帧的归一化状态变化小于 **0.8%**，模拟 $N-1$ 故障时仍低于 **3.1%**，预测残差落在阈值里。改用摇摆方程那类物理过程模型能在暂态里提高预测精度，代价是要在线辨识发电机惯性常数，等于多开一个攻击面。作者把物理信息化的过程模型留给了未来工作。

模型的失配在这里是被主动利用的，恒等过程模型把误差压到量测噪声以下，省掉了参数辨识这条路。

### 3.2 编号洗牌，从种子到报文

设物理编号集合是 $\mathcal{ID} = \{ID_1, \ldots, ID_N\}$。时变种子 $s_t$ 由硬件随机数发生器产生，只分发给集中器和控制中心，走预先建好的安全信道。集中器用一个确定性的双射函数把编号换掉，

$$ID_{i}^{\prime} = f(ID_{i}, s_{t}), \quad \forall i \in \{1, \ldots, N\}\tag{7}$$

$ID_i$ 是第 $i$ 台传感器的物理编号，$ID_i'$ 是它这一步的临时编号，$f$ 是洗牌函数。一个洗牌周期内这个映射是无碰撞的置换。集中器自己留一张对照表，

$$\mathcal{M}_{t} = \left\{\left(ID_{i}, ID_{i}^{\prime}\right) \colon ID_{i}^{\prime} = f\left(ID_{i}, s_{t}\right), \forall i \right\}\tag{8}$$

发出去的数据流保持量测值和时标不变，只换编号，

$$\mathcal{D}_{t}^{\mathrm{tx}} = \left\{\left(ID_{i}^{\prime}, m_{i}, t_{i}\right) \colon \left(ID_{i}, m_{i}, t_{i}\right) \in \mathcal{D}_{t}^{\mathrm{rx}} \right\}\tag{9}$$

$\mathcal{D}_t^{\mathrm{rx}}$ 是集中器收到的原始三元组集合，$m_i$ 是第 $i$ 台的量测值，$t_i$ 是时标，$\mathcal{D}_t^{\mathrm{tx}}$ 是换过编号之后发出去的那一份。控制中心收到之后做逆映射，

$$ID_{i} = f^{-1}(ID_{i}^{\prime}, s_{t}), \quad \forall ID_{i}^{\prime} \in \mathcal{D}_{t}^{\mathrm{tx}}\tag{10}$$

$f^{-1}$ 是 $f$ 在同一个种子下的逆函数。种子每步都变，攻击者从截获的历史报文里推不出未来的映射。

### 3.3 机器学习通道，从特征向量到指派问题

种子不可用时，或者深度 Q 网络主动选了这条路，恢复走预测。四个候选模型吃的东西不一样。树模型吃的是一个手工特征向量 $\phi_t \in \mathbb{R}^{5F}$，

$$\phi_{t} = \left[ \mathbf{x}_{t-1} \parallel \bar{\mathbf{x}} \parallel \sigma_{\mathbf{x}} \parallel \mathbf{x}_{t-1} - \mathbf{x}_{t-T} \parallel \mathbf{x}_{t-1} - \mathbf{x}_{t-2} \right]\tag{11}$$

五块依次是上一时刻的状态、窗口均值 $\bar{\mathbf{x}}$、窗口标准差 $\sigma_{\mathbf{x}}$、长时趋势 $\mathbf{x}_{t-1} - \mathbf{x}_{t-T}$ 和瞬时变化率 $\mathbf{x}_{t-1} - \mathbf{x}_{t-2}$，$\parallel$ 是拼接，$F$ 是每个时刻的特征数，$T$ 是回看窗口长度。序列模型不吃这套手工特征，直接把原始归一化序列 $\mathbf{X}_{t-T \colon t}$ 喂进去。

四个模型各自独立训练，数据按时间顺序 80/20 切分，损失是均方误差 $\mathcal{L} = \frac{1}{N}\sum_t \|\mathbf{x}_t - \hat{\mathbf{x}}_t^{-}\|^2$，优化器用 Adam。选谁上岗由一个离线一次性完成的比较决定，

$$\mathcal{M}^{*} = \arg \min_{\mathcal{M}_{k} \in \{\mathrm{XGB}, \mathrm{RF}, \mathrm{LSTM}, \mathrm{GRU}\}} \frac{1}{|\mathcal{T}_{\text{test}}|} \sum_{t \in \mathcal{T}_{\text{test}}} \left\| \mathbf{x}_{t} - \hat{\mathbf{x}}_{t}^{(k)} \right\|^{2}\tag{12}$$

$\mathcal{T}_{\text{test}}$ 是留出测试集，$\hat{\mathbf{x}}_t^{(k)}$ 是第 $k$ 个模型的预测。赢了的那一个存下来部署。表 2 是四个模型的配置，树模型 200 棵和 100 棵，深度 6 和 10，序列模型都是 64 到 32 的两层结构、dropout 0.2、Adam 学习率 $10^{-3}$、训 20 轮。

| 模型 | 输入 | 关键超参数 | 损失 |
|---|---|---|---|
| XGBoost | $\phi_t$ | 200 棵树，深度 6，学习率 0.1，子采样 0.8 | 均方误差 |
| 随机森林 | $\phi_t$ | 100 棵树，深度 10 | 均方误差 |
| LSTM | $\mathbf{X}_{t-T \colon t}$ | [64→32]，Dropout 0.2，Adam $10^{-3}$，20 轮 | 均方误差 |
| GRU | $\mathbf{X}_{t-T \colon t}$ | [64→32]，Dropout 0.2，Adam $10^{-3}$，20 轮 | 均方误差 |

得到期望量测 $\tilde{\mathbf{z}}_t = |\mathbf{H}\hat{\mathbf{x}}_t^{-}|$ 之后，把收到的乱序量测配回原位变成一个二值指派问题。$M_{ij} \in \{0,1\}$ 表示第 $j$ 条乱序量测被指到第 $i$ 个预测位置，代价矩阵的每一项是 $c_{ij} = |\tilde{z}_i - z_{\mathrm{shuf},j}|$，也就是预测值和实收值的绝对差。约束是行、列各不超过 1，超出邻近距离阈值的不可能配对在求解之前就被压掉。这个混合整数规划交给 OR-Tools 的 CBC 求解器 [38]，解出来的置换 $\pi^{*}$ 把数据摆正，$\hat{\mathbf{z}}_t = \mathbf{z}_{\mathrm{shuf}}[\pi^{*}]$，再送进扩展卡尔曼滤波的预测步和后面的坏数据检测。

### 3.4 混合恢复，怎么把两条路拼起来

深度 Q 网络给出种子比例 $\rho_t$ 之后，两个支路的份额直接换算成 $(r_{\mathrm{seed}}, r_{\mathrm{ml}}) = (\rho_t/100, 1 - \rho_t/100)$。被选中的传感器集合 $\mathcal{C}_t = \{i \colon c_t^{(i)} = 1\}$ 按这个份额劈成两个不相交的子集，

$$|\mathcal{C}_{t}^{\mathrm{seed}}| = \left\lfloor r_{\mathrm{seed}} \cdot |\mathcal{C}_{t}| \right\rfloor, \qquad \mathcal{C}_{t}^{\mathrm{ml}} = \mathcal{C}_{t} \setminus \mathcal{C}_{t}^{\mathrm{seed}}\tag{13}$$

$\lfloor \cdot \rfloor$ 是向下取整，符号 $\setminus$ 是集合差。走种子的那一份用 3.2 的洗牌逆映射还原，走预测的那一份用 3.3 的指派问题还原。两组还原结果和没被洗过的固定传感器集合 $\mathcal{F}_t$ 合并成一条量测向量，

$$\mathbf{z}_{\mathrm{rem}}(t) = \mathbf{z}_{\mathrm{seed}}(t)\big|_{\mathcal{C}_{t}^{\mathrm{seed}}} \cup \mathbf{z}_{\mathrm{ml}}(t)\big|_{\mathcal{C}_{t}^{\mathrm{ml}}} \cup \mathbf{z}(t)\big|_{\mathcal{F}_{t}}\tag{14}$$

竖线加下标表示取子集，$\cup$ 是按编号对齐之后的拼接。如果坏数据检测确认这条向量保住了可观性，它直接进状态估计。否则控制中心退到一条加权混合，

$$\mathbf{z}_{\mathrm{fin}}(t) = \alpha \mathbf{z}_{\mathrm{rem}}(t) + (1 - \alpha)\tilde{\mathbf{z}}(t), \qquad \alpha \in [0, 1]\tag{15}$$

$\tilde{\mathbf{z}}(t)$ 是模型预测出来的期望量测，$\alpha$ 是可观性满足时取 1 的权重，被标记的传感器占比越大它越往 0 掉。这条兜底保证了极端情况下状态估计不断流。

__走种子的那部分传感器依赖的是同一把种子，走预测的那部分完全不含共享秘密__。混合的价值就落在这一条差别上，种子出问题的时候波及面被这批走预测的传感器卡住。==编号一旦被洗过，攻击者预先算好的注入向量就落不到他瞄准的母线上，剩下的问题只是控制中心能不能在一帧之内把编号还原回来==。

### 3.5 决策过程，三个分量和一张奖赏表

防御问题写成离散时间的马尔可夫决策过程 $\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{T}, \mathcal{R}, \gamma \rangle$。状态是扩展卡尔曼滤波估计出来的归一化状态窗口 $\mathbf{s}_t = \mathbf{X}_t \in \mathbb{R}^{T \times F}$，回看长度取 $T = 10$，特征数 $F$ 随系统变，IEEE 14 母线是 13，每台非平衡母线一个。网络输入处挂一层批归一化，

$$\hat{\mathbf{X}}_{t} = \gamma_{\mathrm{bn}} \frac{\mathbf{X}_{t} - \mu_{B}}{\sqrt{\sigma_{B}^{2} + \epsilon}} + \beta_{\mathrm{bn}}\tag{16}$$

$\mu_B$ 和 $\sigma_B^2$ 是训练时的批均值和批方差，推理时换成滑动平均，$\epsilon$ 是数值稳定项，$\gamma_{\mathrm{bn}}$ 和 $\beta_{\mathrm{bn}}$ 是可学的缩放与平移参数。这层归一化让状态观测在不同运行工况和不同攻击强度下都保持在良态。

动作是三元的，

$$a_{t} = \left(d_{t}, \mathbf{c}_{t}, \rho_{t}\right), \quad d_{t} \in \{25, \ldots, 80\}, \quad \rho_{t} \in \{10, \ldots, 90\}\tag{17}$$

$d_t$ 是欺骗量，指这一步被选中洗编号的测量单元百分比。$\mathbf{c}_t$ 是逐传感器的二值标志向量，只有它决定洗哪些，并且满足计数约束 $\sum_{i=1}^{N} c_t^{(i)} = \lfloor N d_t / 100 \rfloor$。论文举的例子是 $d_t = 50$、$N = 100$ 时正好标出 50 台。$\rho_t$ 是种子比例，定下式 (13) 里的 $r_{\mathrm{seed}}$。

环境的转移写成

$$P(\mathbf{s}_{t+1} \mid \mathbf{s}_{t}, a_{t}) = P(\mathbf{X}_{t+1} \mid \mathbf{X}_{t}, d_{t}, \mathbf{c}_{t}, \rho_{t})\tag{18}$$

随机性来自攻击注入、量测噪声和当前防御配置的效果这三处。奖赏是四项的加权和，

$$r_{t} = \lambda_{3} D_{t} - \lambda_{1} C_{t}^{\mathrm{dec}} - \lambda_{2} L_{t} - \lambda_{4} A_{t}\tag{19}$$

$D_t$ 是这一步被攻击帧上的坏数据检测率，也就是后文的 CSER，给正分。$A_t$ 是攻击准确度，指重映射之后仍然落在原本瞄准的传感器上的注入比例，给负分。这两项都同时依赖状态、注入和实际发生的重映射，不是只依赖动作。欺骗代价 $C_t^{\mathrm{dec}} = d_t/100$ 罚洗牌带来的运行开销。时延项是

$$L_{t} = \frac{d_{t}}{100}\left(\frac{\rho_{t}}{100}\kappa_{1} + \left(1 - \frac{\rho_{t}}{100}\right)\kappa_{2}\right)\tag{20}$$

$\kappa_1$ 和 $\kappa_2$ 分别是种子还原和机器学习还原的单位处理代价，$\kappa_2 > \kappa_1$，对应混合整数规划那一步更贵。六个权重 $\{\lambda_1, \lambda_2, \lambda_3, \lambda_4, \kappa_1, \kappa_2\}$ 是在 IEEE 14 母线上网格搜索定的，然后固定用于所有拓扑，为了让跨系统的比较公平。论文点出影响最大的两个是 $\lambda_3$ 和 $\lambda_4$，它们一起决定安全与开销的取舍。

作者做过一次敏感性检查。把 $\lambda_3$ 和 $\lambda_4$ 各自在 $\{0.5, 1.0, 2.0, 4.0\}$ 里独立取值，16 组配置，在 IEEE 14 母线上跑 50 个留出回合。隐身穿透率的均值从 **1.8%** 到 **5.2%**，最低点在 $\lambda_3 = \lambda_4 = 4.0$，最高点在两者都取 0.5。论文的结论是策略对中等扰动稳健，检测激励被压低时会可预期地退化。作者另外提醒，改 $\lambda_1$ 或 $\lambda_2$ 会移动最优点，运营方按自己的时延预算重标这两个权重之后应该微调策略，不能直接照搬。

### 3.6 动作空间为什么不做成枚举

动作是因子化的。欺骗水平和种子比例合成 $12 \times 5 = 60$ 个离散选择，传感器子集用 $N$ 个逐传感器标志表示，不去枚举子集。论文给了一组对照，联合枚举需要 $\sum_d \binom{N}{\lfloor N d / 100 \rfloor}$ 个选择，在 $N = 19$ 时大约是 $5.2 \times 10^{5}$，而标志表示只随 $N$ 线性增长。每步的重映射和机器学习匹配开销同样随 $N$ 增长，这个代价在第 IV-A 节有测量。

$5.2 \times 10^{5}$ 这个数对 $N = 19$ 来说大得离谱，因为按 19 台传感器算，所有子集之和是 $2^{19} = 524288$。也就是说这一项实际是全部子集的并集计数，跟论文写的按 $d$ 分档求和只有在下取整取到所有值的意义上才对得上。原文照抄了这个数，读者按 19 台重算会得到同一个量级，但式子的写法不严谨。==动作空间用逐传感器标志而不是枚举子集，这是这篇能在 118 母线上跑起来的前提==。

### 3.7 深度 Q 网络，为什么选它

选深度 Q 网络的理由是动作空间的形状。$d_t$ 和 $\rho_t$ 取有限的整数百分比，传感器标志是二值的，这个空间天然离散。深度 Q 网络对每个离散动作算 Q 值，给出一个直接的、可解释的挑选机制。它用一个深度网络逼近最优动作价值函数 $Q_\theta(\mathbf{s}_t, a_t)$，贝尔曼目标写成

$$y_{t}^{\mathrm{DQN}} = r_{t} + \gamma \max_{a^{\prime}} Q_{\theta^{-}}(\mathbf{s}_{t+1}, a^{\prime})\tag{21}$$

$\theta^{-}$ 是周期性同步的目标网络参数，把自举用的目标和在线网络解耦，减少振荡。在线网络优化时序差分损失

$$\mathcal{L}(\theta) = \mathbb{E}_{(\mathbf{s}_{t}, a_{t}, r_{t}, \mathbf{s}_{t+1}) \sim \mathcal{B}} \left[ \left(y_{t}^{\mathrm{DQN}} - Q_{\theta}(\mathbf{s}_{t}, a_{t})\right)^{2} \right]\tag{22}$$

$\mathcal{B}$ 是容量 $10^5$ 的经验回放缓冲。最优防御策略按最大 Q 值取，

$$\pi_{\mathrm{DQN}}^{*}(\mathbf{s}_{t}) = \arg \max_{a_{t} \in \mathcal{A}} Q_{\theta}(\mathbf{s}_{t}, a_{t})\tag{23}$$

Q 网络是四层多层感知机，隐层取 $[256 \to 512 \to 512 \to 256]$ 的对称扩缩结构，激活用 ReLU。学习率 $5 \times 10^{-4}$，折扣因子 0.99，回放缓冲 100000 条，批大小 128。学习从 1000 步之后开始，目标网络软更新系数 0.001、硬更新间隔 1000 步，每 4 步训一次。探索率 $\epsilon$ 从 1.0 退到 0.05，探索比例 0.2，总训练步数 40000。

### 3.8 被优化的量从哪里起步，靠什么驱动，谁来兜底

这一段按同一套问题过一遍 ROAM 里出现的三个被优化量，这是判读机制完整性的关键。

策略 $\pi_{\mathrm{DQN}}^{*}$ 的初值来自网络的随机初始化，驱动它的残差是式 (22) 里的时序差分误差 $y_t^{\mathrm{DQN}} - Q_\theta(\mathbf{s}_t, a_t)$，兜底的是周期同步的目标网络 $\theta^{-}$，它把自举目标钉住。没有这个目标网络，自举目标跟着在线网络一起动，训练会振荡。

编号映射 $\pi^{*}$ 的初值来自机器学习模型预测出来的期望量测 $\tilde{\mathbf{z}}_t = |\mathbf{H}\hat{\mathbf{x}}_t^{-}|$，驱动它的是代价矩阵 $c_{ij} = |\tilde{z}_i - z_{\mathrm{shuf},j}|$，兜底的是行、列各不超过 1 的一对一约束和邻近距离阈值，这两条把不可能配对挡在求解之前。

权重 $\alpha$ 的初值取 1，也就是完全相信还原后的量测，驱动它的是坏数据检测给出的可观性判定和被标记传感器的占比，兜底的是式 (15) 里那 40% 上下的预测量测，$\alpha$ 往 0 走时状态估计靠预测值续命。

### 3.9 自适应攻击者，让对手也学

为了在静态场景池之外施压，论文把防御方和自适应攻击者的对抗写成一个竞争性马尔可夫博弈 $\mathcal{G} = \langle S, \mathcal{A}_{\mathrm{def}}, \mathcal{A}_{\mathrm{atk}}, \mathcal{T}, \mathcal{R}_{\mathrm{def}}, \mathcal{R}_{\mathrm{atk}}, \gamma \rangle$。防御方保留式 (19) 的奖赏，攻击者的奖赏与它的检测项和状态精度项反号。

攻击者用软演员评论家训练，选它的理由是熵正则化的策略目标，

$$\pi_{\mathrm{atk}}^{*} = \arg \max_{\pi} \mathbb{E}_{\pi} \left[ \sum_{t} \gamma^{t} \left(R_{\mathrm{atk}, t} + \alpha_{\text{ent}} \mathcal{H}[\pi(\cdot | \mathbf{s}_{t})]\right) \right]\tag{26}$$

$\alpha_{\text{ent}}$ 是控制探索与利用的温度参数，$\mathcal{H}$ 是策略熵。熵项压住过早收敛到单一攻击模式，逼出一个更有多样性的对手。攻击者看到的观测是同一段系统状态序列，再拼上防御方最近一次的动作 $(d_t, \rho_t)$，

$$\mathbf{o}_{\mathrm{atk}} = \left[ \operatorname{vec}\left(\mathbf{s}_{t-L+1 \colon t}\right) \parallel d_{t}/100 \parallel \rho_{t}/100 \right] \in \mathbb{R}^{L \cdot F + 2}\tag{27}$$

连续动作是一个 $2|\mathcal{Z}| + 1$ 维的向量，

$$\mathbf{a}_{\mathrm{atk}} = \left[ \boldsymbol{\ell} \in [-1, 1]^{|\mathcal{Z}|} \parallel \mathbf{m} \in [-1, 1]^{|\mathcal{Z}|} \parallel \alpha \in [-1, 1] \right]\tag{28}$$

$\boldsymbol{\ell}$ 是传感器选择 logits，$\mathbf{m}$ 是逐传感器的注入幅值参数，$\alpha$ 是全局强度标量，$|\mathcal{Z}|$ 是量测条数。这个连续动作按三步转成物理注入矩阵，第一步把 logits 过 sigmoid 得到选中概率 $p_i = \sigma(3\ell_i)$，第二步按阈值挑出前 $k$ 台

$$k = \operatorname{clip}\left(\sum_{i} \mathbf{1}[p_{i} > 0.3],\ 3,\ 30\right)\tag{30}$$

$k$ 被夹在 3 到 30 之间，$\mathbf{1}[\cdot]$ 是指示函数。第三步定注入量

$$a_{i} = m_{i} \cdot 50 \cdot \tilde{\alpha}, \quad \tilde{\alpha} = \operatorname{clip}\left(\frac{\alpha + 1}{2},\ 0.1,\ 1.0\right)\tag{31}$$

$\tilde{\alpha}$ 是把 $\alpha$ 从 $[-1,1]$ 映到 $[0.1, 1.0]$ 的全局强度，单台注入幅值落在 $[-50, +50]$ 区间。攻击者的奖赏是四项相加再乘 100，

$$R_{\mathrm{atk}} = 100 \cdot \left(2.0 \cdot \frac{\mathrm{EDR}}{100} - 1.5 \cdot \frac{\mathrm{CSER}}{100} + 1.0 \cdot \frac{\mathrm{AccAtk}}{100} - 0.3 \cdot \frac{n_{\mathrm{atk}}}{30}\right)\tag{32}$$

四项依次是状态破坏、被检出惩罚、命中目标的准确度奖励、以及稀疏性代价。$n_{\mathrm{atk}}$ 是被攻击的传感器数，除以 30 对应 $k$ 的上限。稀疏性代价压住乱撒式的多传感器攻击，逼攻击者做定点、隐蔽的注入。

对抗训练是四阶段交替的。先把标准单智能体训练出来的深度 Q 网络和 PPO 防御方冻结，权重记作 $\theta_{\mathrm{DQN}}^{*}$ 和 $\theta_{\mathrm{PPO}}^{*}$。然后让软演员评论家攻击者对着冻结的深度 Q 网络训 10000 步，得到有意义的初始攻击策略。接着两个防御方对着冻结的攻击者微调，适应对方学到的打法。最后攻击者再对着更新后的冻结深度 Q 网络重训一次，吃掉微调新引入的弱点。

### 3.10 对照用的 PPO 和它的动作空间

为了验证深度 Q 网络这个设计选择，论文配了一个 PPO 防御方，解同一个马尔可夫决策过程，形成离线值方法与在线策略梯度方法的对照。==PPO 和深度 Q 网络共用同一份观测、同一个动作空间和同一条奖赏函数，两者的差别只剩更新规则==。PPO 优化一个裁剪替代目标，

$$\mathcal{L}^{\mathrm{CLIP}}(\theta) = \mathbb{E}_{t}\left[\min\left(\rho_{t}(\theta)\hat{A}_{t}, \operatorname{clip}\left(\rho_{t}(\theta), 1 - \varepsilon_{\text{clip}}, 1 + \varepsilon_{\text{clip}}\right)\hat{A}_{t}\right)\right]\tag{24}$$

$\rho_t(\theta) = \pi_\theta(a_t|\mathbf{s}_t) / \pi_{\theta_{\mathrm{old}}}(a_t|\mathbf{s}_t)$ 是更新后策略与旧策略的概率比，$\hat{A}_t$ 是广义优势估计，$\varepsilon_{\mathrm{clip}} = 0.2$ 实现信赖域约束。完整目标再加价值损失和熵奖励，

$$\mathcal{L}^{\mathrm{PPO}}(\theta) = \mathcal{L}^{\mathrm{CLIP}} - c_{\mathrm{vf}}\mathcal{L}^{\mathrm{VF}} + c_{\mathrm{ent}}\mathcal{H}[\pi_{\theta}]\tag{25}$$

$c_{\mathrm{vf}} = 0.5$，$c_{\mathrm{ent}}$ 是熵系数，论文表 3 里取 0。广义优势估计的 $\lambda_{\mathrm{GAE}} = 0.95$。PPO 和深度 Q 网络共用观测、动作空间和奖赏，学习率 $3 \times 10^{-4}$，每次 rollout 2048 步，批大小 64，训 10 轮，策略网络是 MlpPolicy，激活用 Tanh。__两个防御方解的是同一个马尔可夫决策过程，观测、动作空间和奖赏三项完全一致__。

两个防御方解的是同一个马尔可夫决策过程，差别只在更新规则，所以后面的性能差可以归到算法本身。

**这节要你记住的是，动作三元组里只有第二个分量是逐传感器的，混合就发生在那里。**

## 四、结果

实验设置先说清楚，后面每个数字都挂在这套条件上。三个测试系统是 IEEE 14、57、118 母线，母线数与线路数分别是 14/20、57/80、118/186，量测条数分别是 55、218、491。训练用 1000 个满足坏数据检测约束的虚假数据注入场景，另留 500 个做评测，训练和评测各跑 200 和 204 个回合，深度 Q 网络训 200 回合、PPO 训 204 回合。软件是 Python 3.11 加 Stable Baselines3。评测分两层，一层是标准留出场景，一层是对着训练好的自适应攻击者。

四个指标的定义要先立住。攻击准确度 AA 是注入仍然落在原本瞄准的传感器上的比例，$\mathrm{AA} = |\mathcal{A}_{\mathrm{int}} \cap \mathcal{A}_{\mathrm{act}}| / |\mathcal{A}_{\mathrm{int}}| \times 100\%$，$\mathcal{A}_{\mathrm{int}}$ 是意图攻击目标集合，$\mathcal{A}_{\mathrm{act}}$ 是洗牌之后实际被打到的传感器集合。被攻陷传感器消除率 CSER 是实际被打到的传感器里被坏数据检测抓到的比例，$\mathrm{CSER} = |\mathcal{D}_{\mathrm{BDD}} \cap \mathcal{A}_{\mathrm{act}}| / |\mathcal{A}_{\mathrm{act}}| \times 100\%$。隐身穿透率 PSA 把攻击准确度和漏检率乘起来，

$$\mathrm{PSA} = \mathrm{AA} \times \left(1 - \frac{\mathrm{CSER}}{100}\right)$$

暴露率 PEA 是它的补数，等于 $100\% - \mathrm{PSA}$。状态估计偏差率 EDR 量的是意图目标位置上还原量测和原始量测的相对误差，

$$\mathrm{EDR} = \frac{\left\| \mathbf{z}_{\mathrm{rec}}[\mathcal{A}_{\mathrm{int}}] - \mathbf{z}_{\mathrm{org}}[\mathcal{A}_{\mathrm{int}}] \right\|}{\left\| \mathbf{z}_{\mathrm{org}}[\mathcal{A}_{\mathrm{int}}] \right\|} \times 100\%$$

$\mathbf{z}_{\mathrm{rec}}$ 是还原出来的量测向量，$\mathbf{z}_{\mathrm{org}}$ 是原始量测向量。==PSA 是这篇的主指标，它同时吃攻击准确度和检测率，单独看任何一个都会被误导==。

### 4.1 四条恢复路线的横向对照

|---|---|---|---|---|---|---|---|

这张表里最该看的是三列。PSA 那一列能看出谁把攻击挡掉了，CSER 那一列能看出谁在还原之后还留下可检出的痕迹，还原耗时那一列决定方案能不能塞进 16.7 到 33.3 ms 的帧预算。

种子路的厉害之处在检测。密钥安全时它的 PSA 在满欺骗下掉到 **0.94%**，CSER 是 84.78%，还原只要 1.53 ms，帧预算里绰绰有余。它的弱点也是同一处。密钥泄露之后 CSER 在满欺骗下崩到 **8.45%**，EDR 顶到 **100.00%**，也就是还原出来的量测和目标完全对不上。

低欺骗加密钥泄露是这张表里最反直觉的一格。20% 欺骗时 PSA 是 **46.19%**，比完全不设防的 30.63% 还高。论文给的解释是，攻击者知道泄露的种子，错的逆映射把被攻击的量测重新指派到攻击者原本瞄准的传感器位置上，集中器自己的重映射把假数据对齐到了目标。到 40% 欺骗时 PSA 是 28.97%，仍在无防御基线附近。满欺骗加密钥泄露反而只有 5.51%，因为错位本身把 93.99% 的注入推离了目标。==密钥泄露的危险集中在低欺骗区，这个结论跟「洗得越多越乱越好」的直觉相反==。

机器学习路在满欺骗下把 EDR 压到 **13.07%**，是四条路里最低的，而且对密钥泄露完全免疫，因为整条通道不含共享秘密。它的代价写在最后一列，还原 **90.86 ms**，是种子路的约 60 倍，也已经超出单帧预算。论文把这个量级差归到组合匹配那一步。

混合方案在 60% 种子加 40% 机器学习的固定配比下拿到最好的综合表现。满欺骗时 PSA 是 **1.27%**，低于纯机器学习的 1.96%，与密钥安全的纯种子方案差 0.33 个百分点；还原耗时 **17.99 ms**，比纯机器学习快大约 5 倍。论文给的原因是混合整数规划只在缩小的传感器子集上跑，搜索空间随子集平方级收缩。因为只有走种子的那 60% 依赖密钥，密钥泄露伤害不到走预测的那 40%。论文明确说，混合方案在密钥泄露下的端到端精度量化留给了未来工作。

## 五、局限

### 5.1 论文自己承认的

**过程模型是恒等的。** 作者明确写，改用线性化的摇摆方程过程模型能在暂态事件里提高状态预测精度，但需要在线辨识发电机惯性常数，那等于多开一个攻击面。他们把物理信息化的过程模型列为未来工作。

**混合方案在种子泄露下的端到端精度没有量化。** 混合策略那一段的收尾写得很直白，因为只有走种子的那 60% 依赖密钥，密钥泄露污染不到走预测的那 40%，但混合方案在泄露条件下的端到端精度留给了未来工作。

**机器学习还原在资源受限的部署里会退化。** 论文介绍预测通道时承认，组合匹配那一步让时延涨了约 60 倍，而且在资源受限的情况下精度可能下降。

**反馈闭环的实时性只在一个配置上验证过。** 硬件在环实验用的是 IEEE 118 母线、19 台测量单元、3 秒决策周期这一套配置，实机结果也只有一个会话的数字。

**对抗评测里攻击者可以恢复全映射的情形被排除在威胁模型之外。** 论文在威胁模型一节写明，能在一帧之内恢复完整映射的攻击者不在模型范围内。

### 5.2 编者补充的

下面这几条论文未将其列为局限，是我在读的时候自己起疑的地方，判断来自正文和表格的数字关系，不是原文的陈述。

**硬件在环只演示了种子里的一条路。** __第 IV-F 节的部署文字没有一处给出这次会话实际用过的还原配比，表 8 的指标全是执行时间和盲窗__。它只写了推理引擎每 3 秒给一次决策、采集进程施加种子或机器学习或混合重映射，而表 4 的还原耗时是混合方案在整篇论文里的唯一实测来源，那个数字出自仿真。混合路径在 3 秒周期、真实 TCP 流和操作系统抖动下能不能守住 17.99 ms，这篇没有回答。

**一把种子同时承担了安全和还原两个职责。** 式 (13) 的种子比例 $\rho_t$ 决定谁走种子路，而走种子路的那部分传感器用的还是同一把 $s_t$。密钥一旦泄露，受影响的正是这批被特意挑出来走快路的传感器。混合只是限制了波及面，没有把风险和路径选择解耦。

**攻击者的训练预算和防御者的微调预算不对等。** 四阶段协议里攻击者训 10000 步，防御方只做一次微调，论文没有给出防御方微调的步数、学习率或回合数。对抗评测的结论因此要连这个不对称一起读。

**评测的终点是状态估计，不是调频。** 论文开头把威胁落到自动发电控制的频率稳定性上，式 (4) 和式 (5) 也是按发电机母线的频率和有功速率限制写的。到了实验部分，主指标换成 PSA、CSER 和 EDR，全部是状态估计和检测层面的量。从估计偏差到频率偏差这一段传递，论文没有测。

**表 4 里混合方案在部分欺骗档位上的优势不稳。** 40% 欺骗时混合的 PSA 是 8.31%，比纯机器学习的 8.94% 好，但 20% 档位上混合是 11.62%，纯种子方案是 12.74%，两者的差距只有 1.12 个百分点；到 60% 档位这个差距缩到 0.68 个百分点。混合在低欺骗区的收益并不宽裕。

**式 (17) 的动作空间上界和下界没有论证。** $d_t$ 取 25 到 80，$\rho_t$ 取 10 到 90，这两个区间的边界怎么定的，论文没有交代。训练期的收敛值 73.84% 和 87.84% 都贴近上界，读者无法判断这是策略选择还是区间截断的结果。

**盲窗的度量口径可以更严。** 表 8 的盲窗是时间占比，2.6% 的均值对应约 78 ms。这段时间里集中器已经换了编号而控制中心还没提交新映射，帧流在这段窗口里处于什么状态，论文没有说明，也没有给出窗口期内坏数据检测的行为。最大执行时间 56.28 ms 超过一个相量帧的上限 33.3 ms，这个越界在单帧尺度上的后果同样没有展开。

**这节要你记住的是，论文承认的三条都在模型和评测层面，实时混合路径没验。**

## 六、我的评价

这一节是我的判断，不是论文的陈述。

### 6.1 做对的地方

判别一篇传感器加人工智能的论文值不值得细读，我通常先问它的信息层改动有没有穿过物理过程。这篇穿过了。编号重映射改的是状态估计看到的量测内容，状态估计的输出进自动发电控制回路，回路的动作落到发电机上。改动点在回路的测量环节，后果在物理侧。这一条它站得住。

第二个做对的地方是把防御动作的代价写进了奖赏。式 (19) 里检测率和攻击准确度给正负分，式 (20) 把时延按两条通道的单位代价分开计。$D_t$ 和 $A_t$ 都依赖实际发生的重映射，不是只看动作。这一点让策略没法靠一个恒定的高欺骗量刷分。

第三个做对的地方是那个反直觉结果的报告方式。种子泄露让 20% 欺骗的隐身穿透率升到 46.19%，作者没有把它藏进附录，而是放在正文里解释机制。缺陷被正面写出来，比藏起来可信。

### 6.2 存疑的地方

**主指标的口径不太直观。** PSA 等于攻击准确度乘漏检率。洗牌把攻击准确度压到 6.01% 之后，PSA 自动就低了，检测率对它的影响被这一项乘小了。看表 6 的 118 母线，PPO 的攻击准确度 13.13% 明显低于深度 Q 网络的 25.59%，PSA 于是也低，但它同时把 80% 的传感器都洗了，运行开销和盲窗风险都比对手高一截。把 PSA 当唯一主指标推荐，会低估洗牌量本身的代价。

**状态估计不是系统的终点。** 论文的威胁叙事走的是调频，评测停在状态估计。从 EDR 到频率偏差之间缺一段传递，读者只能相信这个代理指标是够用的。这是作者自己划的评测边界，代价是论文能声称的强度被这条边界框住。

**对抗评测暴露的结构性弱点没有被接住。** 57 母线上深度 Q 网络的 EDR 在对上自适应攻击者后到 57.79%，接近标准评测的两倍，论文把它写成需要集成或按拓扑选型的理由。__从工程角度看，57 母线上那一格暴露的是恢复机制在自适应压力下不成立，换选型解决不了它。__

**奖励函数的四项权重是薄弱环节。** 六个权重在 14 母线上网格搜索定下来，然后固定到 57 和 118 母线。论文自己报告了 $\lambda_3$ 与 $\lambda_4$ 从 0.5 变到 4.0 会让 PSA 均值在 1.8% 到 5.2% 之间移动，这个敏感性不小。而 57 和 118 母线上的部署期反转，很可能有一部分来自权重没有按拓扑重标。

**式 (17) 那个 $5.2 \times 10^{5}$ 的计数写法不严谨。** 按 $N = 19$ 算，全部子集之和是 $2^{19} = 524288$，和论文给的数对得上；但论文写的求和式是按 $d$ 分档再求和，只有在 $\lfloor Nd/100 \rfloor$ 覆盖所有可能取值时才成立。这一处不影响结论，属于写作上的松散。

### 6.3 它想走去哪

论文结尾列的四条方向里，最有分量的是联邦训练。多公用事业共享一套防御策略而不交换拓扑数据，这个约束和移动目标防御的部署现实是对得上的，也最难做。第二条是混合方案在种子泄露下的端到端精度量化，这条更像补一个洞，工作量不大。第三条是往含分布式资源的配电网延伸，那会碰上节点数暴涨和测量信噪比下降两个新约束。第四条是给预测模块做形式化的隐私保证。

从我读下来看，第二条和第一条之外还有一件更该做的事，把恢复机制在自适应攻击者下的失效机理讲清楚。57 母线那一格 57.79% 的 EDR 是全文里最有信息量的数字，它指向的是一段还没被解释的机制，而不是一个选型问题。

**这节要你记住的是，它把物理-信息耦合做实了，弱点在恢复环节而不是判别环节。**

## 七、可以接着做什么

**在自适应攻击者下做恢复通道的消融。** 表 7 里 57 母线的 EDR 翻倍出现在 $\rho$ 偏高的配置上。把种子比例固定成几档，只让攻击者学，能分离出到底是预测模型在该拓扑上失准，还是错位把数据推到了更难还原的位置。这个实验的成本很低，直接用论文公开的权重和场景集就能做。

**把电网的物理过程模型接回状态估计。** 论文用恒等过程模型换掉了惯性常数辨识，也在第 II-B 节承认了暂态精度上的代价。在一个已知惯性常数的测试系统上做离线对照，可以量出这个代价有多大。要是代价集中在 $N-1$ 故障那几帧，那么整条论证的适用范围就有了明确边界。

**用盲窗期内的量测篡改量重写时延指标。** 表 8 的盲窗是时间占比。把它换成窗口期内坏数据检测的检出率变化，或者换成窗口期内注入落在目标上的比例，指标会直接对应安全性，而不是对应时钟。

**把评测终点推到频率。** 在硬件在环试验台上加一个频率偏差的记录，把 EDR 和自动发电控制回路的实际响应连起来。论文的威胁模型已经把速率限制写在发电机母线上，这一步是把评测挪到同一坐标系里。

**比较按拓扑重标权重和按拓扑选型两条路线。** 论文建议集成或按拓扑选型，但没试过给 57 和 118 母线各自重标 $\lambda_3$ 与 $\lambda_4$。这两条路线的成本差很大，一次网格搜索就能看出重标能不能拿回部署期的那个反转。

**给种子路由加一条不依赖种子的兜底。** 式 (13) 里走种子的那一份完全依赖 $s_t$。可以在控制中心侧对种子路的结果做一次可观测性交叉检查，发现逆映射结果与预测值矛盾时把该传感器临时改判到预测路。改动小，直接针对 5.2 节里那条耦合。

**把动作空间的边界当实验变量。** $d_t$ 的上界取 80、$\rho_t$ 取 90，而训练收敛值贴着上界。放宽上界重训一轮，能区分策略偏好和区间截断。

※ 上面这些是即时联想，没有实验、没有查证，只当线索。

| 术语 | 一句话解释 |
|---|---|
| 相量测量单元（PMU） | 装在变电站里、按 IEEE C37.118 帧率输出母线电压和线路电流相量的测量装置。 |
| 相量数据集中器（PDC） | 把多台测量单元的帧按时间戳对齐再往上传的中间层设备，ROAM 在这里改编号。 |
| 坏数据检测（BDD） | 状态估计之后检查量测残差、判断数据是否被篡改的环节。 |
| 虚假数据注入（FDI） | 攻击者构造满足坏数据检测约束的偏移量，让状态估计偏离真值。 |
| 移动目标防御（MTD） | 不停改动系统的某项配置，让攻击者预先算好的攻击失效。 |
| 编号重映射 | ROAM 的具体手段，把物理传感器编号换成临时编号再还原。 |
| 种子 | 由硬件随机数发生器产生、只发给集中器和控制中心的随机数，决定洗牌函数。 |
| 种子比例 | 动作分量，指被洗过的传感器里走种子还原的百分比。 |
| 欺骗量 | 动作分量，指这一步被选中洗编号的传感器百分比。 |
| 扩展卡尔曼滤波（EKF） | 在非线性量测方程上做线性化的递推状态估计器。 |
| 量测雅可比矩阵 | 把母线状态映射到量测值的矩阵，由网络拓扑决定。 |
| 混合整数规划（MIP） | 含整数变量、用来把乱序量测配回原位的一对一指派问题。 |
| 指派问题 | 在代价矩阵上求一对一匹配的优化问题，约束是每行每列最多选一个。 |
| 深度 Q 网络（DQN） | 对离散动作逐个估计价值、按最大值取动作的强化学习算法。 |
| PPO | 用裁剪替代目标限制每次策略更新幅度的在线策略梯度算法。 |
| 软演员评论家（SAC） | 带熵正则项的连续动作强化学习算法，本文用它训练自适应攻击者。 |
| 经验回放缓冲 | 存放历史转移样本、供离线值方法抽样训练的容器。 |
| 广义优势估计（GAE） | 在偏差和方差之间取折中的优势函数估计方法。 |
| 隐身穿透率（PSA） | 攻击准确度乘漏检率，衡量既命中目标又没被检出的事件占比。 |
| 暴露率（PEA） | 一百减去隐身穿透率。 |
| 攻击准确度（AA） | 注入仍然落在原本瞄准的传感器上的比例。 |
| 被攻陷传感器消除率（CSER） | 实际被打到的传感器里被坏数据检测抓到的比例。 |
| 状态估计偏差率（EDR） | 意图目标位置上还原量测相对原始量测的误差。 |
| 跨层洗牌 | 允许传感器跨越层次边界互换编号，用来最大化错位。 |
| 盲窗 | 编号已经换掉而新映射还没提交的那段时间。 |
| 硬件在环（HIL） | 把真实设备接进实时仿真回路的测试方式，本文用 OPAL-RT 平台。 |
| 自动发电控制（AGC） | 按频率偏差调整发电机出力、维持系统频率的闭环控制。 |
| 可观性 | 由当前量测集合能否唯一确定系统状态的性质。 |
| 批归一化 | 在网络输入处按小批量统计量把特征缩放的层。 |
