## 它想干什么

一辆车开进无信号灯的四岔路口。横向有车过来，对方可以直行穿过，可以左转切进你的车道，也可以右转离开。三种走法要三种应对，踩早了白等，踩晚了撞上。

决策的难处有三层。对方的意图是一个离散的三选一，这是第一层。它的位置、速度、朝向是连续量，测一次带一次噪声，往前推几秒不确定范围就摊开，这是第二层。你自己也说不准自己在哪儿，主车定位同样带误差，这是第三层。三层叠起来，才够算"会不会撞"。

现成的两条路各有死法。一条把概率直接写进优化约束，要求规划出的轨迹按置信度留够净空。净空随不确定性长大，车道宽度是定值，两者一打架求解器就交不出解。另一条按最可能的走法算一条轨迹，解总归有，撞不撞看运气。前者在窄路上卡死，后者在有人突然拐弯时来不及刹。

这篇走第三条路。概率在进优化之前就被结算成一个标量，再用这个标量去切一块凸的安全区域，规划器只在这块区域里找解。区域是凸的，当前位姿又在区域里，区域内任何一点都能用一条不越界的直线连上。解存在与否因此不取决于求解器的运气。区域外面再套一层控制屏障函数，把实际下发的控制压回区域内。

==整篇的赌注押在一句判断上，安全与可行的矛盾可以在上游化解，不必留给规划器去权衡==。这话如果成立，规划器那一层就只剩一个小规模的凸二次规划。

论文在四岔路口的 100 次蒙特卡洛试验上报出 **0% 碰撞**和 **0% 求解不可行**，整条管线一拍 **12.7 ms**。两个基线分别是 36% 碰撞的确定性 MPC，与 10% 碰撞加 14.2% 不可行的机会约束 MPC。代价写在另一列，它的归一化通行时间是 **1.91**，确定性 MPC 是 **1.23**。

## 一、问题背景

### 1.1 三种不确定性，量纲各不相同

对方的意图不写在脸上。论文把意图建模成离散模式，模式集合由路网几何决定，一个可行机动一个模式。四岔路口取直行、左转、右转三个，记作 $\mathcal{M} \triangleq \{M^1, M^2, M^3\}$。人在路口还会改变主意，所以估计器要同时维护两样东西，模式上的离散概率分布，与每个模式下的连续状态分布。

第二层是预测。给定当前状态与协方差往前推，协方差只会变大。这是马尔可夫预测的固有性质，跟调参无关。没有反馈把估计拉回路上，误差就没有东西压住它。

第三层是定位。主车自己也只有一个带噪声的位置估计，于是两车的相对位置带两份独立的误差。

这三样的单位是概率、方差和米，混在一起没法直接进一个优化。工程上常见的做法是选一样当真，其余视而不见。论文的选择是三个都留着，各自以结构化的形式跨模块传递。

### 1.2 数学上的死结在哪

把概率写进约束，净空的形式大致是基础距离加上一个标准差倍数。标准差随时域增长，净空跟着长。车道宽度是常数，路口可用的横向空间更是常数。两条曲线相交的位置，决定这条路线在哪种场景下先崩。

论文的机会约束基线在四岔路口就崩了。直行场景下 **19.2%** 的规划周期解不出解，左转场景 **17.1%**。它崩的时候直接无解，谈不上更保守，只能回退到上一拍的控制量。

反方向那条路是按最可能的走法算一条确定轨迹。它总解得出，但在对方真拐弯时预测就是错的，约束加在错误的位置上。论文的确定性基线在左转场景撞了 **94.6%**。

这个死结的形状值得记一下。安全要的是"留足余量"，可行要的是"余量小于可用空间"。余量的下界随不确定性单调上升，可用空间不随它上升。两者的矛盾不解决，求解器就只能二选一地把答案交出去。

### 1.3 六条替代路线，各缺一块

**集合式规划**。Althoff 与 Magdici 的做法是算出对方所有可能未来的可达集，规划时绕开整个集合，避撞由构造保证。代价是所有机动的可能性被压成一个超集，不看哪个更可能，论文指出这会带出冻结行为甚至数值不可行。

**机会约束 MPC**。Zhu 与 Alonso-Mora 这一路把安全写成一串概率约束，净空取 $D + \Phi^{-1}(0.99)\sigma_{\mathrm{proj}}$，其中 $\Phi^{-1}$ 是标准正态的分位函数，$\sigma_{\mathrm{proj}}$ 是沿分离方向的标准差。它比集合式少保守一些，代价是净空与不确定性同向增长，高不确定区里净空能超过路面宽度。

**采样式规划**。de Groot 等人的做法是从预测分布里抽若干条对方轨迹，每条都要求不撞，用样本数换置信度。它给出的概率界比逐时刻的机会约束更紧，代价是保证强度与样本数绑定，算力随要求线性涨。

**POMDP**。Hubmann 与 Sunberg 两路都把意图当隐变量，在信念空间上边估边规划。这是对意图歧义最讲道理的处理，代价是信念树随视野指数膨胀，实际要砍动作分辨率或砍视野，实时性与保证质量一起降。

**端到端**。以 Planning-oriented 那一类工作为代表，感知预测规划一起训。不确定性被吸进共享的网络权重里，规划器手上没有可检查的显式不确定量，于是安全裕度既看不见也证不出，可行性没有完备性保证。

**确定性 MPC**。Nair 等人的写法把预测轨迹当作已知，约束加在预测点上。它便宜，代价是预测一旦偏离假设，约束就是错位的，而且没有补救机制。

六条路摆开，缺口是同一个。这些量要么全塞在规划器里，安全与可行二选一；要么被吸进不透明的表示，两样都拿不到。==没有谁把意图概率、预测协方差、定位误差当作显式量，一路送到规划器的门口==。

### 1.4 这篇的判断

一句话，把结算点提前到预测与规划之间。机制本身还能再压一句，先在感知侧把风险折成一个数，再用这个数裁出一块凸区域。

分工是这样。路网几何负责安全区的形状，这个量离线已知。概率负责安全区的边界，在线算。凸二次规划负责位姿，在线解。屏障函数负责最后一道，也在线解。

这套判断有两个可检验的推论。去掉任何一份不确定性，碰撞率都该往上走；只要安全区的凸性还在，不可行率就该一直是零。两条推论在第四节都对着数验过，一条涨了，一条没动。

这里值得把账算清，因为后面所有"保证"都建在这笔账上。两车的相对位置是二维随机量，两个分量。主车定位给它一个 $2\times2$ 的位置协方差，对方预测在每一步给另一个 $2\times2$，两者相加仍是 $2\times2$。一个对称的 $2\times2$ 协方差有 3 个独立元素，两个观测源合起来给 6 个。判一次会不会撞只问一件事，沿连心方向的投影距离是否小于两车外接圆半径之和，也就是 1 个判据、1 个未知数。所以判定不需要解出相对位置，也不需要整个时域的联合分布，==一个主车位姿加一个对方预测步，就够给出一个数==。

> 📌 **控制视角**　按感知、规划、控制的三段式来摆，这套方法横跨后两段。感知段它用的是现成的 EKF 与 IMM，没有自己的检测或跟踪贡献。规划段它的 MPC 是标准写法，微分平坦加二次代价，教科书里有。真正新增的东西在预测与决策之间的那道接口上，一份概率、一块几何区域、一个目标位姿。判断它能不能搬到你的平台上，该问的是这道接口对上游的假设能不能满足，高斯、单峰、模式集已知；比它的规划器快几个毫秒，意义不大。

**小结**　三种不确定性单位不同，这篇先把它们折算成概率再交接

## 三、方法拆解

### 3.1 一组并行滤波器同时给意图和状态

估计器在每一拍假设对方只按其中一个模式运动。$r$ 个滤波器并行跑，一个模式一个。四岔路口的模式集有三个元素，所以 $r = 3$。每个滤波器按自己那个模式做预测与更新，得到的是一组条件在模式上的状态估计。

模式概率的更新式是

$$
\mu_k^j = \frac{1}{c}\,\Lambda_k^j\,\bar{c}^j,\qquad j = 1,\dots,r
\tag{1}
$$

$\mu_k^j$ 是第 $j$ 个模式的后验概率。$\Lambda_k^j$ 是量测似然，即在模式 $j$ 下当前观测 $\mathbf{z}_k$ 出现的可能性，越像越给分。$\bar{c}^j$ 是收到观测之前的先验，由上一拍的概率经马尔可夫转移矩阵混合得到。$c$ 是归一化常数，让 $r$ 个后验加起来等于 1。

拿到这组概率，把各模式的状态合成一个，

$$
\hat{\mathbf{x}}_{k\mid k} = \sum_{j=1}^{r}\hat{\mathbf{x}}_{k\mid k}^{j}\,\mu_k^{j}
\tag{2}
$$

$$
P_{k\mid k} = \sum_{j=1}^{r}\mu_k^{j}\left\{P_{k\mid k}^{j} + \left[\hat{\mathbf{x}}_{k\mid k}^{j}-\hat{\mathbf{x}}_{k\mid k}\right]\left[\hat{\mathbf{x}}_{k\mid k}^{j}-\hat{\mathbf{x}}_{k\mid k}\right]^{\top}\right\}
\tag{3}
$$

$P_{k\mid k}^{j}$ 是第 $j$ 个滤波器自己的协方差。式 (3) 大括号里的两项分工不同，第一项说"就算知道意图，也还剩这么多不确定"，第二项是各模式均值相对混合均值的散布。==第二项就是不知道意图这件事本身值多少方差==。模式概率越接近，这一项越大。这条链后面还会用到，意图越含糊，合成协方差越大，碰撞概率越高，安全区越保守。

被估的量在三件套里齐了。初值来自上一拍的后验与转移矩阵。驱动是当前量测的似然。兜底的是模式集 $\mathcal{M}$ 与转移矩阵这两样离线给定的东西。模式集由路网几何生成，论文没有让它在线生长。

### 3.2 每个意图各推一条轨迹

对每个模式各推一条轨迹，工具是 sigma 点滤波器。原文给的理由很朴素，非线性运动学下好用。做法是在均值两侧按协方差撒一组确定性采样点，每个点过一遍非线性模型，再按权重还原均值与协方差。

$$
\chi_{k\mid k}^{s}\in\left\{\hat{\mathbf{x}}_{k\mid k},\ \hat{\mathbf{x}}_{k\mid k}\pm n_{\sigma}\mathbf{L}_{k}\right\},\qquad P_{k\mid k}=\mathbf{L}_{k}\mathbf{L}_{k}^{\top}
\tag{4}
$$

$\mathbf{L}_k$ 是协方差的平方根因子，$n_\sigma$ 是撒点的尺度，采样点一共 $2n_x+1$ 个，$n_x$ 是状态维数。论文没有给出 $n_x$ 与 $n_\sigma$ 的取值，按式 (4) 反推，$n_x$ 取 4 时是 9 个点。

每个采样点过的模型是运动学自行车模型，对方被假定在跟踪该意图对应的机动路径，

$$
\theta_{k+1}^{j} = \theta_{k}^{j} + \frac{v_{k}^{j}}{L}\sin\left(\delta_{k}^{j}\right)\Delta t
\tag{5}
$$

$$
\mathbf{p}_{k+1}^{j} = \mathbf{p}_{k}^{j} + v_{k}^{j}
\begin{bmatrix}
\cos\left(\theta_{k+1}^{j}+\delta_{k}^{j}\right)\\
\sin\left(\theta_{k+1}^{j}+\delta_{k}^{j}\right)
\end{bmatrix}\Delta t
\tag{6}
$$

$$
v_{k+1}^{j} = v_{k}^{j} + a_{k}^{j}\Delta t
\tag{7}
$$

$\theta$ 是朝向，$\mathbf{p}$ 是平面位置，$v$ 是速度，$L$ 是轴距，注意这个符号和后面车身长度同名但不是一个量。$\delta$ 是转向输入，$a$ 是比例速度修正，$\Delta t$ 是步长。

$\delta$ 不是自由变量，它由跟踪该意图对应的机动路径算出来。速度也由一个比例控制器往目标值上拉。这两句话是这套预测的关键，模型内部带着车道保持与速度环，外推就不是纯开环积分。原文把好处写得很直白，这样预测出的协方差更小、不会无界增长、并且沿道路方向对齐。==开环外推的协方差会随时间无界膨胀，闭环把控制器塞进模型，等于给预测配了一个会自己纠偏的假想驾驶员==。

$$
\hat{\mathbf{x}}_{k+1\mid k}^{j} = \sum_{s} W_{m}^{s}\,\boldsymbol{\chi}_{k+1\mid k}^{s}
\tag{8}
$$

$$
\hat{P}_{k+1\mid k}^{j} = \sum_{s} W_{c}^{s}\,\tilde{\boldsymbol{\chi}}^{s,j}\left(\tilde{\boldsymbol{\chi}}^{s,j}\right)^{\top} + Q
\tag{9}
$$

$W_m^s$ 与 $W_c^s$ 是两套权重，分别算均值和协方差，$\tilde{\boldsymbol{\chi}}^{s,j}$ 是采样点相对预测均值的偏差，$Q$ 是加性过程噪声。

输出是每个意图 $N_T$ 条带时间戳的高斯分布，$N_T = T/\Delta t$。有了这份序列，碰撞概率可以解析算出来，不必采样。

这一层的三件套比较薄。初值是 3.1 节的均值与协方差。驱动这一项空着，因为它是纯前向传播，没有量测进来修正。兜底的是模型内的控制律与过程噪声 $Q$，两者一起决定了协方差长成什么形状。

### 3.3 主车自己那一份误差

主车把自己的位置量测过一遍 EKF，得到位姿估计与 $2\times2$ 的平面位置协方差。到预测的每一步 $n$，碰撞检测把两份不确定度相加，$\Sigma = P_{k\mid k}^{e} + \hat{P}_{k+n\mid k}^{j}$。$P_{k\mid k}^{e}$ 是主车定位那一份，$\hat{P}_{k+n\mid k}^{j}$ 是对方在第 $n$ 步预测那一份。定位越差，所有意图下的碰撞概率一起抬，行为一律更保守。论文没有为定位误差单设一条补偿通道，它是通过 $\Sigma$ 进到概率里的。

### 3.4 从两块矩形到一个标量

碰撞检测回答的问题很窄，给定两车的分布，它们在未来某一拍会不会重叠。车被表示成有向包围盒（Oriented Bounding Box，OBB），即沿朝向 $\theta$ 定向的矩形，半长 $L/2$、半宽 $W/2$，半展记作 $e_0$ 与 $e_1$。原文在此处写了一句 the full box spans $L\times M$，按上下文应是 $L\times W$，$M$ 没有定义，这是一处排版失真。

相对位置是一个高斯随机变量，均值是两车中心之差，协方差是两份之和。

$$
\Delta\mathbf{p}_{k,n}\sim\mathcal{N}\!\left(\hat{\mathbf{x}}_{k+n\mid k}^{j}-\hat{\mathbf{x}}_{k\mid k}^{e},\ P_{k\mid k}^{e}+\hat{P}_{k+n\mid k}^{j}\right),\quad n\in\{1,\dots,N_T\}
\tag{10}
$$

两个矩形之间的间隙，用中心连线的长度减去各自在连线方向上的投影半宽。投影半宽按 $r(\mathbf{d}) = e_0|\mathbf{a}_0\cdot\mathbf{d}| + e_1|\mathbf{a}_1\cdot\mathbf{d}|$ 算，$\mathbf{a}_0$、$\mathbf{a}_1$ 是车身坐标轴，$\mathbf{d}$ 是单位连心方向。

$$
d_{\mathrm{gap},k,n} = \left\|\hat{\mathbf{x}}_{k+n\mid k}^{j}-\hat{\mathbf{x}}_{k\mid k}^{e}\right\| - r_{\mathrm{ego}}(\mathbf{d}_{k,n}) - r_{\mathrm{agent}}(\mathbf{d}_{k,n})
\tag{11}
$$

最近接近的那一拍取 $n^{*} = \arg\min_n d_{\mathrm{gap},k,n}$。==最近接近点并不落在中心距最小的那一拍==。投影半宽随两车相对朝向变化，朝向一错开，同样的中心距对应的间隙就不同。原文专门说明了这一点，把车辆几何放进搜索，算出来的概率才准。

在 $n^{*}$ 处把 $2\times2$ 的 $\Sigma$ 投影到连心方向，得到一个标量方差，

$$
\sigma_{\mathrm{proj}}^{2} = \mathbf{d}_{k,n^{*}}^{\top}\Sigma\,\mathbf{d}_{k,n^{*}},\qquad
d_{\mathrm{miss}}^{j} = \left\|\hat{\mathbf{x}}_{k+n^{*}\mid k}^{j}-\hat{\mathbf{x}}_{k\mid k}^{e}\right\| - r_{\mathrm{col}}
\tag{12}
$$

$r_{\mathrm{col}} = r_{\mathrm{ego}} + r_{\mathrm{agent}}$ 是两车外接圆半径之和，外接圆在任意朝向下都包住车身矩形。所以 $d_{\mathrm{miss}}$ 偏小，概率偏大，原文明确说这是对真实风险的上界。

$$
P_{\mathrm{col}}^{j} = 1 - \Phi\!\left(\frac{d_{\mathrm{miss}}^{j}}{\sigma_{\mathrm{proj}}}\right)
\tag{13}
$$

$\Phi$ 是标准正态的累积分布函数。$d_{\mathrm{miss}}$ 为正且远大于 $\sigma_{\mathrm{proj}}$ 时概率趋零；$d_{\mathrm{miss}}$ 为零时概率正好 0.5；间隙变成负的，概率往 1 走。

三个读法要一起记住。整段时域里只在最近接近那一拍算概率，算的不是联合分布。几何上用外接圆代替矩形，保守落在上界这一侧。概率是逐意图给的，三个模式三个数，它们不加权求和，下一步只挑一个用。

### 3.5 决策，把标量折成一块区域

决策模块先挑出最可能的意图，$j^{*} = \arg\max_j \mu_k^{j}$。原文明确解释为什么不取加权和。低概率意图若碰撞概率很高，加权和会把它摊薄，结果不会超过最大那一项，风险因此被低估。它还补了一条机制，概率接近时 IMM 的混合协方差变大，$\Sigma$ 变大，$P_{\mathrm{col}}$ 随之上升，安全区自己就更保守。

程序上是一个级联检查，先看概率过不过阈值，再过就整条车道放行，不过才去构造危险区。

```
Algorithm 1  决策模块
输入   模式概率 μ_k
       各意图碰撞概率 P_col^j
       各意图预测轨迹 {x̂, P̂}，n = 1 … N_T
       主车车道边界 L
       阈值 ε
输出   安全区 S，中间目标位姿 ζ_goal

 1  j* ← argmax_j μ_k^j
 2  若 P_col^{j*} ≤ ε
 3      则 S ← L                                    // 整条车道都安全
 4  否则
 5      沿 j* 的预测把对方 OBB 逐拍扫过，并集记为 U   // 逐拍累积
 6      若 y_e < y_a                                 // 主车还没到 U
 7          则 y_safe ← min over (x,y) ∈ L ∩ U 的 y
 8             S ← [x⁻, x⁺] × [y_e − L, y_safe]      // 让行
 9      否则                                        // U 已在主车身后
10          则 S ← L                                 // 径直通行
11  ζ_goal ← 在 S 内部取一个目标位姿
```

$y_e$ 是主车纵向位置，$y_a$ 是对方纵向位置，$\varepsilon = 0.01$ 是判定高风险的阈值。分支的物理含义是一次让行判断，主车还没进危险区就让，已经过去了就走。式 (14) 把结果写成四个半平面的交，

$$
\mathcal{S} = \left[x_L^{-}, x_L^{+}\right]\times\left[y_{\min}, y_{\max}\right] = \bigcap_{m=1}^{4} H_m
\tag{14}
$$

$H_m$ 是四个半平面，对应矩形的四条边。四个线性不等式给 2 个坐标分量套上边界，可行域非空且是凸多边形。$y_{\min}$ 与 $y_{\max}$ 由算法 1 决定，安全时取车道本身的两个纵向边界，让行时取 $y_e - L$ 与 $y_{\mathrm{safe}}$。原文说 $\mathcal{S}$ 取的是车道内排除危险区的最大轴对齐矩形。

凸性带来的是递归可行，论证只有一句话。凸集里任意两点的连线整段都在集合内。主车当前位姿在 $\mathcal{S}$ 里，下界取 $y_e - L$ 就是保证这一点；中间目标位姿也在 $\mathcal{S}$ 里。于是那条直线本身就是一条不越界的候选轨迹，MPC 每一拍至少存在这一条解。__安全区是凸的，当前位姿在它里面，所以每拍至少有一条可行轨迹__。

这里要说清一件事，这套论证跟不确定性没有关系。哪怕上游概率算得离谱，只要安全区还是凸的、还含当前位姿，可行性就还在。论文自己的说法也是这个意思，可行性保证在所有消融下都成立，它是结构性的。

### 3.6 规划与安全过滤

规划器在安全区里追中间目标位姿。它用的是微分平坦，原文的说法是这套变换把系统动力学变成线性、可控、时不变的。具体做法是把非线性车辆模型映到平坦输出空间，在那里它就是一个双积分器，平坦输出取 $\boldsymbol{\zeta} = [x,\,y,\,v_x,\,v_y]^{\top}$，控制取 $\mathbf{u} = [a_x,\,a_y]^{\top}$。目标函数是

$$
\min_{\boldsymbol{\zeta},\mathbf{u}}\ \sum_{k=0}^{N-1}\left[\left\|\boldsymbol{\zeta}_k-\boldsymbol{\zeta}_{\mathrm{goal}}\right\|_Q^2+\left\|\mathbf{u}_k\right\|_R^2\right]+\left\|\boldsymbol{\zeta}_N-\boldsymbol{\zeta}_{\mathrm{goal}}\right\|_P^2
\tag{15}
$$

$\boldsymbol{\zeta}_k$ 是第 $k$ 步的平坦输出，$\mathbf{u}_k$ 是同一步的平坦控制，$\boldsymbol{\zeta}_{\mathrm{goal}}$ 是决策模块给的中间目标位姿。$Q$ 与 $R$ 分别是状态和控制的权重，$P$ 是终端权重，$N$ 是视野步数。约束是线性动力学 $\boldsymbol{\zeta}_{k+1} = A\boldsymbol{\zeta}_k + B\mathbf{u}_k$、速度与加速度限幅、以及初始条件 $\boldsymbol{\zeta}_0 = \boldsymbol{\zeta}_{\mathrm{current}}$。线性动力学配二次代价，解出来是个小规模二次规划，原文报的是约 5 ms。

三件套在这一层是齐的。初值是当前位姿 $\boldsymbol{\zeta}_{\mathrm{current}}$。驱动是两项残差，偏离目标位姿的跟踪误差，加上控制量的代价。兜底的是线性动力学、限幅，以及经屏障函数施加的安全区边界。

安全区的边界再往里收一道，做法是给四条边界各配一个二阶控制屏障函数。以纵向的上边界 $y_{\max}$ 为例，条件写成

$$
h_{y_{\max}}(\boldsymbol{\zeta},\mathbf{u}) = -a_y-(\lambda_1+\lambda_2)\,v_y+\lambda_1\lambda_2\left(y_{\max}-y\right)\ \ge\ 0
\tag{16}
$$

$a_y$ 是纵向加速度，平坦控制的一个分量。$v_y$ 是纵向速度。$(y_{\max}-y)$ 是到上边界还剩的余量。$\lambda_1$、$\lambda_2$ 是两个正的可调参数，原文只给了大于零，没有给取值。读法是余量大的时候第三项给正贡献，允许往外加速；余量趋零时这一项归零，条件退化成加速度必须把向外的速度压回零以下。参数越大，边界收得越紧。

原文引 Nagumo 定理，只要这条条件在每个时刻都成立，状态就永远留在 $\mathcal{S}$ 内。这就是前向不变。落地成一个最小改动问题，

$$
\min_{\mathbf{u}_{\mathrm{safe}}}\ \left\|\mathbf{u}_{\mathrm{safe}}-\mathbf{u}_{\mathrm{ref}}\right\|^{2}
\quad\text{s.t.}\quad
h_b\left(\boldsymbol{\zeta}_{\mathrm{current}},\mathbf{u}_{\mathrm{safe}}\right)\ \ge\ 0,\ \ \forall b
\tag{17}
$$

$\mathbf{u}_{\mathrm{ref}}$ 是规划器给的参考控制，$b$ 遍历四条边界。2 个未知数（两个加速度分量）配 4 条线性不等式，可行域是凸多边形，规模小到可以每拍都解。三件套同样齐，初值是 $\mathbf{u}_{\mathrm{ref}}$，残差是它与安全控制之间的二范数，兜底是那四条不等式。

最后一步是把平坦空间翻译回底盘认的量，线速度取 $v = \sqrt{v_x^2+v_y^2}$，角速度取 $\omega = (v_xa_y-v_ya_x)/v^2$。

### 3.7 保证其实是三环

把保证拆开看，它由三环串成，每环依赖的前提不同。

第一环，安全区按概率构造。前提是高斯、模式集已知、外接圆那层保守化成立。结论是模型之内概率安全。

第二环，安全区是凸的且含当前位姿。前提只有凸性这一件事，与概率算得准不准无关。结论是每拍有可行解。

第三环，屏障函数让状态前向不变。前提是双积分器模型与两个增益。结论是执行轨迹不出安全区。

三环串起来才叫既避撞又可行。任何一环的前提被打破，保证就在那一环上破，另外两环帮不上忙。这样拆开读有个好处，一句笼统的"有保证"变成了可以分别检验的三句话，每句对应一组公式和一个模块，缺哪环一眼能看出来。

**小结**　三环各管一件事，凸性那一环与不确定性无关

意图那一项最贵。碰撞从 0 涨到 **29.0%**，直行 45.7%、左转 35.1%。原文的解释是碰撞检测与决策在错误意图下没能把安全区切成让行的那一支。

第二项有个反直觉的地方。去掉预测之后直行场景的碰撞是 **20.0%**，比左转的 5.4% 还高。匀速直线外推在转弯场景错得最离谱，按直觉左转该更吃亏。原文给的解释是，匀速外推的协方差随时域线性增长，即便直行方向上的预测大致正确，碰撞时机也会被误判。

第三项是定位。给近乎完美的量测，碰撞率 5.0%，集中在直行的 14.3%。原文的解释是，没有定位协方差就会低估风险，开得更激进，留的刹车距离不够。

==三组消融的不可行率都是 0.0，这一格比碰撞率更能说明这套架构的性质==。它说明可行性不随上游质量变化，只要安全区还是凸的、还含当前位姿。原文自己的说法也是这样，可行性保证在所有消融下结构性成立。

还有一笔要点出来。完整管线 12.7 ms，三个消融是 7.8、6.7、6.8，各自省下 4.9、6.0、5.9 ms。三项加起来 16.8 ms，比总开销还大，所以这三个数不是可加的分解。原文是把完整管线与最便宜的那个消融相比，给出的数是约 6 ms，这是为定位、IMM 与不确定性感知预测器付的价。

硬件是两台 Clearpath Jackal，3 m × 3 m 的路口台架。动作捕捉以 60 Hz 给两车平面坐标，论文写明没有额外注入噪声。主车用 EKF 以 50 Hz 估自己的位姿与速度，对方用 IMM 以 10 Hz 同时当跟踪器与意图估计器。下游预测器 25 Hz、视野 2.5 s，碰撞检测 20 Hz，决策 50 Hz，规划器 2 Hz，安全过滤器 5 Hz。阈值同样是 0.01。

三个场景各跑一次，结果是这样。直行场景最小车体间距 **0.0869 m**，用时 13.16 s。左转 **0.2641 m**，12.9 s。右转 **0.6060 m**，7.46 s，这一档对方的轨迹不与主车车道相交，流水线早早把整条车道还了回来。原文的结论是两条保证在真实传感不确定度下转移到了物理平台上。

0.0869 m 这个数得单独看一眼，它只有 8.7 cm，比仿真里 0.25 m 的平均净空小一个量级。判碰撞的口径是两车矩形重叠。

第四个场景专门试探模型失配。对方走一条之字形轨迹。IMM 没法用单一模式解释它，意图概率因此来回摆，t₁ 判右转，t₂ 转左，t₃ 转直行，t₄ 又回到左转，t₅ 主车才判定可以走。

概率摆动期间碰撞风险一直居高位，安全区整段保持在收缩状态。结果是无碰撞，最小间距 0.2641 m，用时 15.33 s，四个场景里最慢。原文的措辞很克制，说这个分布外实验 suggests 流水线在模型失配下退化得比较温和，上游模块在没有模式能贴合时会给出保守估计，避撞与可行性两个性质因此保住了。

四个场景的用时排下来是 7.46、12.9、13.16、15.33 s。最慢的那个正是模型失配的那一个。

> 📌 **控制视角**　这一节最该带走的是那张消融表的三行不可行率。碰撞率会随上游质量上下跳，不可行率一直是 0，说明这套架构把"必然有解"和"大概率不撞"放进了两套不同的机制。工程上判断一个安全框架值不值得用，可以先问它把这两件事分开了没有。分开了，你至少知道出问题时该去查哪一环；混在一起，一次失败既可能是估错也可能是解不出，排查成本翻倍。

**小结**　碰撞压到零的代价是通行慢了五成，可行性不随上游变化

## 五、局限

论文没有单独的局限一节，承认的地方散在结果与讨论里。归拢起来是这几条。

**模式集之外的行为只能靠保守兜住。** 原文写的是 IMM 无法用单一模式解释之字形轨迹，于是意图概率持续摆动、碰撞风险居高、安全区整段保持收缩。它对这件事的定性用的词是 suggests 与 degrades gracefully，没有把它写成缺陷。

**三岔路口有一次没到目标。** 原文写 One trial reports unreached goal，偏离目标 6 cm，判定阈值是 5 cm。它的 99% 成功率就是这 1 次没到目标扣出来的。

**消融下轨迹质量可能退化。** 原文用的是 might，写 trajectory quality might degrade depending on the upstream uncertainty propagation。三组消融的碰撞率上去了，轨迹质量这一项只有这句定性描述。

**概率是上界，但也只是概率。** 原文用外接圆半径把 $r_{\mathrm{col}}$ 放大，明确说得到的概率 upperbounds 真实风险。这条既是保守化的依据，也划出了"保证"的层级，到概率为止。

**只取最可能的那一个意图。** 概率接近时靠混合协方差变大来变保守，原文举了 $(0.45, 0.5, 0.05)$ 这组数。这是它的设计取舍，也是它对多峰风险处理的上限。

### 编者补充的局限

下面这几条论文未将其列为局限，是我读表读出来的。

**0% 是经验频率，不是证明。** 100 次里 0 次碰撞，按常用的三倍法则，真实碰撞率的上界大约是 3%。__0% 是 100 次试验里的经验频率，不是证明__。而且这 100 次被分到三个场景，各 35、37、28 次。

**硬件只有四次实验。** 三个标称场景加一个之字形，每个跑一条轨迹，没有重复统计，也没有给净空的分布。8.7 cm 那一次的余量已经贴近判据。

**感知前端没进这条流程。** 动作捕捉给的是无附加噪声的位置。图 2 用虚线画了视觉估车辆外形的可能性，正文也引了视觉估外形的做法，实验里两车尺寸都是已知量。真实检测误差、遮挡、视角切换带来的分布偏移，这套实验没有覆盖。

**没有任何预测精度的指标。** 论文报的是碰撞率、成功率、净空、时间，全是端到端指标。意图判对率、轨迹预测误差、碰撞概率的校准程度都没有报，一次失败因此说不清是哪一级出的错。

**机会约束基线的复现条件不完整。** 它的净空写成 $D + \Phi^{-1}(0.99)\sigma_{\mathrm{proj}}$，$D$ 在文中没有定义，也没有给数值。这条基线是与本文最接近的对照，缺一个常数会让复现打折扣。

**算力平台没有报。** 12.7 ms 是仿真机上的墙钟时间，硬件上各模块的实际频率从 2 Hz 到 60 Hz 不等。两个数回答的是不同的问题，混着引会得出错误结论。

**多车扩展是顺序通行，不是交互。** 三辆车的意图相互独立，安全区对每个 agent 各算一套。互相让行、抢行、博弈这类真交互没有测。

**概率只在最近接近那一拍算。** 不是时域上的联合概率。多车时各车独立算，联合风险没有处理。

**小结**　承认的局限都在模型之内，模型之外的没写成局限

## 六、我的评价

做得对的地方有四处。

把一句笼统的"有保证"拆成三环，并且逐环给出前提。这是系统论文该有的写法，读者可以拿它去对照自己的场景，看哪一环的前提不成立。第二环尤其干净，凸性只依赖几何，不依赖概率。

消融的三项与它宣称的三个不确定性源一一对应。很多论文的消融是拿几个无关变体凑数，这篇的三项正好是它要证明"每一份不确定性都必要"的那三份，缺一个论证就不闭合。

主动报出通行时间的代价。摘要里只写 0% 与 12.7 ms，正文老老实实给了 1.91 对 1.23。

主动做分布外实验。之字形那一段算不上严格评测，但它把一个明显不利的场景摆出来了，这在机器人论文里不算常见。

存疑的地方有七处。

第一，"保证"的强度。三环里只有第二环是硬的，而且它与不确定性无关。第一环是模型之内的概率，第三环是模型之内的前向不变。==标题里的 guarantee，落到纸上其实是"给定模型下安全区概率安全"加"每一拍有可行解"==。0% 碰撞是支持证据，不能读成保证。要读成保证，得先证明模型误差有界，这一步论文没做。

第二，速度优势的归因。三个框架都跑 CasADi 加 IPOPT，5.1 ms 对 18.0 ms 的差落在问题结构上，一个是小的凸二次规划，另一个带非线性约束，跟不确定性传播无关。上游那套机制本身还要花约 6 ms。论文说这 6 ms 是 modest price，我同意这个定性，但它不该和"更快"混在同一句话里读。

第三，消融的整拍时间不可加。三项各省 4.9、6.0、5.9 ms，加起来超过总开销。我猜去掉定位误差之后 $\Sigma$ 变小、碰撞概率更低、决策模块更常走阈值那一支、跳过了扫掠，所以省下的时间并不是算力差。这条只是猜测，论文没有给分模块的计时。

第四，统计力。0/100 的 95% 置信上界大约 3%，分到每个场景只有 28 到 37 次。硬件是四次。要在统计上区分 0% 与 1%，这个样本量不够。

第五，8.7 cm 那一次。判据是矩形重叠，8.7 cm 的余量说明这次成功离失败很近。它不是反例，但它提醒 0.0869 m 与 0.25 m 之间差着一个量级，实机上的净空分布比仿真紧得多。

第六，interpretable 这个词。论文标题里有它，正文里它落在结构上，每个量有物理含义，每个模块的输入输出能指认。这不算短板，只是别把这个词读成"给人看的解释"，论文没有做任何面向人的可解释性评估。

第七，一处对不上的数。之字形场景报的最小间距是 0.2641 m，与左转场景一字不差。两条不同轨迹、两次不同实验给出同一个四位有效数字，原文没有解释，我也没有依据判断这是巧合还是笔误。它不影响任何结论，但引用硬件那一节的净空时，这两个数最好别混着用。

它想走去哪是清楚的。结论最后一句说要走 certifiably safe 的自动驾驶。真要走过去，缺的是把模型误差纳进来，保守化的边界怎么给、模式集怎么在线生长、感知延迟怎么补，这三件都在模型之外。

**小结**　第一环是概率第三环是模型，只有第二环是硬的

## 七、可以接着做什么

下面四条是读完之后的联想，给正在找题的人当线索。

### 1. 让模式集在线长出来

现在模式集由路网几何离线给定，遇到之字形这种轨迹只能靠整体收缩兜住。判据其实就在手边，IMM 的似然。当所有模式的似然都低时，说明没有一个模式能解释观测，这本身就是异常信号。做法是给似然设一个门限，低于门限时插入新模式的候选，或者干脆把安全区钉在最大收缩。要回答的是新模式的初始化、与已有模式的合并规则、以及插入之后协方差怎么不炸。

### 2. 把安全区换成沿车道的凸多边形

轴对齐矩形的好处是 CBF 约束是线性不等式，坏处是横向也是硬边界。弯道上、斜交路口里，矩形会把可用空间白切掉一块，1.91 的归一化时间里应该有这一份。换成沿车道走向的凸多边形仍然保凸，第二环的论证不受影响。要验证的是约束条数涨上去之后 QP 还快不快，以及车辆几何与多边形求交的算法会不会成为新瓶颈。

### 3. 把感知延迟算进保证

第三环的前向不变要求每个时刻都满足条件。硬件上规划 2 Hz、安全过滤 5 Hz，两者之间隔着 200 到 500 ms，这段窗口里严格说没有保证。做法有两条，一条是把延迟做成状态增广，另一条是给边界加一段按最坏延迟算出来的补偿带。要回答的是补偿带该多宽，宽了会不会把可行性吃掉。

### 4. 多车从顺序通行推到真交互

现在三辆车的意图相互独立，安全区各算各的。真交互要让两车或三车的安全区互相耦合，可以做联合的凸近似，也可以把对方的反应写进预测模型里，让预测知道自己也在被预测。难点在耦合之后凸性还在不在，一旦不在了，第二环那套一句话的论证就得重写。

※ 上面四条都是读完文章之后的即时联想，我没有做实验，也没有查证过是否已经有人在做，更没有验证过可行性。只当选题线索看，不要当结论用。

**小结**　四条线索，从扩模式集到补延迟，都还没有实验

## 名词速查

| 词 | 一句话解释 |
|---|---|
| **意图模式** | 对方可能采取的一种机动，本文里由路网几何给出，四岔路口是直行、左转、右转三个 |
| **模式集 $\mathcal{M}$** | 所有意图模式组成的集合，离线给定，论文没有让它在线生长 |
| **IMM** | 交互多模型滤波器，并行跑一组滤波器、每个滤波器对应一个模式，再按概率把结果合成 |
| **模式概率 $\mu$** | 每一拍对"对方正在执行哪一模式"的后验判断，几个概率加起来等于 1 |
| **量测似然 $\Lambda$** | 在某个模式下，当前这帧观测出现的可能性，越像给分越高 |
| **混合协方差** | 把各模式的协方差按概率加权、再加上各模式均值之间的散布，得到的总协方差 |
| **EKF** | 扩展卡尔曼滤波，把非线性模型在当前点线性化之后做卡尔曼滤波 |
| **sigma 点滤波器** | 在均值两侧按协方差撒一组确定性采样点，各自过一遍非线性模型再还原统计量 |
| **协方差** | 一个量的不确定程度，二维位置对应一个 2×2 矩阵 |
| **预测视野** | 往前推多长时间，仿真里由步数与步长决定，硬件上是 2.5 s |
| **投影半宽** | 把车身矩形沿某个方向压扁得到的半宽，随相对朝向变化 |
| **最近接近点** | 两车间隙最小的那一拍，注意它不等于中心距最小的那一拍 |
| **分离方向** | 两车中心连线方向，概率就沿这个方向算 |
| **标准正态 CDF $\Phi$** | 一维高斯落在某个值以下的概率，本文用它把间隙换成概率 |
| **碰撞概率 $P_{\mathrm{col}}$** | 一个意图下的标量风险，两个车身外接圆相交的概率上界 |
| **外接圆半径** | 包住车身矩形的最小圆半径，任何朝向下都够大，所以概率偏保守 |
| **安全区 $\mathcal{S}$** | 车道里挖掉危险区之后剩下的凸矩形，规划器与安全过滤器只在这里面活动 |
| **危险区 $\mathcal{U}$** | 对方车身沿最可能意图的预测逐拍扫过形成的并集 |
| **机会约束 MPC** | 把安全写成逐时刻概率约束的 MPC，净空随不确定性一起长，不确定性大时容易无解 |
| **确定性 MPC** | 把预测轨迹当作已知的 MPC，解总有，预测一旦错了就会撞 |
| **集合式规划** | 先算出对方所有可能未来的集合，再规划绕开整个集合，避撞由构造保证但偏保守 |
| **POMDP** | 把意图当作隐变量、在信念分布上做规划的一类方法，信念树随视野指数增长 |
| **端到端** | 感知预测规划一起训成网络，不确定性被吸进权重，没有显式可查的安全裕度 |
| **三段式** | 把机器人系统分成感知、规划、控制三段的惯用说法，用来定位一个方法在整条链里的位置 |
| **有向包围盒（OBB）** | 沿车身朝向定向的矩形，半长 L/2、半宽 W/2，用来近似车身轮廓 |
| **AABB** | 与坐标轴对齐的包围盒，本文用它构造安全区，因为四条边就是四个线性约束 |
| **半平面** | 一条直线一侧的区域，四个半平面相交得到矩形 |
| **递归可行** | 每一拍都至少存在一条可行解，且解把状态带到下一拍仍然可行的位置 |
| **前向不变** | 一旦状态落在集合内，之后的演化永远不出这个集合 |
| **微分平坦** | 系统状态与控制都能由一组平坦输出及其有限阶导数表示，非线性模型因此可换成线性模型求解 |
| **双积分器** | 只有加速度输入的简化模型，位置是加速度的二次积分 |
| **控制屏障函数** | 把"必须留在集合内"翻译成一条关于控制输入的代数不等式 |
| **二阶条件** | 屏障函数条件里带二阶导数的那一版，对双积分器系统给出关于加速度的线性约束 |
| **Nagumo 定理** | 只要每个时刻都满足屏障条件，状态就保持前向不变 |
| **二次规划** | 二次目标配线性约束的优化问题，凸的时候解起来很快 |
| **IPOPT** | 一个内点法非线性求解器，本文三个规划框架都用它实现 |
| **蒙特卡洛试验** | 每次随机抽场景参数跑一遍，用多次结果统计成功率与失败率 |
| **消融** | 一次只拆掉一个部件，看性能掉多少，用来证明这个部件必要 |
| **归一化通行时间** | 实际通行时间除以无障碍通行时间，1.0 表示和空路一样快 |
| **最小净空** | 一次试验里两车车身矩形之间的最小距离，只统计成功到达的试验 |
