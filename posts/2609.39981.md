## 它想干什么

经典 LQR 最小化的是一段期望代价。真实系统里的扰动是随机的，同一套反馈反复跑，每次真花掉的代价并不相同。==LQR 只对平均值负责，对这次跑和下次跑差多少不闻不问==。

楼宇温控按平均能耗调控制器，长期账单可能很好看，但有些天特别贵。车辆横向控制只压平均跟踪误差，某几次运行里横向偏差就冲出车道。这两类场合要的是平均表现好，波动也要小。

想在控制里把波动管起来，第一步是能写出累积回报的方差。折扣无穷时域下，这个量一直没有闭式表达。困难出在回报本身是无穷多个相关随机项之和，平方以后交叉项成堆，而这些交叉项一般不为零，收不成紧凑形式。

这篇论文先把方差做成闭式。在扰动独立同分布、零均值、概率密度关于原点对称的条件下，随机回报可以拆成三块两两正交的部分，方差随之简化成两项，其中一项带一个额外的 Lyapunov 方程。扰动若服从高斯分布，式子还要再简一层，最后只剩扰动协方差。

拿到闭式之后，论文把方差乘上风险厌恶系数 $\alpha$ 加进目标，构造一个均值-方差最优控制问题。这个问题非凸，又要守住闭环稳定，直接做梯度下降会滑出稳定域。论文把稳定约束换成一个在稳定边界上发散的障碍项，再用伴随法算出梯度，得到一个每轮解六个 Lyapunov 方程的梯度下降算法。定理 3 保证迭代全程稳定，并收敛到惩罚目标的平稳点。

全文有一条好用的参照线。把 $\alpha$ 调到 0，目标退回期望代价，最优增益正好是折扣代数 Riccati 方程的解 $K_{\mathrm{DARE}}$。$\alpha$ 从小往大调，就是从这个经典解出发，用更高的平均代价去换更小的方差。

**这节要你记住的是**　先拿到回报方差的闭式，再把它当风险项做控制。

## 一、问题背景

### 1.1 问题为什么难

先看被控对象。系统是离散时间的线性系统，带外部扰动。

$$x_{t+1}=Ax_{t}+Bu_{t}+v_{t} \tag{1}$$

$x_t\in\mathbb{R}^n$ 是状态，$u_t\in\mathbb{R}^m$ 是控制输入，$v_t\in\mathbb{R}^n$ 是外部扰动。论文假定 $v_t$ 独立同分布，分布记作 $\mathcal{D}$，协方差 $\Sigma$ 正定。取线性反馈 $u_t=Kx_t$，闭环矩阵记作 $A_K=A+BK$。

折扣 LQR 最小化的是期望累积二次代价。

$$V^{\pi}(x)=\mathbb{E}\Big[\sum_{t=0}^{\infty}\gamma^{t}\big(x_{t}^{\top}Qx_{t}+u_{t}^{\top}Ru_{t}\big)\Big]$$

$Q$ 与 $R$ 对称正定，$\gamma\in(0,1)$ 是折扣因子。固定 $K$ 之后这个目标解成二次型加常数，二次型系数 $P$ 由 Lyapunov 方程给出。

$$P=Q+K^{\top}RK+\gamma A_{K}^{\top}PA_{K} \tag{2}$$

那个常数项是 $\frac{\gamma}{1-\gamma}\mathrm{tr}(P\Sigma)$，来源是扰动一直往状态里灌能量。

分布 LQR 不满足于算期望，它要刻画整个回报分布。随机回报的定义是

$$G^{K}(x)=\sum_{t=0}^{\infty}\gamma^{t}x_{t}^{\top}(Q+K^{\top}RK)x_{t} \tag{3}$$

这一项是一次具体实验里真花掉的钱，本身是随机变量。它满足随机变量版本的 Bellman 方程。

$$G^{K}(x)\stackrel{D}{=}x^{\top}(Q+K^{\top}RK)x+\gamma G^{K}(x^{\prime}),\qquad x^{\prime}=A_{K}x+v_{0}$$

第一个难点在这里露出。$G^{K}(x)$ 通过 $P$ 隐式依赖 $K$。$K$ 一动，Lyapunov 方程的解跟着动。想对这个目标求梯度，必须穿透一层矩阵方程。

第二个难点在方差本身。把 (3) 展开，回报是三类项之和。

$$G^{K}(x)=x^{\top}Px+2\Psi_{1}+\Psi_{2}+2\Psi_{3}$$

$$\begin{cases}\Psi_{1}=\sum_{k=0}^{\infty}\gamma^{k+1}w_{k}^{\top}PA_{K}^{k+1}x\\ \Psi_{2}=\sum_{k=0}^{\infty}\gamma^{k+1}w_{k}^{\top}Pw_{k}\\ \Psi_{3}=\sum_{k=1}^{\infty}\gamma^{k+1}w_{k}^{\top}P\sum_{\tau=0}^{k-1}A_{K}^{k-\tau}w_{\tau}\end{cases} \tag{4}$$

$w_k$ 是与 $v_t$ 同分布的辅助随机变量，彼此独立。$\Psi_1$ 是扰动的一次项，$\Psi_2$ 是扰动的二次型项，$\Psi_3$ 是不同时刻扰动之间的交叉项。

方差等于二阶矩减去一阶矩的平方，难点全在二阶矩。三项两两相乘有六组，每组都是无穷级数。扰动若不带零均值，或分布不对称，奇数阶矩就残留在里面，凑不出紧凑形式。回报方差一直没有闭式表达，根源就在这里。

Assumption 1 把局面救了回来。它要求扰动独立同分布、零均值，并且概率密度关于原点对称。命题 1 在这条假设下证明三块两两正交，也就是交叉二阶矩全部为零。正交性的证明落在一个奇函数上。引理 3 考虑 $g(w)=ww^{\top}Pw$，它在 $w$ 变号时也变号。对称性保证 $w$ 与 $-w$ 同分布，一个取值为自身相反数的随机变量，期望只能是零。

正交性一到手，方差就拆成两块。

$$\mathrm{Var}[G^{K}(x)]=\mathrm{Var}[\Gamma_{1}]+\mathrm{Var}[\Gamma_{2}]$$

其中 $\Gamma_1=\Psi_2$，$\Gamma_2=2(\Psi_1+\Psi_3)$。六组交叉里五组归零。==方差于是只剩两块自乘，交叉项全被清掉==。

还有一层要处理。$\Gamma_2$ 里面的 $\Psi_1$ 与 $\Psi_3$ 仍然纠缠在一起。命题 2 引入一个辅助状态序列

$$\xi_{k+1}=A_{K}\xi_{k}+w_{k},\qquad \xi_{0}=x \tag{5}$$

以及它的一步预测 $s_{k}=\mathbb{E}[\xi_{k+1}\mid\xi_{k}]=A_{K}\xi_{k}$。$s_k$ 由初值和前 $k$ 步扰动的线性组合决定，与 $w_k$ 独立。有了这层独立性，回报可以重写成两项，第二项的期望是零，方差就等于它的二阶矩。

$$G^{K}(x)=x^{\top}Px+\sum_{k=0}^{\infty}\gamma^{k+1}w_{k}^{\top}Pw_{k}+2\sum_{k=0}^{\infty}\gamma^{k+1}w_{k}^{\top}Ps_{k}$$

> 📌 **控制视角**　方差过去没有闭式解，卡在交叉项不消失，积分技巧帮不上忙。作者的做法是找一组假设把奇数阶矩全部按掉，再把剩下的一次项改写成与噪声独立的预测状态。控制理论里不少算不出来的量，最后都归结成这样一次变量替换。

### 1.2 前人两条路各自缺什么

风险感知控制主要有两条路。

第一条路换掉风险度量。线性指数二次高斯（LEQG）的机制是把期望目标换成指数效用 $\frac{2}{\theta}\log\mathbb{E}[e^{\frac{\theta}{2}G^{K}(x)}]$，用二次型的指数把尾部抬起来，因此保留了完整的解析解。差别落在参数的含义上。$\theta$ 是敏感度参数，只有它趋近于零的时候，这个目标才一阶等于均值-方差目标。$\theta$ 一大，被优化的就不再是方差。文献里另一支罚条件风险价值（CVaR），机制上要对分布做积分，一般没有闭式，只能退到分布模糊下求代价上界，做次优设计。差别是保守换可解。还有一支是风险约束 LQR，机制是把每一阶段状态代价的预测方差累加起来当风险度量，差别在于它盯的不是折扣无穷时域累积回报本身的方差。

第二条路是分布鲁棒。机制是只保留扰动的一阶与二阶矩信息，在一个分布集合上取最坏情形做 min-max。差别在于最坏分布可能是现实中几乎不出现的情形，得到的策略偏保守。

第三条路和这篇论文同源。分布强化学习的机制是把价值函数从数换成分布，用随机变量版的 Bellman 方程直接刻画整个回报分布。差别是它输出分布，不直接给控制器。分布 LQR 把这条思路搬进线性二次控制，机制上给出回报分布的可解刻画，同样停在策略评估和分布刻画这一步。

最接近这项工作的是 Bijl 等 2016 年的结果。机制是连续时间 LQG，用二阶矩展开配 Lyapunov 与 Sylvester 算子，给出代价的精确均值和方差，同样做梯度下降优化方差。差别有两处。它没有收敛保证，这篇论文的定理 3 把稳定性与收敛一并证了。它的方差表达依托连续时间算子，这篇论文在离散时间 LQR 里给出只带一个额外 Lyapunov 方程的紧致表达。

还有一路是策略梯度。机制是在经典 LQR 上利用代价的 coercive 性质与梯度支配性质拿到全局收敛。coercive 说的是增益趋于无穷时代价也趋于无穷，梯度支配说的是梯度范数可以控制目标值与最优值的差距。差别在于论文说这两条性质在均值-方差目标上不成立，这套工具搬不过来。

### 1.3 这篇的做法

论文的贡献按依赖顺序排成三件。定理 1 给出对称独立同分布扰动下回报方差的精确闭式，代价是求解一个额外的 Lyapunov 方程。推论 1 顺着定理 1 给出一个只用到四阶矩的上界，并且比已有的范数界紧得多。定理 2 在高斯扰动下把式子简化到只依赖扰动协方差。第三件是一个均值-方差最优控制问题与它的求解器，对数障碍加伴随梯度下降，配定理 3 的收敛结论。

取舍摆得很清楚。论文没有把非凸问题变成凸问题，它把定义域处理干净，然后老实说解到的是平稳点。

**这节要你记住的是**　方差难在交叉项不消，对称性把它清掉。

## 三、方法拆解

### 3.1 随机回报的三项分解

回报的展开式 (3) 把扰动按出现次数分成了三块。$\Psi_1$ 里扰动只出现一次，系数带着 $A_K$ 的高次幂，随 $k$ 衰减。$\Psi_2$ 是单个扰动的二次型 $w_k^{\top}Pw_k$，与状态无关。$\Psi_3$ 把两个不同时刻的扰动乘在一起，权重是闭环矩阵幂的叠加。

分解的意义在于它把"回报的随机性来自哪里"摆到了明面上。扰动进系统后有两条件用路径。一条是直接打进当前状态，再由 $P$ 折算成代价。另一条是先影响状态，等下一拍扰动再进来，两条路径的乘积就是 $\Psi_3$。方差之所以贵，贵在第二条路径。

### 3.2 正交性，交叉项消失的机制

方差按定义写作 $\mathbb{E}[G^2]-(\mathbb{E}G)^2$。把 $G=x^{\top}Px+2\Psi_1+\Psi_2+2\Psi_3$ 代进二阶矩，会得到 $\Psi_i\Psi_j$ 的六组乘积。论文的命题 1 在 Assumption 1 下证明，$i\neq j$ 时 $\mathbb{E}[\Psi_i\Psi_j]=0$。

证明靠两条。奇阶矩为零，这一条把 $\Psi_1$ 与 $\Psi_2$ 的乘积、$\Psi_1$ 与 $\Psi_3$ 的乘积清掉，因为里面总有某个扰动的奇数次幂落单。不同下标扰动的相互独立，这一条把 $\Psi_2$ 与 $\Psi_3$ 的乘积清掉。两条合起来，__三块两两正交，等价于它们的交叉二阶矩全部为零__。

### 3.3 方差闭式，定理 1 与那个额外的 Lyapunov 方程

$\mathrm{Var}[\Gamma_1]$ 好算。$\Gamma_1$ 是独立随机变量之和，只有 $i=j$ 的对角项留下四阶矩，非对角项按几何级数配对后剩一个负的 $\mathrm{tr}^2(P\Sigma)$。

$\mathrm{Var}[\Gamma_2]$ 靠 $s_k$ 与 $w_k$ 的独立性。$\mathbb{E}[\Gamma_2]=0$，于是方差等于二阶矩。级数展开后 $i\neq j$ 的项全灭，因为 $w_i$ 与 $w_j$、$s_i$、$s_j$ 都独立。剩下

$$\mathrm{Var}[\Gamma_{2}]=4\gamma^{2}\sum_{k=0}^{\infty}\gamma^{2k}\mathbb{E}\big[(w_{k}^{\top}Ps_{k})^{2}\big]=4\gamma^{2}\mathrm{tr}\Big(P\Sigma P\sum_{k=0}^{\infty}\gamma^{2k}\mathbb{E}[s_{k}s_{k}^{\top}]\Big)$$

右边那个和式就是论文里的 $Z$。==那个额外 Lyapunov 方程正是 s 序列二阶矩的加权和==。它的递推来自 $s_{k+1}=A_K\xi_{k+1}=A_K(A_K\xi_k+w_k)=A_Ks_k+A_Kw_k$，两边取二阶矩得到

$$\mathbb{E}[s_{k+1}s_{k+1}^{\top}]=A_{K}\mathbb{E}[s_{k}s_{k}^{\top}]A_{K}^{\top}+A_{K}\Sigma A_{K}^{\top}$$

初值是 $\mathbb{E}[s_0s_0^{\top}]=A_Kxx^{\top}A_K^{\top}$。把这个递推按 $\gamma^{2k}$ 加权求和，左侧折叠成一个代数方程，于是定理 1 的方差是

$$\mathrm{Var}[G^{K}(x)]=\frac{\gamma^{2}}{1-\gamma^{2}}\mathbb{E}\big[(w^{\top}Pw)^{2}\big]-\frac{\gamma^{2}}{1-\gamma^{2}}\mathrm{tr}^{2}(P\Sigma)+4\gamma^{2}\mathrm{tr}(P\Sigma PZ) \tag{6}$$

其中 $Z$ 是下面这个 Lyapunov 方程的唯一正定解。

$$Z-\gamma^{2}A_{K}ZA_{K}^{\top}=A_{K}\Big(xx^{\top}+\frac{\gamma^{2}}{1-\gamma^{2}}\Sigma\Big)A_{K}^{\top} \tag{7}$$

逐项读一遍。(6) 的第一项带扰动的四阶矩，量的是纯二次型部分的波动。(6) 的第二项是负的，来源是对角与非对角配对时的相互抵消。(6) 的第三项把 $P$、$\Sigma$、$Z$ 三者乘在一起，量的是噪声与一步预测状态之间的无穷时域交互。(7) 右边的 $xx^{\top}$ 说明这个量依赖初始状态，$\frac{\gamma^{2}}{1-\gamma^{2}}\Sigma$ 说明扰动协方差通过 $A_K$ 灌进来。

把四阶矩用一个粗一些的量顶掉，就得到推论 1 的上界。设 $\mathbb{E}[\|w\|^4]=\varphi^4<+\infty$，用 $\mathbb{E}[(w^{\top}Pw)^2]\leq\|P\|^2\varphi^4$ 替换第一项，

$$\mathrm{Var}[G^{K}(x)]\leq\frac{\gamma^{2}}{1-\gamma^{2}}\|P\|^{2}\varphi^{4}-\frac{\gamma^{2}}{1-\gamma^{2}}\mathrm{tr}^{2}(P\Sigma)+4\gamma^{2}\mathrm{tr}(P\Sigma PZ) \tag{8}$$

这一界只在四阶矩那一项上放松，其余项都是精确的。已有的范数界把所有项统一用范数顶，松得多。

### 3.4 高斯扰动下的简化

扰动是零均值高斯时，四阶矩可以拆成二阶矩的乘积。引理 1 用 Isserlis 定理给出

$$\mathbb{E}\big[(w^{\top}Pw)^{2}\big]=2\,\mathrm{tr}(P\Sigma P\Sigma)+[\mathrm{tr}(P\Sigma)]^{2}$$

代进 (6)，$\mathrm{tr}^2(P\Sigma)$ 那一项正好对消，定理 2 给出

$$\mathrm{Var}[G^{K}(x)]=\frac{2\gamma^{2}}{1-\gamma^{2}}\mathrm{tr}(P\Sigma P\Sigma)+4\gamma^{2}\mathrm{tr}(P\Sigma PZ)$$

高斯情形下，方差只依赖扰动协方差，四阶矩消失了。__后面的控制器综合就建立在这个结果上__。

### 3.5 均值-方差优化问题的完整形式

这是本栏目最该看清的一段。论文要解的问题是

$$\min_{K}\ \mathbb{E}\big[G^{K}(x)\big]+\alpha\,\mathrm{Var}\big[G^{K}(x)\big] \tag{9a}$$

$$\rho(A_{K})<1 \tag{9b}$$

$$P-\gamma A_{K}^{\top}PA_{K}=Q+K^{\top}RK \tag{9c}$$

$$Z-\gamma^{2}A_{K}ZA_{K}^{\top}=A_{K}\Big(xx^{\top}+\frac{\gamma^{2}}{1-\gamma^{2}}\Sigma\Big)A_{K}^{\top} \tag{9d}$$

决策变量是反馈增益 $K\in\mathbb{R}^{m\times n}$，一共 $mn$ 个未知数。目标函数由两部分组成，期望累积代价加风险厌恶系数 $\alpha$ 乘方差，$\alpha\geq 0$ 越大越怕波动。约束有三条，(9b) 要求闭环谱半径小于 1，(9c) 与 (9d) 分别把 $P$ 与 $Z$ 钉死在各自的 Lyapunov 方程上。

把方差换成含 $P$、$Z$ 的显式表达式，目标函数可以写成

$$J(K,P,Z)=x^{\top}Px+b\,\mathrm{tr}(P\Sigma)+c\,\mathrm{tr}(P\Sigma P\Sigma)+d\,\mathrm{tr}(P\Sigma PZ)$$

系数是 $b=\frac{\gamma}{1-\gamma}$，$c=\frac{2\alpha\gamma^{2}}{1-\gamma^{2}}$，$d=4\alpha\gamma^{2}$。$J$ 是 $P$ 和 $Z$ 的显函数，而 $P$、$Z$ 通过两个 Lyapunov 方程依赖 $K$，所以 $J$ 最终只是 $K$ 的函数。

自由度账本可以顺手记一下。决策变量 $mn$ 个。每算一次目标要解两个 $n\times n$ 的 Lyapunov 方程，每个方程有 $\frac{n(n+1)}{2}$ 个独立未知量。伴随法再加两个同规模的方程，障碍项再加两个，一轮共六个。用 Bartels-Stewart 求解，每个的代价是 $O(n^3)$。

__α 等于 0 时最优增益就是 K_DARE，这是全文的退化锚点__。这时 (9a) 只剩期望代价，整个问题退回 §2.1 的风险中性折扣随机 LQR，最优解是折扣代数 Riccati 方程

$$P_{\mathrm{DARE}}=Q+\gamma A^{\top}P_{\mathrm{DARE}}A-\gamma A^{\top}P_{\mathrm{DARE}}B(R+\gamma B^{\top}P_{\mathrm{DARE}}B)^{-1}B^{\top}P_{\mathrm{DARE}}A$$

对应的增益 $K_{\mathrm{DARE}}=-(R+\gamma B^{\top}P_{\mathrm{DARE}}B)^{-1}\gamma B^{\top}P_{\mathrm{DARE}}A$。==把 α 调到 0，整套问题退回风险中性折扣 LQR==。$\alpha$ 从零往上加，就是站在这个经典解上，一步步拿期望代价换方差。这张退化的对应关系也是读后面实验结果的钥匙。

### 3.6 为什么不能直接解

四处拦路。

第一处是非凸。$J$ 里的 $\mathrm{tr}(P\Sigma P\Sigma)$ 对 $P$ 是二次的，$P$ 又是 $K$ 的有理函数，$\mathrm{tr}(P\Sigma PZ)$ 还要把两个 Lyapunov 解乘在一起。

第二处是约束耦合。等式约束是两个 Lyapunov 方程，而目标函数里的 $d\,\mathrm{tr}(P\Sigma PZ)$ 把它们的解联在一起。论文原话是这条耦合让"可计算的重写"很难找到，所以它放弃了消约束改凸问题这条路。

第三处是定义域的形状。折扣 Lyapunov 方程在 $\rho(A_K)<1/\sqrt{\gamma}$ 之前都有解，$\rho(A_K)$ 逼近 1 时目标依然有限。于是 $J$ 的次水平集可以贴着稳定域边界不断堆积，可能不是紧集。==次水平集可能贴着稳定域边界堆积，梯度下降无法保证不越界==。

第四处是工具不匹配。经典 LQR 上那套策略梯度结果依赖代价的 coercive 和梯度支配性质，论文指出这两条在均值-方差目标上都不成立。

论文的应对分两层。先用伴随法把 $J$ 的梯度算出来，再加一个障碍项，把开集边界变成一堵光滑的软墙。

### 3.7 伴随法与 J 的梯度表达式

目标里的 $P$ 与 $Z$ 都隐式依赖 $K$。直接求它们对 $K$ 的导数，要对 $mn$ 个方向各解一次矩阵方程，代价过高。伴随法换了个问法。把两个 Lyapunov 方程写进 Lagrangian，配上乘子 $\Lambda_P$ 与 $\Lambda_Z$，然后挑乘子让 Lagrangian 对 $P$ 与 $Z$ 的偏导为零。这一步把隐式依赖项从微分里消掉，总梯度就等于 Lagrangian 对 $K$ 的偏导。

先算显式偏导。

$$\frac{\partial J}{\partial P}=xx^{\top}+b\Sigma+2c\Sigma P\Sigma+d(\Sigma PZ+ZP\Sigma) \tag{10}$$

$$\frac{\partial J}{\partial Z}=dP\Sigma P \tag{11}$$

再解伴随方程。引理 2 给出

$$\Lambda_{P}-\gamma A_{K}\Lambda_{P}A_{K}^{\top}=-\frac{\partial J}{\partial P} \tag{12}$$

$$\Lambda_{Z}-\gamma^{2}A_{K}^{\top}\Lambda_{Z}A_{K}=-\frac{\partial J}{\partial Z} \tag{13}$$

两个方程在稳定域上都有唯一解。理由在 Remark 4 里。$\rho(\gamma A_K\otimes A_K)=\gamma\rho(A_K)^{2}<1$，$\rho(\gamma^{2}A_K\otimes A_K)=\gamma^{2}\rho(A_K)^{2}<1$，对应的 Lyapunov 算子非奇异。

拼起来就是命题 3 的梯度。

$$\nabla_{K}J=-2(RK+\gamma B^{\top}PA_{K})\Lambda_{P}-2\gamma^{2}B^{\top}\Lambda_{Z}A_{K}(Z+M) \tag{14}$$

其中 $M=\frac{1}{\gamma^{2}}xx^{\top}+\frac{1}{1-\gamma^{2}}\Sigma$。(14) 的第一项形状眼熟，把 $\Lambda_P$ 换成单位阵就退回经典 LQR 的梯度。第二项是方差引进来的新东西。

### 3.8 加一堵墙，松弛的代价有多大

梯度有了，还剩定义域那处麻烦。这是全文唯一一处把硬约束换成软惩罚的地方。

$$J_{\mu}(K)=J(K)+\mu\log\det\widetilde{P}(K),\qquad K\in\mathcal{D}_{\mathrm{stab}} \tag{15}$$

$\mu>0$ 是障碍权重，$\widetilde{P}(K)$ 是无折扣 Lyapunov 方程的唯一正定解。

$$\widetilde{P}-A_{K}^{\top}\widetilde{P}A_{K}=I \tag{16}$$

机制可以从 $\widetilde{P}$ 的级数形式看清。$\widetilde{P}=\sum_{t=0}^{\infty}(A_K^{\top})^{t}A_K^{t}\succeq I$。取 $A_K$ 的一个模等于谱半径的特征向量，得到 $\lambda_{\max}(\widetilde{P})\geq\frac{1}{1-\rho(A_K)^{2}}$，于是

$$\log\det\widetilde{P}\geq\log\lambda_{\max}(\widetilde{P})\geq-\log\big(1-\rho(A_{K})^{2}\big)$$

$\rho(A_K)$ 逼近 1 时右端发散。==障碍项精确地在稳定边界上发散==。__它的作用是把惩罚目标的次水平集压成紧集，并让整个次水平集落在稳定域内部__。

障碍项那一半的梯度由命题 4 给出。

$$\nabla_{K}\log\det\widetilde{P}=-2B^{\top}\widetilde{P}A_{K}\widetilde{\Lambda} \tag{17}$$

$\widetilde{\Lambda}$ 解另一个 Lyapunov 方程。

$$\widetilde{\Lambda}-A_{K}\widetilde{\Lambda}A_{K}^{\top}=-\widetilde{P}^{-1} \tag{18}$$

被优化的量到这里可以补齐三件套。初值来自折扣 LQR 增益，算法第 1 行指定，它自带稳定性，保证 $K_0$ 落在稳定域内。驱动来自残差 $\nabla_KJ_\mu$，也就是 (14) 加 $\mu$ 乘 (17)，每一轮都要重算六个 Lyapunov 方程。兜底来自障碍项本身，它在边界发散，配合 Armijo 回溯保证每步都落在稳定域里。

代价写在明面上。解出来的是 $J_\mu$ 的平稳点，$\mu$ 固定且为正时相对 $J$ 的解有偏差。论文在 §5.2 把偏差量化为三条，控制器的相对偏差、原目标值的相对畸变、原目标的梯度残差。表 3 给出这些量随 $\mu$ 从 $10^{-4}$ 涨到 $10^2$ 的变化，取 $\mu_{\mathrm{ref}}=10^{-8}$ 做数值参考。

论文也给了选 $\mu$ 的经验规则。给定原目标畸变的容差与梯度残差的容差，各自取满足容差的最大 $\mu$，再取两者中小的那一个。

### 3.9 算法、稳定性与收敛

算法 1 把上面的顺序固定下来。

```
输入  A, B, Q, R, Σ, x, γ, α, μ>0, b, c, d, M, β∈(0,1), τ∈(0,1), η0>0, ε>0
输出  平稳增益 K*，且 ρ(A + B K*) < 1
K ← 折扣 LQR 增益            ▷ 初值自带稳定性
while ‖∇_K J_μ(K)‖ > ε do
  解式(2) 得 P；解式(7) 得 Z；解式(16) 得 P̃
  由式(10)(11) 算 ∂J/∂P 与 ∂J/∂Z
  解式(12) 得 Λ_P；解式(13) 得 Λ_Z；解式(18) 得 Λ̃
  ∇_K J_μ ← 式(14) + μ · 式(17)
  η ← η0
  while J_μ(K − η ∇_K J_μ) > J_μ(K) − τ η ‖∇_K J_μ‖² do
    η ← βη                   ▷ Armijo 回溯
  end while
  K ← K − η ∇_K J_μ
end while
```

定理 3 给三条保证。迭代序列全部落在初始次水平集 $S_0$ 内，而 $S_0$ 是稳定域的子集。步长有正下界 $\eta_{k}\geq\eta_{\min}>0$，这个下界来自回溯线搜索的有限终止性。梯度趋于零，并且最快的一次迭代满足

$$\min_{0\leq k\leq N}\|\nabla J_{\mu}(K_{k})\|^{2}\leq\frac{J_{\mu}(K_{0})-\inf_{S_{0}}J_{\mu}}{\tau\eta_{\min}(N+1)}=O\Big(\frac{1}{N}\Big) \tag{19}$$

==所有迭代都留在稳定域内，步长还有正的下界==。收敛速度是次线性的。

复杂度的账也好算。每轮解六个 $n\times n$ Lyapunov 方程，加 $O(1)$ 次同规模矩阵乘法，单轮 $O(n^3)$。Armijo 每次试探要多解三个方程，但试探次数的上界是个常数。要让梯度范数降到 $\varepsilon_{\mathrm{grad}}$ 以下，迭代次数是 $O(1/\varepsilon_{\mathrm{grad}}^2)$，总代价 $O\big(n^{3}/\varepsilon_{\mathrm{grad}}^{2}\big)$。

**这节要你记住的是**　障碍项把稳定域变成软墙，伴随法把梯度变成两次求解。

## 五、局限

论文自己承认的有五条。

1. 目标依赖初始状态 $x$。论文在结论里明说当前形式依赖 $x$，目标是 $J(K,x)$ 而不是一个只关于 $K$ 的量。要覆盖一族初值，得改成对一个紧不确定集取最坏情形的形式，论文把这一条列为未来方向。

2. 结论建立在 Assumption 1 上。扰动必须独立同分布、零均值、概率密度关于原点对称。定理 2 与整个控制器综合还要再限定到高斯扰动，因为 §4 用的方差表达式来自高斯情形。非对称或非独立同分布的情形论文没有给。

3. 目前只做离散时间。论文在结论里把连续时间线性系统的推广列为未来方向。

4. 非凸问题只解到平稳点。论文承认均值-方差最优控制是带等式与不等式约束的非凸问题，而且两个 Lyapunov 方程的耦合让可计算的重写很难找到。定理 3 给的是惩罚目标平稳点的收敛，不是全局最优。

5. 惩罚化带来偏差。论文在 §5.2 明说固定 $\mu>0$ 时得到的控制器相对 $J$ 的解可能有偏差，并专门用一节量化这个偏差。

下面这条是编者补充的，论文未将其列为局限。

全篇假定 $A$、$B$、$\Sigma$、$Q$、$R$ 精确已知，这是一个基于模型的设计，数据驱动或无模型的版本论文没有做。数值验证的规模也偏小，两个有物理背景的算例分别是 $n=3$ 的数据中心冷却和 $n=2$ 的车辆转向，维度推到 25 的实验用的是随机生成的系统矩阵，只测时间不测性能。论文还没有讨论把方差作为唯一风险代理是否足够。图 3(b) 显示航向角越界概率随 $\alpha$ 非单调，论文报告了这个现象，但没有把它当成局限来讨论。$\mu$ 的选取虽然有基于容差的规则，容差本身仍需人来指定。

**这节要你记住的是**　理论前提和惩罚偏差，是这套方法的两处硬边界。

## 六、我的评价

做得对的几处。

顺序排得对。论文先解决"方差能不能写出来"，再解决"这个目标能不能算"，最后才谈收敛。这个顺序符合问题的依赖关系，因为均值-方差目标的可解性完全取决于方差有没有闭式。

障碍项用得克制。它没有假装把非凸问题解掉了，只处理定义域的非紧性，然后老实说解到的是平稳点。==解出来的是惩罚目标的平稳点，不是原目标的解==。这句话在很多论文里会被含糊过去，这篇没有。

和 LEQG 的对比选得好。LEQG 是风险敏感控制里少数有完整解析解的方法，把它扫出来的控制点画到均值-方差平面上，读者能直接看到，有解析解和在均值-方差意义下 Pareto 有效是两件事。这个对比比再多加一个数值算例有用。反面也要看到，LEQG 的增益由闭式给出，不需要迭代，本文方法每轮要解六个 Lyapunov 方程，维度到 25 时单次求解已经落在**10 秒**的量级。

存疑的几处。

界的紧度依赖四阶矩。表 1 里四种分布的四阶矩都有闭式，所以看着漂亮。工程里 $\Sigma$ 常常是估出来的，$\varphi^4$ 更难，推论 1 的实用性会打折。

稳定性的保证只覆盖迭代过程。定理 3 保证的是迭代不越出稳定域，不是闭环性能有界。超调、裕度、执行器饱和这些控制工程师最在意的指标没有进目标函数，也没进定理。

$\alpha$ 到物理量的映射要靠事后仿真。论文自己承认"风险厌恶的边际收益递减"，而图 3(b) 又显示不同物理量的最优 $\alpha$ 不一样。实际用起来，$\alpha$ 是一个需要扫描的超参数，不是一个可以按物理意义直接指定的量。把方差当唯一风险代理，物理量的越界概率不会一致地随 $\alpha$ 改善。

它想走去哪。结论里给的是两条，把初值依赖改成对不确定集取最坏情形，以及推广到连续时间。

**这节要你记住的是**　它给的是一个能算的风险目标，不是一套现成的控制器。

## 七、可以接着做什么

下面几条是读完之后顺手想到的，只当线索。

换风险判据。把方差换成越界概率的凸近似，或者换成条件风险价值。代价是丢掉闭式，但换来的是能直接对上图 3 那类物理判据的目标函数。这条路的风险在于凸近似的保守程度不好控制。

把标量风险厌恶变成向量。图 3 给出的现象是，一个 $\alpha$ 无法同时压低两个物理量的越界概率。可以考虑给状态的不同分量各配一个权重，或者把几个物理量的越界概率做成约束而不是惩罚项。

处理掉对初始状态的依赖。论文提的是对不确定集取最坏情形，这条路的难点是 maxmin 结构会让问题更难解。另一条路是用稳态分布的均值代替单点初值，这样目标就与 $x$ 无关了，代价是丢掉瞬态信息。

换求解器。既然 $P$ 与 $Z$ 都满足 Lyapunov 方程，可以考虑把 $J$ 重写成两个 Lyapunov 解的显函数之后做半定松弛，或者用拟牛顿法加速。目标是把次线性的 $O(\frac{1}{N})$ 换掉，同时保住稳定域内的可行性。

检验对模型误差的鲁棒性。全篇假定 $\Sigma$ 精确。伴随梯度对 $\Sigma$ 的敏感度是一个可以立刻做的数值实验，把 $\Sigma$ 扰动百分之几，看最优增益和实际方差怎么变。

※ 以上是即时联想，没有做实验，也没有查证相关文献，只当线索用。

**这节要你记住的是**　往下走的方向，是换风险判据和换求解器两条。

## 名词速查

| 词 | 一句话解释 |
|---|---|
| 折扣 LQR | 目标带折扣因子的线性二次调节器，最小化期望累积二次代价 |
| 分布 LQR | 把回报当作随机变量、刻画它整个分布的线性二次控制框架 |
| 随机回报 | 固定控制器在一次具体实验里真花掉的累积代价，是随机变量 |
| 方差风险度量 | 用随机回报的二阶中心矩衡量同一控制器在多次运行之间的波动 |
| Lyapunov 方程 | 形如 $X-aA^{\top}XA=C$ 的线性矩阵方程，解存在要求谱半径足够小 |
| $Z$ 方程 | 定理 1 引进的额外 Lyapunov 方程，解等于预测状态二阶矩的加权和 |
| 正交性 | 两个随机变量的乘积期望为零，本文用它把方差的交叉项清掉 |
| Isserlis 定理 | 高斯随机变量的高阶矩可以拆成所有两两配对二阶矩乘积之和 |
| DARE | 折扣代数 Riccati 方程，$\alpha$ 等于 0 时最优增益的出处 |
| 风险厌恶系数 | 目标里给方差配的权重，越大越怕波动，记作 $\alpha$ |
| 对数障碍 | 在定义域边界发散的一项，本文用来把稳定域约束变成软墙 |
| 伴随法 | 引入乘子消掉隐式导数的方法，把梯度计算压到解两个矩阵方程 |
| 平稳点 | 梯度为零的点，非凸问题里梯度下降能保证到达的最强结论 |
| 梯度支配 | 梯度范数的平方能控制目标与最优值之差的性质，经典 LQR 上有 |
| coercive 性质 | 变量趋于无穷时函数值也趋于无穷，是经典 LQR 有全局收敛的前提之一 |
| 谱半径 | 矩阵特征值模的最大值，小于 1 表示离散系统渐近稳定 |
| 四阶矩 | 随机变量四次方的期望，描述分布尾部的厚薄，本文的界要用到它 |
| Monte Carlo | 用大量随机采样估计期望或方差的数值办法 |
| 次水平集 | 目标函数取值不超过某个阈值的控制器集合 |
| LEQG | 用指数效用惩罚尾部的风险敏感控制，$\theta$ 趋零时一阶等价于均值-方差 |
| CVaR | 条件风险价值，衡量超出某个分位点的平均损失，一般没有闭式 |
| Pareto 有效 | 无法在不恶化另一项指标的前提下改进任何一项指标的取值 |
| Bartels-Stewart | 求解 Lyapunov 方程的标准算法，复杂度是 $O(n^3)$ |
| Armijo 回溯 | 步长太大导致下降不足时不断折半的线搜索规则 |
