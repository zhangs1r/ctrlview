## 它想干什么

一台 32 英寸翼展的固定翼在陌生的室内障碍场里穿行，机头只挂一枚 87°×58° 的深度相机。它要在 0.1 秒内算出四个操纵面指令，还不能撞上柱子。这台机器有 17 维状态、4 维输入，动力学强非线性且欠驱动，感知只覆盖正前方一小块。

把「不会撞」说成一句可以检验的话，需要概率语言。这篇的目标是这样一个陈述。在置信度 $1-\delta$ 之下，==未来 $N_T$ 步里每一刻都待在安全集内的条件概率==不低于 $1-\beta_\mathcal{S}$。

强化学习能把这类机器飞起来，代价是学出来的策略没有强制约束的机制。NMPC 能把约束写成显式的优化条件，代价是只看 11 步，遇到凹形障碍会陷进局部极小。论文要做的是把两者的长处拼在一起。

拼法很克制。RL 训出来的三个网络只出现在采样分布这一层，actor 网络给优化变量一个初值，critic 网络当终端代价，传感器预测网络负责猜未来几帧深度图。最后执行什么由 PAC-NMPC 的约束优化求解器决定，它带两个 PAC 界，一个管约束违反概率，一个管终端值函数。PAC 是 Probably Approximately Correct 的缩写，指用有限样本给出的、带置信度的概率界。

训练与部署因此解耦。RL 只影响搜索从哪里开始，不影响最后执行什么。

用 RL 的分布做暖启动与终端代价，两条 PAC 硬约束卡住安全与进步。

这节要你记住的是，强化学习只管带路，概率界负责否决。

## 一、问题背景

### 1.1 不确定性有三个来源

第一是动力学。固定翼的气动面、执行机构延迟、螺旋桨滑流都只能近似建模。论文用二阶龙格库塔积分加高斯过程噪声来补，协方差从真实飞行数据拟合（图 9）。小车那边同理，过程协方差 $diag(4e^{-4}, 4e^{-4}, 1.1e^{-2}, 1e^{-1}, 5.6e^{-3})$ 也是从硬件数据拟合出来的。

第二是感知。深度相机视场只有 87°×58°，机体做机动时观察过的障碍会滑出画面。未来测量更无从知道，环境未知，测量方程 $y_t = h(x_t, O)$ 里的障碍集合 $O$ 不在手里。

第三来自学习模型本身。actor、critic、传感器预测都是近似，它们的误差会直接进入代价和约束的评估。

### 1.2 前人两条路各自缺什么

tube-based robust NMPC [1]、[2] 把有界扰动收进一个 tube 集合，用名义轨迹加减 tube 做约束收紧，换来确定性的硬保证。它要求扰动有界且集合能传播，碰上只有分布、没有界的学习模型就用不上。

SNMPC 一类做法（如 [3]）用协方差传播算违反概率。它需要一个能解析传播的模型，本文拿几百到几千条轨迹的经验分布代替，代价是确定性陈述变成统计陈述。

PAC-NMPC [60] 是这篇的直接前身。它同样采样，优化的是一个反馈策略分布，并给出期望代价与违反概率的 PAC 界。它缺两样，长时程眼光和高维感知下的可扩展性。

RL 一侧。现代深度 RL 策略在部署前训好，省掉实时优化，视野是无限折扣时域。代价有两条，训练分布外性能下降，且没有强制约束的机制。PETS [35] 学概率动力学模型，POLO [36] 学概率值函数，两者都把 NMPC 当成 RL 的策略本身，都不提供安全保证。DMPC [38] 把值函数塞进阶段代价，约束靠罚项，仍然是软代价。Safe RL-MPC [40] 去学一个鲁棒线性 MPC 的参数来换安全保证，非线性项只能当扰动处理，策略偏保守。predictive safety filter [41] 用约束收紧的鲁棒 NMPC 去修正学习策略的输出，同样保守。这两种都没有处理感知输入。LOOP [42] 与 TD-MPC [43] 学隐空间的观测动力学再配值函数来省样本，差别在于它们没有约束机制。DiffStack [44] 与 Actor-Critic MPC [45] 把可微的 MPC 层直接嵌进策略里，能端到端回传梯度，差别在于它们假定动力学确定，也不给安全保证。OptLayer [13] 在策略后加一层约束优化，把不安全输入投影到可行域，==它只保证一步安全==，不考虑动力学与感知的不确定性。PAC-Bayes control [16] 给策略性能的 PAC 保证和向新环境的泛化保证，前提是训练与测试分布的散度有界。本文的界条件在当前观测上，不需要测试分布假设，代价是不给闭环全局保证。

### 1.3 这篇的做法

论文列了四条贡献。一个把 SNMPC 与 RL 接起来的受限 PAC 框架。一个预测未来传感器测量的学习模型，因为未知环境里没有解析的测量方程。一套用 RL 策略给 SNMPC 暖启动的方法，暖启动指给优化器一个接近解的初值，用来把问题推到高维状态与测量空间。一次真机验证，平台是带机载深度相机的固定翼。

这节要你记住的是，难处在于只有一个学出来的分布，没有界也没有结构。

## 三、方法拆解

### 3.1 被优化的到底是什么

决策变量写成 $\nu=(\mu, \mathrm{diag}(\Sigma))$。$\mu$ 是一条标称输入序列 $\xi=(\mathbf{u}_t^d, \dots, \mathbf{u}_{t+N_T-1}^d)$ 的均值，维数是 $N_T \cdot n_u$。$\Sigma$ 取对角协方差，维数相同。所以决策变量一共

$$2 \cdot N_T \cdot n_u$$

个。小车 $N_T=12$、$n_u=2$，是 48 个；固定翼 $N_T=11$、$n_u=4$，是 88 个。

$\xi$ 从一个高斯代理分布 $\mathcal{N}(\xi \mid \mu, \Sigma)$ 里采样，代理分布指采样直接用的那个分布。每条采样轨迹再用 TVLQR 在标称轨迹附近展开成一个时变反馈策略

$$\mathbf{u}_t = \mathbf{K}_t(\mathbf{x}_t^d - \mathbf{x}_t) + \mathbf{u}_t^d$$

TVLQR 指时变线性二次调节器，沿标称轨迹把动力学线性化，反解一个二次代价下的最优反馈增益。这一点和教科书里的开环 MPC 分开了，==优化器交出去的是一族反馈律==，不是一个动作序列。

代价和约束违反指示量分别定义成

$$J(\boldsymbol{\tau}) = \sum_{i=t}^{t+N_T-1} \ell(\mathbf{x}_i, \mathbf{u}_i) + \ell_f(\mathbf{x}_{t+N_T}) \tag{1}$$

$$C(\boldsymbol{\tau}) = \bigvee_{i=t}^{t+N_T-1} \left( c(\mathbf{x}_i, \mathbf{u}_i, \mathbf{y}_{t-N_y, \dots, t}) > 0 \right) \tag{2}$$

$C(\tau)$ 是 0 或 1，取轨迹上所有时刻的或。所以 ==$\mathbb{E}[C(\tau)]$ 就是违反约束的概率==。这一步把安全换成了一个可以估计的标量。

原版 PAC-NMPC 的问题是

$$\begin{array}{l} \hat{\boldsymbol{\nu}}_{i+1}^{*} = \arg\min_{\boldsymbol{\nu}} \min_{\alpha} \left( \mathcal{J}_{\alpha}^{+}(\boldsymbol{\nu}) + \gamma \mathcal{C}_{\alpha}^{+}(\boldsymbol{\nu}) \right) \\ \text{s.t.} \quad \mathbb{P}\left(\mathbb{E}[J(\boldsymbol{\tau})] \leq \mathcal{J}_{\alpha}^{+}(\boldsymbol{\nu})\right) \geq 1-\delta \\ \phantom{\text{s.t.}} \quad \mathbb{P}\left(\mathbb{E}[C(\boldsymbol{\tau})] \leq \mathcal{C}_{\alpha}^{+}(\boldsymbol{\nu})\right) \geq 1-\delta \end{array} \tag{3}$$

两层优化叠在一起，外层对分布参数，内层对退火系数 $\alpha$。两条约束本身是概率陈述，不是数值不等式，这是它没法直接丢给通用求解器的原因之一。

界的形状是

$$\mathcal{J}_{\alpha}^{+}(\boldsymbol{\nu}) = \widehat{\mathcal{J}}_{\alpha}(\boldsymbol{\nu}) + \alpha d(\boldsymbol{\nu}) + \Phi_{\alpha} \tag{4}$$

$\widehat{\mathcal{J}}_{\alpha}$ 是从采样算出来的稳健估计，$d$ 是离先验分布的距离项，$\Phi_{\alpha}$ 是集中不等式项。写开了是这样两式

$$\widehat{\mathcal{J}}_{\alpha}(\boldsymbol{\nu}) = \frac{1}{\alpha L M} \sum_{i=0}^{L-1} \sum_{j=0}^{M-1} \psi(\alpha \ell_{ij}) \tag{5}$$

$$\Phi_{\alpha} = \frac{1}{\alpha L M} \log \frac{1}{\delta} \tag{10}$$

（5）式里的 $\ell_{ij}$ 用概率比 $p(\xi_{ij}|\nu) / p(\xi_{ij}|\nu_i)$ 把先验分布采出来的轨迹折算到当前分布上。距离项 $d$ 用的是 Rényi 散度，作用是别让优化跑出采样覆盖得住的范围。

为什么不能直接解，有四条。期望没有解析式，动力学和学出来的值函数都不解析。约束 $c$ 依赖一段测量历史，还依赖未来那些没观测到的测量。可行域非凸，障碍物和凹陷阱都在里面。重规划周期是 0.1 秒。

论文的解法是采样加 SQP。采样把期望换成经验估计，再补一个集中项把估计误差兜住。非凸约束交给 SNOPT [70]，一个大规模约束优化的序列二次规划实现，它只保证收敛到局部解，全局最优没有保证。

自由度账。未知数是 $2 N_T n_u$ 个。__每条采样轨迹最多贡献 2 个独立标量__，一个代价样本加一个 0 或 1 的约束样本。要让集中项落到 $\Phi_{\alpha}$ 以下，样本量需要满足

$$L \cdot M \geq \frac{\log(1/\delta)}{\alpha \, \Phi_{\alpha}}$$

$\delta=0.05$ 时 $\log(1/\delta)=3.0$。小车那套用 $L=5$、$M=1024$，一次规划迭代要推进 5120 条轨迹；固定翼用 $L=1$、$M=1024$，是 1024 条。

这节要你记住的是，被优化的是采样分布的均值与方差，约束靠概率界把关。

### 3.2 RL 在这套框架里给出什么

观测写成 $\mathbf{z}_t = (\mathbf{x}_t, \mathbf{y}_t)$，状态加传感器测量。actor $\pi^{\phi}(\mathbf{z}_t)$ 直接输出控制量，critic $Q^{\psi}(\mathbf{z}_t, \mathbf{u}_t)$ 估计动作价值。两者组合出值函数

$$V^{\phi\psi}(\mathbf{x}_t) = \min_{\mathbf{u}_t \in \mathcal{U}} \left[ g(\mathbf{x}_t, \mathbf{u}_t) + \beta \mathbb{E}\left[ V(\mathbf{x}_{t+1}) \mid \mathbf{x}_t, \mathbf{u}_t \right] \right] \tag{11}$$

$g$ 是训练用的阶段代价，$\beta$ 是折扣因子。传感器预测 $\mathbf{h}^{\eta}(\mathbf{x}_t, \mathbf{y}_t, \mathbf{x}_{t+k})$ 输出假设未来状态下的测量，因为未知环境里写不出测量的动力学。

训练目标是

$$g(\mathbf{x}_t, \mathbf{u}_t) = \ell(\mathbf{x}_t, \mathbf{u}_t) + \gamma_c c(\mathbf{x}_t, \mathbf{u}_t) \tag{35}$$

违反罚 $\gamma_c$ 在小车取 1000，固定翼取 1500，都是启发式选的。训练时的约束 $c$ 用全环境信息，规划时的约束只用测量历史，两者不是同一个函数。

概率化靠 MC dropout

$$r_j^{(l)} \sim \operatorname{Bernoulli}(p) \qquad \tilde{\mathbf{y}}^{(l)} = \mathbf{r}^{(l)} * \mathbf{y}^{(l)} \tag{14}$$

MC dropout 指推理时也随机丢一部分神经元，多次前向等价于从近似贝叶斯后验里取样。Gal 与 Ghahramani [69] 把 dropout 解释成这种变分近似，它给的是近似后验，不是有覆盖率保证的置信集。

关键的取舍在算力。PAC-NMPC 本来就要为每条采样轨迹做一次前向，于是 ==给每条轨迹换一个 dropout mask 是零额外前向==。换用 ensemble 或多头网络也能给不确定度，那要多几倍算力。

三个网络分工清楚。actor 决定搜索从哪里开始，critic 决定终端代价和有没有进步，传感器预测决定终端状态能不能被评价。

这节要你记住的是，RL 提供的是分布，不是控制律。

### 3.3 暖启动、驱动量与兜底

被优化量的三件套先说清。初值来自 actor，算法 1 先用 $\pi^{\phi}(\mathbf{x}_t, \mathbf{y}_t)$ 算出第一个输入，再用标称动力学 $\mathbf{f}$ 往前推状态，用传感器预测补出每一步的未来测量，继续问 actor 要输入。方差 $\Sigma$ 初始设成预设的高值，目的是让采样覆盖得开。

未来测量是直接从头一帧预测的，$\hat{\mathbf{y}}_{t+k} = \mathbf{h}^{\eta}(\mathbf{x}_t, \mathbf{y}_t, \mathbf{x}_{t+k})$，不做递归。论文试过递归预测，误差会累积，效果变差。

驱动量是采样轨迹的经验代价与违反率，没有解析残差可用。

兜底有两层。==actor 暖启动一旦踩线，就整条换成上一轮 PAC-NMPC 策略==。先验分布 $\nu_0, \dots, \nu_{L-1}$ 通过距离项 $d(\nu)$ 把优化拉回采样覆盖得住的范围。还有一个小设计，运行时往往来不及把探索方差降下来，所以最后一轮优化把 $\Sigma$ 收到预设的小值，让界对准将要执行的那条策略，界因此更紧。

这节要你记住的是，初值靠 actor，踩线就退回上一轮，方差由先验管住。

### 3.4 PAC 保证是怎么来的

论文定义的概率安全保证是这句

$$\mathbb{P}\left( \mathbb{P}\left( \mathbf{x}_{t+i} \in \mathcal{S}, \forall i \in \{0, \dots, N_T\} \mid \mathbf{x}_t \right) \geq 1 - \beta_{\mathcal{S}} \right) \geq 1 - \delta_{\mathcal{S}}$$

两层的量词要分开读。外层概率来自算法自身的随机性，包括采样和 dropout mask。内层概率来自动力学噪声。整句说的是，以不低于 $1-\delta_\mathcal{S}$ 的置信度，条件碰撞概率不超过 $\beta_\mathcal{S}$。

<figure src="2609.39854-svg-twolevel.svg" caption="概率安全保证的两层量词与参数来源。">
<figcaption><b>示意图 B</b>　（编者绘制）外层管算法，内层管机器人。左列是外层的置信度，参数 δ 由用户给，取 0.05。右列是内层的条件概率，上界由采样出来的违反概率界提供，再压到 ε<sub>c</sub> 以下。样本量从中间那个不等式进界，采样越多上界越紧。</figcaption>
</figure>

两个参数各有来路。$\beta_\mathcal{S}$ 就是违反概率的 PAC 上界 $\mathcal{C}_{\alpha}^{+}$，被当成硬约束压到 $\epsilon_c$ 以下，固定翼取 $\epsilon_c = 0.1$。$\delta_\mathcal{S}$ 就是用户给的 $\delta$，两组实验都取 0.05。样本量按 3.1 节那个不等式进界，$L \cdot M$ 翻倍，集中项减半。

第二个界作用在终端值函数上

$$\mathbb{P}\left( \mathbb{E}\left[ V^{\phi\psi}(\mathbf{x}_{t+N_T}, \hat{\mathbf{y}}_{t+N_T}) \right] \leq \mathcal{C}_{\mathcal{V}_{\alpha}^{+}}(\boldsymbol{\nu}) \right) \geq 1-\delta \tag{15}$$

$$\text{s.t.} \quad \mathcal{C}_{\mathcal{V}_{\alpha}^{+}}(\boldsymbol{\nu}) \leq \mathbb{E}\left[ V^{\phi\psi}(\mathbf{x}_t, \mathbf{y}_t) \right] \tag{16}$$

$\mathcal{C}_{\mathcal{V}_{\alpha}^{+}}$ 是上界，界与实际期望之间留着一个非零的间隙，所以约束成立时真实期望还在更下面。整条约束的意思就是终端处的期望值函数低于当前值函数，这一段时域预期在降代价。

最终问题是

$$\begin{array}{rl} \boldsymbol{\nu}^{*} = & \arg\min_{\boldsymbol{\nu}} \min_{\alpha > 0} \left( \mathcal{J}_{\alpha}^{+}(\boldsymbol{\nu}) + \gamma \mathcal{C}_{\alpha}^{+}(\boldsymbol{\nu}) \right) \\ \text{s.t.} & \mathcal{C}_{\alpha}^{+}(\boldsymbol{\nu}) \leq \epsilon_c \\ & \mathcal{C}_{\mathcal{V}_{\alpha}^{+}}(\boldsymbol{\nu}) \leq \mathbb{E}\left[ V^{\phi\psi}(\mathbf{x}_t, \mathbf{y}_t) \right] \end{array} \tag{17}$$

和前作 [6] 的差别有两处。==两个界是分开的，一个管安全一个管进步==。两个界都进硬约束，违反概率界同时在目标函数里当罚项，固定翼取 $\gamma=2$。

界的适用范围要写清。__它属于每个有限时域策略，条件在当前观测上__，闭环跑无限时长的安全性没有保证。论文自己写明了这一条，$\delta_\mathcal{S}=0$ 时对应文献 [8] 里的 Safety Level II。

> 📌 **控制视角**　这一定义把保证拆成了两层，验收方式跟着变。鲁棒界满足一次就永远满足，代价是假设强。这里的界要在每个规划间隔重新算，验收时看的是界的违反率，单条轨迹安全与否说明不了问题。

这节要你记住的是，两个界分工，一个压住撞的概率，一个保证值下降。

### 3.5 为什么要学一个传感器预测网络

小车那套可以几何算。360° 平面 LiDAR 的每个有效回波投影成观测点

$$\mathbf{o}^{j} = \begin{bmatrix} r_{xt} \\ r_{yt} \end{bmatrix} + \begin{bmatrix} \cos(\theta_t + \beta^{j}) \\ \sin(\theta_t + \beta^{j}) \end{bmatrix} y_t^{j} \tag{20}$$

再从假设的未来状态反算距离和方位，最后分配给最近的离散方位。__平面、全视场、已知方位表，三个条件凑齐了才成立__。

固定翼不行。深度图先投到三维，再投到未来位姿的像面上，最近邻和双线性泼溅都试过，结果常常留下大片没赋值的像素（图 10 中间那格的黑区）。终端状态上评价不了值函数，整条链就断了。

于是改成监督学习。数据全部来自仿真，让 actor 在随机环境里飞，把 $(\mathbf{x}_t, \mathbf{y}_t, \mathbf{x}_{t+k})$ 当输入、$\mathbf{y}_{t+k}$ 当目标，$k$ 取 0 到 $N_T$。训练损失是平滑 L1 加上结构相似性 SSIM 那一项。全连接和 U-Net 都训过，U-Net 更好。

<figure src="2609.39854-fig10.jpg" caption="深度图预测的三种做法。">
<figcaption><b>图 10</b>　深度图预测的三种做法，从左到右依次是原论文图 10 的 (b) 真值、(c) 几何投影、(e) U-Net。真值来自飞行中采集的 RealSense D450 深度图，颜色由蓝到黄表示由近到远。几何投影那一格的黑区就是投不到的像素，这类空洞会让值函数在终端状态上算不出来。U-Net 那一格把空洞填满了。三格按 (b)(c)(e) 顺序拼合，FC 那一版的结果见表 V。</figcaption>
</figure>

U-Net 有三段编码解码，输入深度图先过一层卷积升通道，每段是卷积加 RMS 归一化加 SiLU 再加 20% dropout，通道数逐段翻倍、分辨率逐段减半。条件化走 FiLM [78] 那一套，把初始到未来状态的 SE(3) 变换展平后过两层全连接，用它的输出缩放和平移瓶颈层的特征图。$\mathbf{h}^{\eta}$ 同样带 MC dropout，传感器预测的不确定度因此也能进 PAC 界。

预测精度见表 V，指标是仿真数据上的留出验证集。

| 模型 | FLOPs (M) | δ₁ | REL | RMSE |
|---|---|---|---|---|
| 几何，最近邻 | 无 | 0.133 | 2.838 | 0.634 |
| 几何，泼溅 | 无 | 0.186 | 2.240 | 0.548 |
| 全连接 | 36.798 | 0.848 | 0.170 | 0.081 |
| **U-Net** | **42.283** | **0.923** | **0.087** | **0.058** |

δ₁ 是满足 $\max(\hat{d}/d, d/\hat{d}) < 1.25$ 的像素比例，越高越好。几何投影那两行的相对误差比 U-Net 大 25 倍以上。

这节要你记住的是，没有测量方程时，只能学一个出来。

### 3.6 计算代价怎么被控制

采样型的代价主要是轨迹条数。控制手段有这么几条。

- 五千多条轨迹的推进天然可分，落在 GPU 上并行
- dropout 与采样轨迹共用前向，不确定度几乎不额外花算力
- 深度图降到 16×12，U-Net 一次前向 42.3 MFLOPs，全连接版 36.8 MFLOPs
- 暖启动把 SQP 的迭代次数压下来，也避开一部分局部极小
- 最后一轮收方差，界更紧，代价是少了一次探索机会
- 固定翼每 0.1 秒重规划一次，视界 11 步，比小车那套 0.2 秒更频繁

真机上算法跑在笔记本上，配置是 i9-13900H 加 RTX 4080 Laptop。深度图在机载 D4 板上降采样后经 WiFi 以 50 Hz 传过来，机载那块 Arduino 只做梯度滤波。控制指令通过遥控器发射机下发。

这节要你记住的是，算力靠并行、复用和降分辨率换来，没人指望机载芯片。

### 3.7 理论那一节给的是可行性

分析从训练代价 $g = \ell + \gamma_c c$ 出发，$\gamma_c$ 取得足够大。结论分三层。

引理 VIII.1 说，最优输入的某个邻域里存在输入让期望值函数继续下降。条件是值函数连续有界、随机动力学对输入弱连续、阶段代价非负。

引理 VIII.2 说，$\gamma_c$ 变大时最优策略的约束代价能被压到任意小，前提是存在一条约束代价小于 $\epsilon$ 的可行策略。

定理 VIII.1 说，若 $\epsilon$ 小于某个正的下界，则存在一个可行输入，它既满足约束又让值函数下降。定理 VIII.2 把它推到多步反馈策略，前提是策略参数化足够丰富、参数集紧、约束代价连续。

这套结论说的是存在一条既安全又有进步的路，不是控制器一定稳定。稳定性、递归可行性都没给。

近似值函数还留了一个间隙

$$e_V(\mathbf{x}_t, \mathbf{u}_t) = \Delta\hat{V}(\mathbf{x}_t, \mathbf{u}_t) - \Delta V(\mathbf{x}_t, \mathbf{u}_t) \tag{51}$$

$$\Delta\hat{V}(\mathbf{x}_t, \mathbf{u}_t) < e_V(\mathbf{x}_t, \mathbf{u}_t) \tag{52}$$

要保证最优值函数真的下降，近似值的下降幅度得大于这个间隙。间隙在实践里未知，所以退到 $\Delta\hat{V} < 0$ 这个更弱但算得出来的条件。

Dubins 车上的对照实验验证了这一点。13 个网络按递增的罚值训练，每个训 500 万步，100 次试验，起点在离目标 7.5 米处。AC-PAC-NMPC 在更小的罚值上就能避开障碍到达目标，actor 需要更大的罚值才赶上。

> 📌 **控制视角**　这类结论在控制里的位置要说清。Lyapunov 方法和控制障碍函数给的是对所有时刻成立的不变性质，代价是要一个先验的函数。这里给的是存在性加概率陈述，不需要先验函数，但每一步都要重新验一遍。前者管得宽，后者验得动，适用场景不同。

这节要你记住的是，理论给的是存在性，不是稳定性。

### 3.8 退化到经典形式

把过程噪声置零、dropout 关掉，$C(\tau)$ 变成确定性的 0 或 1，稳健估计退化成样本均值，$\Phi_\alpha$ 与 $d(\nu)$ 一起消失。这时问题退化成一个确定性 NMPC，初值来自 actor，终端代价来自学出来的值函数。这正是 DMPC [38] 与 POLO [36] 那一类的形态。

再去掉学习终端代价，只留暖启动，就退化成 PAC-NMPC [60] 本身。

若 $N_T = 1$，问题退化成一步安全层，形态接近 OptLayer [13]，区别是这一步里还带着动力学与感知的不确定性。

若把值函数改进约束删掉，只把值函数当终端代价，安全就只剩违反概率一条，长时程性能开始依赖 critic 的准确度。这一条论文没有做单独消融，前作 [6] 里两个界是合在一起的，拆不开。

这节要你记住的是，不确定性一关，它就回到带学习终端代价的确定性 MPC。

| MPPI 加学习值函数 | 70% | 7% | 23% | 55% | 9% | 36% |

MPPI 指模型预测路径积分控制，无梯度地采样开环输入序列，按代价做指数加权平均。它实现简单、不用求解器，代价是没有约束违反概率的界，表里那两栏 23% 和 36% 就是这个缺口的代价。二次终端代价那一行是另一类失败，论文的说法是系统常常卡在局部极小里，卡住率 24% 与 53%。A* 那一路会规划穿过被遮挡的障碍，论文给的解释是障碍没进地图之前车已经太近了，违反率 7% 和 5%。

本文那行在两张表里都没违反过约束。反向的数字也要看，陷阱环境里本文卡住 7%，比 actor 的 2% 高，说明放松不了。

## 五、局限

### 保证是局部的、有限时域的

PAC 界属于每个有限时域策略，条件在当前观测上。==闭环无限时长的安全性没有保证==。论文原文用 local 与 conditional 两个词限定得很明确。

### 值函数改进的条件建立在最优值函数上

第 VIII-C 节承认学到的模型只是不确切的近似。近似与最优之间的间隙 $e_V$ 未知，只能退而验证 $\Delta\hat{V} < 0$。

### MC dropout 的不确定度没有标定

结论里写明，希望有方法去标定、甚至给出不确定度的界。

### 约束罚是启发式选的

$\gamma_c$ 要么手工定，要么当拉格朗日乘子学。分析要求它足够大，大到什么程度没有给。

### 深度分辨率可能漏掉细障碍

论文承认 16×12 的分辨率可能限制薄障碍的检出，只是本文环境里障碍半径在 0.2 到 0.4 米之间，够用。

### 传感器预测模型不是普遍必要

论文提到，视场大的简单二维环境里，学一个传感器预测模型可能没有必要。

### 两个任务没有联合训练

结论把联合训练列为未来工作，现在的三个网络各自独立训练，与 PAC-NMPC 之间没有反馈。

### 状态真值来自动捕（编者补充，论文未将其列为局限）

两套真机实验都用 OptiTrack 提供位姿与速度，固定翼那套是 180 Hz。感知在这套闭环里只承担障碍检测，状态估计的误差没有进 PAC 界。换到没有动捕的现场，这个界要重新算。

### 小车那一节的数据来自前作（编者补充，论文未将其列为局限）

第 VI 节写明沿用 [6] 的公式与实验结果，且那组实验没开 RL 暖启动、传感器预测也是几何的。本文新增的三个组件在小车上没有单独消融，表 II、表 III、表 IV 里的优势不能全记在本篇账上。

### 真机样本量偏小（编者补充，论文未将其列为局限）

固定翼 10 个环境，小车 20 个。按 10 个环境算，80% 与 40% 这个差距的分辨率是 10 个百分点，方向可信，精度不要当真。

### 基线里缺一个安全滤波器（编者补充，论文未将其列为局限）

表 I 里列了 OptLayer 与 predictive safety filter 这一类做法，实验对照里一个都没有出现。缺一个同样给保证、但只保证一步的参照，读者没法判断多算这一步值不值。

### 感知噪声没有单独建模（编者补充，论文未将其列为局限）

真机那次尖峰来自深度图的杂散噪声，而界里的随机源只有动力学噪声与网络 dropout。当前测量被当成确定的输入，感知噪声只能通过下游网络间接影响界。

这节要你记住的是，作者把保证的边界写清楚了，覆盖不到的地方也摆出来了。

## 六、我的评价

做得对的地方里，==把 RL 放在采样分布这一层最值得学==。RL 提供分布，求解器提供约束，训练与部署因此解耦，训练时不必内嵌一个 NMPC 求解器。前作 [6] 把值函数改进并进违反概率界，这篇拆成两个界，安全与进步各自可查，消融的时候也能分开归因。

MC dropout 与采样轨迹共用前向这个设计很省。采样型 MPC 本来就要为每条轨迹跑一次网络，把 mask 挂到轨迹上，不确定度的边际成本几乎为零。这类不花钱的复用比堆模型更值得抄。

第 VIII 节虽然只给了存在性，但它回答了暖启动为什么合理。它证明了在 actor 附近能找到既可行又下降的方向，这比单纯说经验上有效强得多。

存疑的地方有几处。界的条件性容易被读者略过。看到概率安全保证，很多人会读成不会撞。它条件在当前观测上，感知一旦出错，界的前提就没了，图 14 里那次尖峰就是实例。消融里 3% 与 90% 的落差说明这套方法对传感器预测模型的依赖极强。那个模型的训练数据是 actor 自己飞出来的，闭环里存在同源风险，坏习惯可能被学进去再喂回给 critic。分布外那组打成 76% 对 76% 更值得停一下，说明优势的一半来自训练分布，真要靠它上现场，分布覆盖比算法本身更关键。

保守性的价格也该算清。仿真里 actor 成功时的平均代价 468.1 低于本文的 513.3，卡住率在陷阱环境里本文 7%、actor 2%。安全是买来的，账单写在这两栏里。

参数上，$\gamma=2$ 或 4、$\epsilon_c=0.1$、$\delta=0.05$、MPPI 的温度 0.35，都靠经验定，只有 $\gamma_c$ 在第 VIII 节做了扫描。论文第 V 节那两个界对 $\epsilon_c$ 尤其敏感，它直接决定可行域的大小，换一个任务这套数字要重调。

它想走去哪很清楚。联合训练、不确定度标定、$e_V$ 的分析，三条都指向同一件事，把界的假设收得更紧。

这节要你记住的是，安全是买来的，账单写在代价和卡住率上。

## 七、可以接着做什么

### 1. 把测量噪声放进界

现在界的随机源只有动力学噪声和 dropout，当前测量是确定输入。可以让 $y_t$ 也带分布，比如用共形预测给每帧深度的每个像素一个置信区间，再把区间传播成 $\mathcal{C}_{\alpha}^{+}$ 里的第三项。这样图 14 那种尖峰会被界提前吸收，代价是界更保守。

### 2. 给 MC dropout 的不确定度做标定

论文自己把这条列进了未来工作，具体做法可以借共形预测或分位数回归。目标是把 $\delta$ 从用户拍的数变成可验证的数，顺带回答一个有意思的问题，dropout 的近似后验离真实后验差多少才不影响界的有效性。

### 3. 把回退的硬切换换成软混合

actor 暖启动一旦踩线就整条换成上一轮策略，这个切换在固定翼仿真里留下的卡住率是 5%。可以按不可行程度做连续插值，比如用不可行步数占比当权重，在 actor 初值与上一轮策略之间做凸组合。这属于工程改动，风险低。

### 4. 把局部界升级成递归可行性

现在的保证是每步独立的。给终端状态加一个可控不变集，或者用终端约束把下一步的可行域锁住，可以把第 VIII 节那条存在性结论接到闭环性质上。这是把理论从存在推向保证的最直接一步。

### 5. 换传感器验证分辨率下限

16×12 是作者按算力和任务一起定的。换成事件相机或低分辨率 LiDAR 重做同一组消融，看这个分辨率下限是结构性的还是任务相关的。结论如果是结构性的，传感器预测模型这条路在小视场上就要重新掂量。

这节要你记住的是，五条都围绕同一件事，把界的假设收得更紧。

※ 上面五条都是读完文章的即时联想，我没有做实验，也没有查证过是否已有人在做，更没有验证过可行性。只当选题线索看，不要当结论用。

## 名词速查

| 词 | 一句话解释 |
|---|---|
| **NMPC** | 非线性模型预测控制，每步解一个有限时域优化，只执行第一个动作 |
| **SNMPC** | 随机 NMPC，把动力学的不确定性显式写进优化问题 |
| **tube 方法** | 把有界扰动收进一个集合沿轨迹传播，用名义轨迹加减集合做约束收紧 |
| **采样型 MPC** | 用一批采样轨迹的统计量代替解析的期望和梯度 |
| **MPPI** | 模型预测路径积分控制，对采样的开环输入序列按代价做指数加权 |
| **代理分布** | 采样用的那个高斯分布，决策变量就是它的均值和对角方差 |
| **TVLQR** | 时变线性二次调节器，沿标称轨迹反解时变反馈增益 |
| **PAC** | Probably Approximately Correct，用有限样本给出的、带置信度的概率界 |
| **PAC-NMPC** | 采样型随机 NMPC，对期望代价和违反概率都给出 PAC 上界 |
| **PAC 界** | 由稳健估计、先验距离项、集中项三块相加得到的上界 |
| **SQP** | 序列二次规划，用一串二次子问题逼近带约束的非线性问题 |
| **SNOPT** | 一个大规模 SQP 求解器实现，只保证收敛到局部解 |
| **A*** | 栅格上的最短路搜索，用来给基线提供全局路径 |
| **集中项** | 刻画有限样本估计误差的项，与样本量成反比 |
| **Rényi 散度** | 衡量两个分布差异的量，这里用来惩罚优化跑离先验分布 |
| **actor** | 策略网络，从观测直接输出控制量 |
| **critic** | 动作价值网络，估计某个状态动作下的未来累积代价 |
| **值函数** | 从当前状态到目标的最小期望累积代价，也叫代价-to-go |
| **折扣因子** | 未来代价的衰减系数，取值在 0 到 1 之间 |
| **MC dropout** | 推理时也随机丢神经元，多次前向当作从近似后验里取样 |
| **暖启动** | 用学出来的策略给优化器一个初值，减少迭代次数并避开局部极小 |
| **终端代价** | 加在时域末端的代价项，用来近似时域之外的成本 |
| **值函数改进约束** | 要求终端值函数的上界不超过当前值函数，保证这一步有进步 |
| **ε_c** | 允许的最大违反概率，当成硬约束压住 |
| **δ** | 用户给定的置信参数，界以 1 减 δ 的概率成立 |
| **约束违反指示量** | 轨迹上是否踩约束的 0 或 1 标志，取或 |
| **γ_c** | 训练时对约束违反的罚系数 |
| **分布偏移** | 部署环境的分布与训练分布不一致 |
| **sim-to-real** | 仿真训好的模型搬到真机上，存在建模与感知的差距 |
| **Nav2** | 机器人导航栈，这里只用来做占据体素栅格和 A* 全局规划 |
| **U-Net** | 编码解码结构的卷积网络，能把输入的逐像素预测补全 |
| **FiLM** | 用另一路特征生成缩放和平移系数，去调制主网络的中间特征图 |
| **SSIM** | 结构相似性指标，用来约束预测图与真值图的结构一致 |
| **动捕** | 光学动作捕捉系统，这里提供状态真值 |
| **共形预测** | 用留出数据校准预测区间，让区间的覆盖率有保证 |
| **分位数回归** | 直接拟合条件分布的分位数，用来给不确定度定界 |
| **递归可行性** | 当前时刻可行就意味着下一时刻仍可行，闭环安全的理论基础 |
