## 它想干什么

一家银行部署了一个信贷审批模型。监管要求银行请外部机构来查这个模型对不同人群有没有差别对待，外部机构拿不到模型权重，只能通过接口提问。监管想知道的不光是有没有歧视，还想知道歧视出现在什么收入段、什么年龄段。

这篇论文要回答的就是这件事。它设计了一套提问方式，让外部审计者用尽量少的提问，把模型在多个受保护人群之间的差距估准，同时保证这些提问不会顺手把模型本身泄露出去。

现实里的公平性训练常常只比普通训练好一点点，所以审计只能放到模型上线之后做。上线之后模型是黑盒，审计者靠提问来了解它。这里有一对矛盾。审计者想多问一点，才估得准；模型所有者想少答一点，好保护自己的模型资产。

论文把三个问题串成一条线。能不能不重建模型、也不要求海量带标注数据，就拿到公平性结论。能不能在保住模型机密的前提下做到提问少、结论还带解释。模型所有者如果故意掩盖不公平，审计还准不准。

答法是把审计对象换掉。审计者不去复原整个模型 $h$，而是去学一个「组间比较函数」，它只描述各组输出之间的差。论文给这个比较函数起名叫偏置探针。

审计者每次提问送出去的是一组样本，每组人群各出一个。模型回给它的是这些预测值两两相减的结果。==审计者从头到尾看不到任何一次绝对预测==，模型机密因此有了落脚点。

这套提问还能带上具体特征。审计者可以问出差异在「月收入」这条轴上怎么变，也能问出差异在「过往被捕次数」这个方向上最大落在哪一段。审计报告因此从一维标量变成一张分布图。

少提问靠一套分歧驱动的挑选规则。只有在当前候选集合里存在两个候选函数、它们的比较结果不一致时，这一次提问才花预算。估准靠两个复杂度量，组间星数与 Daniely-Shwartz 维，论文给出了以它们为准的上下界。

## 一、问题背景

### 1.1 审计者能看什么，这个问题就难在这里

公平性审计的形态取决于审计者能拿到什么。能拿到权重和结构的时候，随便什么白盒度量都能算。这篇从头到尾假定审计者只能提问题。

提问这件事本身有好几种规格，规格不同难度差很多。可以问「这个点模型输出什么」，这叫成员查询，一次拿一个绝对预测。也可以问「这两个点模型更偏向哪一个」，这叫比较查询，只拿一个方向。这篇用的是后者的推广，一次拿一组相对比较。

威胁模型的三条要摆全。审计者知道的是一批无标注样本、每条样本的保护属性，以及被审计的属性定义（这里是多组统计平价）。审计者能做的只有提交跨组查询、观察相对响应，不能读写模型内部，也不能改模型的训练数据。审计者的目标是把公平性指标估到指定误差内，并说清差异落在哪里。

模型所有者的能力另算。论文先假设它诚实，只在跨组查询上如实回答。后面专门用一个对抗章节放开这个假设，让它能按审计者当前估计值来决定是否篡改某一条响应。

还有一条容易漏的边界。这两类人都不需要预先知道模型结构。审计者不需要知道被审计的是线性模型还是神经网络，它只需要一个足够丰富的比较函数类，让真实的比较函数落在里面。

### 1.2 两组的分组属性好办，多组就不好办了

公平性指标的形状决定了审计的难度。两组时，差距只有一个数，把两组各自的条件均值估出来相减就够了。多组时，组对数量按 $k(k-1)/2$ 增长，要用一个最大值覆盖全部组对，任何一对估偏都可能改变最终结论。

论文选的多组公平性是

$$\mu(\mathcal{D}, h) = \max_{i, j \in [k]} \mu_{i,j}(\mathcal{D}, h), \qquad \mu_{i,j}(\mathcal{D}, h) = \mathbb{E}[h(X) \mid X \in \mathcal{Z}_i] - \mathbb{E}[h(X) \mid X \in \mathcal{Z}_j] \tag{1}$$

$k$ 是受保护人群个数，$\mathcal{Z}_i$ 是第 $i$ 组的输入子空间，$\mathcal{D}$ 是输入分布，$h$ 是部署中的模型。$\mu_{i,j}$ 保留正负号，正号说明第 $i$ 组被优待，负号说明反过来。

这里有一处设计取舍要记牢。取最大值之前没有套绝对值，所以审计报告能说清谁被优待、谁被歧视。论文把这个定名叫有符号差距。==只报一个绝对值会丢掉方向==，而方向恰恰是受决策影响的那个人最需要的解释。

多组还带来一个统计上的坑。权重很小的区域对总体差距贡献有限，审计者如果按均匀方式采样，会在一堆无关紧要的区域上浪费预算。所以审计必须知道输入分布的边缘信息，这也解释了为什么审计者手里要有一池无标注样本。

### 1.3 前人两条路各自缺什么

第一条路叫模型重建。审计者知道模型所属的函数类 $\mathcal{H}$，用主动学习的手法不断提问，逐步缩小候选集合，最后从中挑一个当替身，再把公平性指标算在这个替身上。论文把这条路的代表实现叫 RECONAUDIT。

RECONAUDIT 的每一轮会挑一个当前候选集合里还存在分歧的点去问，用得到的回答删掉不一致的候选。它的提问是为「学模型」服务的，不是为「估指标」服务的，所以样本复杂度跟着学习走，量级是 $\mathcal{O}(d/\varepsilon^2 \log(1/\delta))$，$d$ 是函数类的复杂度度量，比如 VC 维。代价有两层。一是慢，$d$ 可能很大；二是危险，重建出模型等于把模型交出去了，提取攻击顺手就能做。

论文还点出重建路线的另一处副作用。它用来做插值估计的那批点，同时也是用来重建的点，规模按 $d/\varepsilon^2$ 增长。模型更新后要验证公平性有没有变，重建路线会要求新模型在这批点上和旧模型一致，这个约束比「公平性指标不变」强得多，等于把模型更新锁死在大半个输入空间上。

第二条路叫直接估计。审计者不管模型结构，直接从每一组里采样、提问、求样本均值，再把组对均值相减，取最大。论文把这条路叫 DIRECTAUDIT。它的样本复杂度是 $\mathcal{O}(k/\varepsilon^2 \log(1/\mu))$，与函数类复杂度无关，这一点比重建路线干净。

它的短板是结论的形状。直接估计只交出一个标量，回答不了「差异出现在哪些特征区域」。要回答这个问题，得为每个特征、每个取值条件分别采样，样本量按特征数乘上去。多组时它还要为每个组对分别估一遍，组对数按 $k^2$ 增长，成本一起涨。

| | 需要知道什么 | 提问一次拿回什么 | 样本复杂度 | 结论形状 | 模型机密 |
|---|---|---|---|---|---|
| RECONAUDIT | 函数类 $\mathcal{H}$ | 单点标签 | $\mathcal{O}(d/\varepsilon^2\log(1/\delta))$ | 替身模型，可再算任意白盒指标 | 差，重建即泄露 |
| DIRECTAUDIT | 不需要 | 单点标签 | $\mathcal{O}(k/\varepsilon^2\log(1/\mu))$ | 一个标量 | 较好，但仍暴露绝对标签 |
| 本文的 k-ALEBI | 比较函数类 $\mathcal{F}$ | 组对差值向量 | 由 $\mathfrak{s}_k$ 与 $\mathrm{DS}_k$ 共同决定 | 探针加逐特征差异分布 | 好，只露关系差 |

还有一条更早的基线要交代。Yan 与 Zhang 在 2022 年提出的主动公平性审计把审计化归成版本空间搜索，论文把它的实现叫 DIAMAUDIT。它的做法是在线性版本空间里找两个统计平价一高一低的假设，挑一个它们分歧的点去问。它的局限在分组数上，实现假定保护属性是二值的，$k=2$ 时才能跑。

这节要你记住的是，问题是黑盒、少查询、还要顺带保住模型机密。

## 三、方法拆解

### 3.1 威胁模型

先把三类人的能力写清楚，后面的数字才有意义。

审计者知道以下四样。一是受保护属性，每条样本属于哪一组是给定的。二是一池无标注样本，用来提供输入分布的信息。三是多组统计平价的定义，也就是式 (1)。四是比较函数类 $\mathcal{F}$，真实模型的比较函数被认为落在里面，这叫可实现性。

审计者能做的是提交跨组查询。一次查询选中 $k$ 个样本，每组一个，得到 $\binom{k}{2}$ 个差值。论文把这个协议叫 CGQ，全称是 Cross-Group Query。审计者也可以只选择一部分已抽到的查询去问，这叫主动挑选。

审计者看到的是相对量。__它拿不到某个样本的绝对预测，也拿不到单点标签__，这是它与成员查询路线的分水岭。

模型所有者先被假定诚实。后文放开成对抗者时，__它的能力被限成两条，一是每次篡改单条响应的概率上界 $p$，二是这个上界必须小于二分之一__。它只能改自己给出的响应，不能改输入分布，也不能改审计者的算法。篡改概率压在半数以下，是为了让多数投票能把污染稀释掉。

### 3.2 把审计目标从模型换成比较函数

核心构造是把样本池抬到乘积空间。定义

$$\mathcal{X} \triangleq \prod_{i=1}^{k} \mathcal{Z}_i, \qquad \mathcal{F}_k(\mathcal{H}) = \left\{ f_h \mid \mathcal{X} \to \mathbb{R}, \ f_h(\mathbf{x}) = M_k\big(h(x_1), \dots, h(x_k)\big) \right\} \tag{2}$$

$\mathbf{x} = (x_1, \dots, x_k)$ 是一次查询，$x_i$ 是第 $i$ 组出的那个样本。$M_k$ 是把 $k$ 个预测值压成审计所需形式的固定算子。本文的公平性目标对应的 $M_k$ 就是两两相减，

$$f_h(\mathbf{x}) = \big(h(x_i) - h(x_j)\big)_{1 \le i < j \le k} \tag{3}$$

这个函数取值是一个长度为 $\binom{k}{2}$ 的向量，每个分量落在 $\{-1, 0, +1\}$。

现在看自由度。审计目标一共 $\binom{k}{2} = k(k-1)/2$ 个组对，所以被估的未知数就是这 $\binom{k}{2}$ 个组间均值差。一次查询能提供的独立约束不超过 $\binom{k}{2}$ 条，因为响应向量本身只有这么多分量，而且这 $k$ 个预测值之间的平移不影响任何差值。这个平移自由度必须靠额外信息补，论文的做法是从池子里取边缘分布信息。$k=2$ 时未知数 1 个，一次查询给 1 条约束；$k=4$ 时未知数 6 个，一次查询最多给 6 条。

有一条命题把这个框架立住了。任意耦合 $\nu$ 只要各组的边缘分布等于 $\mathcal{D}(\cdot \mid \mathcal{Z}_i)$，就有

$$\mu(h, \mathcal{D}) = \left\| \mathbb{E}_{\mathbf{X} \sim \nu}\big[f_h(\mathbf{X})\big] \right\|_{\infty} \tag{4}$$

耦合指的是把 $k$ 个边缘分布拼成一个联合分布的方式。这个等式的意思是，公平性指标只依赖各组自己的分布，和你怎么把它们配成对毫无关系。

反过来，虽然指标值不变，怎么配对会改变审计者看到的样本长什么样，所以论文把耦合当成审计设计的一部分。==耦合在交互开始之前定好，全程不动==。审计者可以主动挑已经抽到的查询，但不能根据模型的回答去改耦合分布。论文写明，允许耦合自适应会构成一个更强的查询模型，不在本文范围里。

### 3.3 偏置探针长什么样

偏置探针就是一个比较泛函，把查询映射到组间的相对响应。论文给了三种粒度。

全局偏置探针 $f(\mathbf{x}) = (f_{i,j}(\mathbf{x}))_{i \neq j}$ 说清整体上各组差多少。

逐特征偏置剖面锚在某个未被保护的特征 $q$ 上。令 $P_q(\mathbf{X})$ 是查询在第 $q$ 维上的投影，则

$$\mathfrak{e}_{q,i,j}(z) = \mathbb{E}_{\mathbf{X} \sim \mathcal{D}^k}\big[ f_{i,j}(\mathbf{X}) \ \big|\ P_q(\mathbf{X}) = z \big], \qquad \widetilde{f}_q(z) = \max_{i < j} \big| \mathfrak{e}_{q,i,j}(z) \big| \tag{5}$$

$\mathfrak{e}_q$ 是一条带方向的曲线，告诉你这个特征取不同值时，组间差距往哪个方向偏。$\widetilde{f}_q$ 把它压成一条只保留幅度的曲线，用来看哪里差得最狠。论文明确写了这两样东西不能被当成普通的特征重要性，也不能当成特征的因果效应。

信贷那个例子里，月收入是第一条未保护特征，性别是保护属性。审计者看到的是 $f_{1,2}(Q) = h(X_1) - h(X_2)$，取值在 $\{-1,0,+1\}$。$\mathfrak{e}_1(z_1, z_2)$ 就回答这样一件事，两个客户的月收入分别落在 $z_1$ 和 $z_2$ 附近时，组间预测差的条件期望是多少。

三层探针合起来给出分级证据。全局探针判断有没有歧视，逐特征剖面说明差异沿哪条轴变，逐特征幅度指出差异最大的区域。

### 3.4 查询怎么花

算法叫 k-ALEBI，主体是一个分歧驱动的版本空间收缩过程。

每一轮先从固定的耦合分布 $\nu$ 里独立抽一个跨组查询。接着判断这个查询是否落在当前版本空间的分歧集里。分歧集指的是那些还存在两个候选函数、它们在这里给出不同值的查询点。只有在分歧集里，这次提问才会真的发出去，否则这一轮不花预算，继续抽下一个。

一旦发出去，版本空间按回答更新，只保留那些在该点上与模型回答一致的候选。循环的轮数上限是池子预算 $n$。

收尾时从版本空间里挑一个 $\hat{f}$，再按式 (5) 算出逐特征的两条曲线，组成审计报告。报告里三样东西并列，全局探针、逐特征剖面、逐特征幅度。

这一步的初值很直接，版本空间从整个函数类 $\mathcal{F}$ 开始。驱动力是模型回答与候选预测之间的不一致，每一条不一致都删掉一批候选。兜底的是分歧判据本身，落在分歧集外的查询一律不问，==所以预算只花在还能把不确定性削小的方向上==。

分歧集在这里的含义和主动学习里不一样。标准主动学习的分歧集是输入空间的一个子集，问的是一个点的标签还会有歧义。这里的分歧集是跨组元组构成的集合，问的是两组之间的比较关系还有歧义。论文把这个差异说成从逐点几何变成多部几何。

### 3.5 两个复杂度量

要给出查询数的界，得先有一个刻画学习难度的量。候选量不能用 VC 维一类的东西，因为在审计设定里，一次查询比较的是一组来自不同组的样本，而不是一个点。

论文选的量叫组间星数 $\mathfrak{s}_k$。粗略地说，它是这样一组查询的最大个数，存在一个中心探针 $f_0$ 和一组见证探针 $f_1, \dots, f_m$，每个见证探针只在自己的那个查询上与中心探针给出不同结果，别处两者一致。星数越大，越是需要很多精心挑出来的查询才能把候选区分开。

另一个量是 Daniely-Shwartz 维 $\mathrm{DS}_k$，它取值于伪立方体这种结构，刻画的是被动学习所需的样本量。

两个量之间有一条不等式，

$$\mathfrak{s}_k(\mathcal{F}) \le \mathrm{DS}_k(\mathcal{F}) \tag{6}$$

套到线性分类器上，结论很干净。二维齐次线性分类器的星数是无穷大，而对应的二组比较函数类星数只有 3。这就是论文说的分离。重建路线在这个例子里天生走不通，比较函数路线却还有限。==多组公平性只跟着保护属性诱导的分组结构走，和特征空间的几何几乎无关==，所以学它不需要学会整个模型。

### 3.6 少问几次的代价边界

无操纵情形下，论文给出了一组匹配的上下界。

下界说，任何审计者想在误差 $\varepsilon$、置信度 $\delta$ 下学会偏置探针，提问次数至少要

$$\Omega\left( \max\left\{ \frac{1-2\delta}{1-\delta} \min\left\{\mathfrak{s}_k, \left\lfloor \frac{1}{2\varepsilon} \right\rfloor \right\},\ \big[ 1-2\varepsilon-2\delta(1-\varepsilon) \big]_+ \mathrm{DS}_k \right\} \right) \tag{7}$$

上界说 k-ALEBI 用以下次数就能达到 PAC 要求，

$$\mathcal{O}\left( \min\left\{ n,\ (e-1)\min\{\mathfrak{s}_k, n\} \log \frac{en}{\min\{\mathfrak{s}_k, n\}} + \log\frac{2}{\delta} + 1,\ \frac{\min\{\mathfrak{s}_k, n\}}{1 \vee \log \min\{\mathfrak{s}_k, n\}} \mathrm{DS}_k \log\left(\frac{en(2^k-2)}{\mathrm{DS}_k}\right) \right\} \right) \tag{8}$$

其中 $n = \lceil (\mathrm{DS}_k + \log(4/\delta)) / \varepsilon \rceil$ 是被动学习所需的池子规模。

量纲要说明白。式 (7) 与式 (8) 数的是提问次数，量纲是一个计数。$\varepsilon$ 是差值上的绝对误差，与 $\mu$ 同量纲，两个分类器的 $\mu$ 都在 $[-1,1]$ 里，所以 $\varepsilon$ 是相对于取值范围的比例。$\delta$ 是失效概率，无纲。$\mathfrak{s}_k$ 与 $\mathrm{DS}_k$ 都是组合量，无纲。

论文讨论了两种情形怎么衔接。当 $\varepsilon \lesssim 1/\mathfrak{s}_k$ 时，上下界只差对数因子。当 $\mathfrak{s}_k$ 趋于无穷时，上界里主动那一项失效，复杂度退化成被动学习的 $\mathrm{DS}_k$。论文由此给出一条等价刻画，==一个比较函数类是 PAC 可主动学习的，当且仅当它的组间星数有限==。

### 3.7 对抗版本加了多少查询

对抗章节先给出一条局部复现性假设。每一次跨组查询都有一个邻域，这个邻域有以下两条性质。它的概率质量不低于 $\gamma$。在它内部任意再抽一个点，该点与原点给出同一个干净响应的概率，对所有候选函数一致地不低于 $1-\rho$，其中 $0 \le \rho < 1/2$。

有了这条假设，篡改就可以用投票稀释。ROBUST k-ALEBI 在 k-ALEBI 每次想要查询 $\mathbf{X}_t$ 时，先在同一个邻域里独立抽 $R$ 个点，逐个去问，再取众数当作这个查询的干净回答，喂回给 k-ALEBI。

$R$ 由两个误差源共同决定。定义 $\beta \triangleq \rho + (1-\rho)p = p + \rho - p\rho$，$\rho$ 管邻域内响应可能不一致，$p$ 管被篡改，$\beta$ 是两者合并后的单次错误概率。由于 $p < 1/2$ 且 $\rho < 1/2$，有 $\beta < 1/2$。局部预算取

$$R(p) = \left\lceil \frac{2}{(1-2\beta)^2} \log \frac{2N}{\delta} \right\rceil \tag{9}$$

总查询复杂度是 $N_0(\varepsilon, \delta/2)$ 乘以 $R$，其中 $N_0$ 就是无对抗情形的上界式 (8)。用拒绝采样从无标注流里取邻域样本时，期望抽取次数还要再除以 $\gamma$。

论文对参数量级的描述有一处写法要留个心。正文写的是 $\beta$ 越小查询越多，字面读起来和 $R(p)$ 的单调性相反。按式 (9) 的实际依赖，$(1-2\beta)$ 变小意味着 $\beta$ 变大，查询数随之上升。附录 F.1 实现的参数是 $\rho = 0.05$、$\delta = 0.05$、$\beta = p + 0.05 - 0.05p$。

实验里的实现细节值得抄一句。每个查询的邻域用固定参考面板上的伪度量构造，取距离最近的 256 个不同查询组成一格，构造过程不看版本空间，也不看任何模型响应。当 $p=0$ 时格子的作用消失，ROBUST k-ALEBI 退化成 k-ALEBI。剩余预算不够支付一次完整的 $R$ 次局部查询时，算法选择弃权，而不是拿一个更小的块凑数。

这节要你记住的是，挑分歧点提问，再把回答聚合成组间差值。

## 四、结果

实验在三个公开数据集上做，COMPAS 用 $k=2$，GERMAN CREDIT 用 $k=4$，STUDENT 用来补性别相关的差异分析。模型有线性模型、随机森林和多层感知机三种，每组实验跑 10 个随机种子。

### 4.3 保住模型机密

<figure src="2609.40034-fig9.jpg" caption="身份泄露随暴露的个体预测数增长。">
<figcaption><b>图 9</b>　身份泄露随暴露的个体预测数增长。三格依次是 COMPAS、German Credit、Student Performance。横轴是暴露给审计者的个体模型预测次数。纵轴是身份泄露，单位是比特，定义见式 (10)。橙线是 RECONAUDIT，蓝线是 k-ALEBI。三格里橙线的斜率都约为蓝线的两倍。</figcaption>
</figure>

泄露的度量用身份泄露，单位是比特。设假设类大小为 $|\mathcal{H}|$，$t$ 次交互后与观测一致的候选集合大小为 $|\mathcal{V}_t|$，则

$$\mathcal{I}_t = \log_2 \frac{|\mathcal{H}|}{|\mathcal{V}_t|} \tag{10}$$

论文给的例子是，假设类 1000 个候选，交互后只剩 20 个一致，==泄露约 5.64 比特==。

曲线读数要小心。横轴是暴露的个体预测次数，不是查询次数，因为一次跨组查询可能暴露多个个体预测。COMPAS 与 Student Performance 这两格里，暴露 **1000** 次个体预测时，RECONAUDIT 的泄露到 **790 比特**附近。同样这个暴露量下 k-ALEBI 到 **410 比特**附近。GERMAN CREDIT 那一格差距更大。1000 次暴露时 RECONAUDIT 约 790 比特，k-ALEBI 在约 770 次暴露时只有约 160 比特。三格里橙线的斜率都接近蓝线的两倍。

这三个数字合起来的意思很明确。同样的暴露预算下，关系型查询让模型更难被定位。审计效用与模型识别在这里被分开了。

### 4.4 顶得住对抗

对抗这组实验的结论要对着两个不同的判据读。

COMPAS 线性模型上，$p=0.40$ 的高篡改档位里，对抗者平均制造 **41.4** 次原始坐标篡改，经过格子内多数投票过滤后只剩 **6.2** 次真正污染了查询。公平性估计误差只从 **0.019** 升到 **0.021**，五轮里没有观察到掩盖。

同档位下 RECONAUDIT 的重建误差从 **0** 升到 **0.074**，掩盖率 **0.20**。Yan 与 Zhang 那条基线在无攻击时误差 **0.03**，在最强的可行攻击概率下升到 **0.05**，而这个攻击概率被压在 **0.12**。GERMAN CREDIT 与 STUDENT 的线性模型上，k-ALEBI 表现出同样的稳定性。

这节要你记住的是，关系型查询同时买到了省预算、可解释和抗提取。

## 五、局限

### 5.1 理论保证依赖可实现性与有限复杂度

推论 3.1 的等价刻画建立在函数类可实现、且 $\mathrm{DS}_k$ 有限这两条上。论文自己列的例子是线性分类器与轴平行矩形，这两类都满足。换成一般神经网络或随机森林时，论文没有给出对应的复杂度计算。论文的保证只在已经被刻画出复杂度的函数类里有内容。

### 5.2 只审计多组统计平价

论文从头到尾只处理一个公平性指标。换到机会均等这类条件型指标上，比较算子的形式要重写，论文没有做。多组的部分依赖也被略过了。

### 5.3 验证集中在线性模型上

主文第 4 节写的是三种模型都训练过。可对照 DIAMAUDIT 的精度数字、逐特征分析、身份泄露与对抗实验，都是在线性或线性版本空间上得到的。随机森林与多层感知机的数字被推到附录，主文没有给出。论文自己在附录里也说明，k-ALEBI 那一侧用的是线性模型族的蒙特卡洛近似。

### 5.4 对抗保证带两条额外假设

局部复现性与格子在星集上的可复现性都是新增假设，分别要求 $\rho < 1/2$ 与 $p < 1/2$。格子映射还必须在交互前定好，不能依赖版本空间。换句话说，防御的有效性建立在模型行为在局部足够一致这件性质上，这条性质本身没有在论文里被验证过。

### 5.5 提取困难性说的是最小集合难找

定理 3.2 的 NP 完全性来自最小测试覆盖问题的归约，它说明的是「找到最小的那组能唯一识别模型的查询」这件事很难。一个不追求最小、肯多花查询或肯用辅助信息的攻击者不在这个论证范围里。论文在正文也承认，准确的公平性估计可以和多个观测上兼容的模型并存。

### 5.6 分组数在正文与附录里对不上

第 4 节写 GERMAN CREDIT 用 $k=4$。附录 F.2 写同一套数据包含四个 status_and_sex 分组，合计 $k=6$ 组。==两个数字都对不上，论文没有解释==。附录同时提到 DIAMAUDIT 的原始实现没有在 GERMAN CREDIT 上运行。分组数直接决定 $\binom{k}{2}$ 这个组对数，而组对数是本文方法的成本与精度核心，所以这个出入不是排版级别的小问题。

### 5.7 保护属性被当成给定且正确(编者补充，论文未将其列为局限)

论文把分组写在输入向量的第 $p+1$ 维上，等于假定每条样本的保护属性已知且准确，也假定分群方案本身没有争议。现实里保护属性经常缺失，有时只能靠推断得到，而推断错误会把不存在的差距算进审计报告。论文没有讨论属性噪声或属性缺失对探针估计的影响。

### 5.8 样本量、种子数与预算上限没有统一报告(编者补充，论文未将其列为局限)

论文只说每组实验跑 10 个随机种子，没有给出三个数据集的池子规模。各图的横轴量程也不一致，COMPAS 与 Student Performance 画到 1000，German Credit 的 k-ALEBI 曲线在约 770 处就停了。缺了这些条件，读者无法判断曲线差异有多少来自算法、多少来自池子大小。

### 5.9 对抗模型只覆盖加权篡改(编者补充，论文未将其列为局限)

条件概率上界 $p < 1/2$ 排除了一类更有威胁的所有者，它可以选择只在那些对最终结论影响最大的查询上篡改，把有限的篡改预算集中投放。论文实现的攻击是独立伯努利篡改，遇到篡改时挑一个让当前绝对统计平价误差变大的错误响应，这比集中投放弱。

这节要你记住的是，保证只在给定函数类、给定分组、给定攻击模型下成立。

## 六、我的评价

值得学的地方，首先是那个同构转换。把「学模型」换成「学组间比较泛函」，看上去只是换了个目标函数，它同时解决了三件事。复杂度从可能无穷大降到有限，机密性从重建风险降到只露关系差，可解释性从一个标量变成一个带方向的逐特征剖面。==一次转换解决三个问题是少见的好设计==。

第二件值得学的是分歧驱动与相对响应这两件事的凑巧咬合。审计者抽一个查询，先判断它是否落在分歧集里，再决定要不要花预算。因为拿回来的是相对响应而不是绝对预测，一次提问同时覆盖了 $\binom{k}{2}$ 个组对，组对数随 $k$ 平方增长的时候，单次提问的信息量也一起涨。DIRECTAUDIT 要为每个组对单独采样，这个差别在多组时会被放大。用控制的语言讲，这有点像把可观测性分析从逐状态点搬到了状态对的差上，可观测量从 $h(x)$ 变成了 $h(x_i) - h(x_j)$，后者恰好是公平性这个属性真正依赖的那部分。

第三件是用最小测试覆盖去证明提取困难，归约选得干净。归约里每个测试对应一个只由两个全新点组成的跨组查询，响应直接等于指示函数，一一对应成立。审计可用而提取困难这句话，因此有了一个可检验的形式，而不只是直觉。

存疑的地方也有几处。

图 4 的读法最需要克制。论文没有给每套配置的 $\mu$ 真值，也没有给误差的均值与区间表格。图上的阴影带在某些区间很宽，种子间的差异可能盖过方法间的差异。真要拿这条结论去写监管报告，还得补一张带区间估计的数值表。

对抗章节的参数依赖性有一处自相矛盾。正文说 $\beta$ 越小查询越多，而式 (9) 的 $R(p)$ 随 $\beta$ 增大而增大，两者方向相反。按公式读，正确说法应该是篡改能力越强需要越多查询。这一处不影响整体结论，但会让照着公式实现的人卡一下。

身份泄露的度量口径需要更小心地声明。横轴是暴露的个体预测数，不是查询次数，而且论文附录写明，一次跨组查询在每个坐标 $i \le k$ 上可能暴露多达两次个体预测。两条曲线的自变量因此都是「已经泄露了多少」，而不是「审计者可以选择什么预算」。用它来论证机密性优势时，该看的是达到同一精度所需的泄露量，论文没有给出这个换算。

实验规模本身构成一条边界。主文在三个数据集上验证，最大的 GERMAN CREDIT 也只有 $k=4$ 或 $k=6$。$\binom{k}{2}$ 的增长是本文方法的卖点，却恰恰没有被大 $k$ 的实验测过。附录提到用合成数据补了多个 $k$ 值，主文没有引用这些数字。

它想走去哪很清楚。一条路是把框架推到别的属性上，附录 A.1 已经给了雏形，把鲁棒性看成「原样本对扰动样本」的两组属性。另一条路是把复杂度分析做到底，当前上下界之间在中间 $\varepsilon$ 区间还留着由 $\mathfrak{s}_k$ 与 $\mathrm{DS}_k$ 之间落差决定的缺口。第三条是让对抗模型更贴现实，允许所有者集中投放篡改预算。

这节要你记住的是，换掉被学的对象，三件难事一起松动了。

## 七、可以接着做什么

### 1. 把审计流程搬到控制系统的数据切片上

自动驾驶感知里的公平性审计面对的是另一种黑盒，模型在车上，审计方只有接口。这套框架能直接搬的地方是池子构造，按车型、天气、地域、时段把池子切片当成受保护分组，再用跨组查询去估组间差，不重建整个感知模型。要先确认的是每个切片有没有足够的样本量，因为 $\gamma$ 这类量在稀切片上会很小，邻域采样会变得很贵。

### 2. 把多组统计平价换成条件型指标

机会均等要求条件在真实标签上，形式从无条件均值差变成条件均值差。可以把比较算子 $M_k$ 换成带标签加权的版本，或者对每类标签分别做一次审计再合并。代价是每次查询的响应维度乘以标签类别数，预算要相应重算。这条更像是一道数学题，要先确认组间星数在这种新算子下还有界。

### 3. 处理保护属性缺失或不准

论文把分组写死在输入向量的某一维上。一个自然的扩展是把硬分组换成软分组，每条样本给一个属于各组的权重，分组本身也从数据里估出来。或者反过来，让模型所有者对分组标签加噪声，看审计误差怎么随属性噪声放大。这条的现实意义大，因为很多场景里保护属性本来就是推断出来的。

### 4. 把身份泄露的度量推广到连续模型

现在的身份泄露是比特计数，依赖候选集合大小的对数。这个度量在有限假设类上好用，在神经网络上会直接变成无穷大。可以换成别的可测量，比如提取替代模型在输入分布上的平均预测一致度，或者替代模型与目标在组间差值向量上的距离。要做这件事，还得先把神经网络的 $\mathrm{DS}_k$ 或者某个可用的代理量算出来。

### 5. 把公平性与鲁棒性放进同一个乘积空间

附录 A.1 提到鲁棒性可以看成两组属性，原样本对扰动样本。可以把扰动当作第二重分组，于是查询空间变成「保护分组 × 扰动强度」的乘积，一次审计同时给出公平性差异和它在扰动下的漂移。这条能省掉两轮独立审计的预算，但要重新算复杂度，因为查询空间维度涨了。

这节要你记住的是，五条都指向同一件事，把属性定义与分组假设一起往外推。

※ 上面五条都是读完文章的即时联想，我没有做实验，也没有查证过是否已有人在做，更没有验证过可行性。只当选题线索看，不要当结论用。

## 名词速查

| 词 | 一句话解释 |
|---|---|
| **公平性审计** | 模型上线后由外部机构检查它有没有差别对待某些人群，监管上已经变成硬要求 |
| **多组公平性** | 受保护人群不止两个时的公平性指标，本文用各组输出均值差的最大值 |
| **统计平价** | 两组预测正例率之差，本文用的是保号版本 |
| **有符号差距** | 差值保留正负，用来区分哪一组被优待 |
| **黑盒审计** | 审计者只能通过接口提问，看不到权重与结构 |
| **成员查询** | 送一个样本，拿回一个绝对预测 |
| **跨组查询 CGQ** | 每组各送一个样本，拿回组对之间的差值向量 |
| **相对响应** | 只含组间差、不含绝对预测的回答 |
| **乘积空间** | 把 k 个组的样本空间做笛卡尔积，一次查询是这个空间里的一个元组 |
| **比较函数** | 把一次跨组查询映射到组对差值向量的函数 |
| **偏置探针** | 本文给比较函数起的名字，分全局、逐特征剖面、逐特征幅度三种 |
| **耦合** | 把各组边缘分布拼成联合分布的方式，本文中它对指标值不产生影响 |
| **版本空间** | 所有还没被提问结果排除掉的候选函数 |
| **分歧集** | 还存在两个候选给出不同结果的查询集合，只有在里面才值得提问 |
| **组间星数 $\mathfrak{s}_k$** | 用一组只在各自位置与中心探针不同的见证探针，能撑开的查询个数上限 |
| **Daniely-Shwartz 维 $\mathrm{DS}_k$** | 多类学习的复杂度度量，基于伪立方体结构，刻画被动学习样本量 |
| **伪立方体** | 每个向量在每个坐标上都有邻居的集合，用来定义多类可学性 |
| **PAC 审计** | 以 $1-\delta$ 的概率把误差压到 $\varepsilon$ 以内的审计 |
| **RECONAUDIT** | 先重建模型再审计的基线，复杂度跟着学习走 |
| **DIRECTAUDIT** | 直接估各组均值再相减的基线，只给标量 |
| **DIAMAUDIT** | Yan 与 Zhang 在 2022 年提出的主动审计实现，只支持二值保护属性 |
| **身份泄露 $\mathcal{I}_t$** | 交互前后假设类大小比值的以 2 为底对数，单位比特 |
| **模型提取攻击** | 通过接口提问训一个替身模型，复制原模型功能 |
| **最小测试覆盖** | 用最少的测试把集合里每两个元素分开的问题，本文的 NP 完全性归约来源 |
| **可实现性** | 真实的比较函数确实落在候选函数类里 |
| **局部复现性** | 一次查询的邻域内，干净响应与原点一致的性质，用 $\rho$ 界定 |
| **格子** | 实现里把查询按参考面板上的伪度量聚成的簇，构造格子时取距离最近的 256 个查询 |
| **篡改概率 $p$** | 模型所有者篡改单次响应的条件概率上界，要求小于二分之一 |
| **合并错误率 $\beta$** | $\beta = p + \rho - p\rho$，邻域不一致与篡改两项合成后的单次错误概率 |
| **拒绝采样** | 从无标注流里反复抽点直到落进目标邻域，期望次数与概率质量成反比 |
| **特征剖面** | 固定某个未保护特征取值后，组间差距的条件期望曲线 |
| **机会均等** | 把预测正例率之差条件在真实标签上的公平性指标，本文没有处理 |
| **可观测性** | 判断系统内部状态能不能由外部输出反推的性质，用来对照本文的相对响应设定 |
| **集中投放篡改** | 对抗者把有限的篡改预算全部用在影响最大的少数查询上，本文的攻击模型不含这种打法 |
